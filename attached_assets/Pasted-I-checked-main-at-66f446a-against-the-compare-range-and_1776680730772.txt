## What is still risky

### Risk 1: fallback-to-template behavior still exists

Inside `mapVariantToPracticeQuestion(...)`, the code still falls back to template values when the variant is incomplete:

* `solutionSteps: variantSteps ?? (template.solutionSteps ?? [])`
* `finalAnswer: ... || template.finalAnswer || ""`
* `answer: ... || template.answer || ""` 

So if the AI returns a bad/incomplete variant, you can still silently reintroduce the old mismatch problem.

This is **much better than before**, but not fully “hard safe.”

### Risk 2: cached filtering is too weak

Cached rows are filtered only by `answer` presence:

```ts
.filter((v) => !!(v.answer && v.answer.trim()))
```

before mapping them into practice questions 

That means a cached row with:

* answer present
* but missing `solutionSteps`
* or missing `finalAnswer`

can still get through and then inherit template fields via fallback.

So the cache path is still not fully trustworthy.
