Fix 1 — Light mode is broken throughout the app + navbar toggle is missing
Background on the theme system:

Theme context: lazytopper/src/context/ThemeContext.tsx
useTheme() returns { theme, toggleTheme, setTheme } where theme is "dark" | "light"
Theme applies by setting data-theme="light" on document.documentElement
CSS variables in lazytopper/src/styles.css:
Dark (:root): --bg: #0a0a0a, --bg-card: rgba(255,255,255,0.03), --bg-card-border: rgba(255,255,255,0.06), --text: #ffffff, --text-muted: rgba(255,255,255,0.45)
Light ([data-theme="light"]): --bg: #f8fafc, --bg-card: #ffffff, --bg-card-border: #e2e8f0, --text: #1e293b, --text-muted: rgba(30,41,59,0.5)
The problem: 57 component files contain 819 occurrences of hardcoded rgba(255,255,255,...) inline styles that never respond to theme changes. In light mode this produces invisible white-on-white text, invisible borders, and unreadable cards across the entire app.
