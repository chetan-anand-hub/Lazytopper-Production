Section A · MCQ / Assertion-Reason1 mark each
Q1. cos θ = 4/5. [1 mark — correct value]
sin²θ + cos²θ = 1 ⇒ cos θ = √(1 − 9/25) = √(16/25) = 4/5 (positive, θ acute).
Q2. 1. [1 mark]
sin30° + cos60° = ½ + ½ = 1.
Section B · Short Answer I2 marks each
Q9. Proof.
(1 − cos²θ) = sin²θ. [1 mark]
sin²θ · cosec²θ = sin²θ · (1/sin²θ) = 1. Hence proved. [1 mark]
Section C · Short Answer II3 marks each
Q14. A = 45°, B = 15°.
tan(A+B) = √3 ⇒ A + B = 60°. [1 mark]
tan(A−B) = 1/√3 ⇒ A − B = 30°. [1 mark]
Solving: A = 45°, B = 15°. [1 mark]
