# paper-03 - SYNTHETIC controller test paper (wave A-15, GRADER-CORE-1)

**Every answer file in this folder is SYNTHETIC**: the handwriting is rendered from fonts by `a15-papers-author`; no real student wrote it.
The questions are CBSE published items (see `key.md` for the paper, question number and page of every item and value point).

| file | what |
|---|---|
| `questions.pdf` | the question paper (10 questions, 25 marks; printed marks in brackets) |
| `answers.pdf` | SYNTHETIC handwritten answer sheet, 3 ruled pages (clean scan) |
| `answers-photo-p1.jpg` | SYNTHETIC phone photo of answer page (rotation -1.8°, JPEG q72, 320835 bytes) |
| `answers-photo-p2.jpg` | SYNTHETIC phone photo of answer page (rotation +2.7°, JPEG q64, 353716 bytes) |
| `answers-photo-p3.jpg` | SYNTHETIC phone photo of answer page (rotation -2.4°, JPEG q71, 363189 bytes) |
| `per-question/q<n>/question.txt` | exact question text (symbols intact) |
| `per-question/q<n>/answer.jpg` | crop of that answer from the SYNTHETIC photo |
| `per-question/q<n>/answer.txt` | typed transcription of the SYNTHETIC answer (struck lines marked `[struck]`) |
| `key.json` / `key.md` | expected marking key (golden-set schema) with CBSE citations |
