# paper-01 - SYNTHETIC controller test paper (wave A-15, GRADER-CORE-1)

**Every answer file in this folder is SYNTHETIC**: the handwriting is rendered from fonts by `a15-papers-author`; no real student wrote it.
The questions are CBSE published items (see `key.md` for the paper, question number and page of every item and value point).

| `answers.pdf` | SYNTHETIC handwritten answer sheet, 4 ruled pages (clean scan) |
| `answers-photo-p1.jpg` | SYNTHETIC phone photo of answer page (rotation +1.4°, JPEG q72, 294776 bytes) |
