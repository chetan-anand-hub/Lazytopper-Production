# board-composite-38 - SYNTHETIC-COMPOSITE 38-question board paper (HOTFIX-2)

A stand-in for a full CBSE board paper, built to measure grading TIME on 38 questions.

| file | what |
|---|---|
| `answers.pdf` | ONE answer upload, **6 pages**: pages 1-4 = owner-anomaly-02's real handwritten answers (Q1-Q27, unchanged); pages 5-6 = SYNTHETIC answers re-rendered (Segoe UI) from controller paper-01 `per-question/q1..q10/answer.txt` as **Q28-Q37** and paper-02 `q4` as **Q38**. `⇒` is drawn as `→` (no glyph in the font). |
| `questions.pdf` | ONE question paper, 4 pages: owner-anomaly-02's 2 pages + Q28-Q38 rendered |
| `case.json` | the 38 questions; each reuses its SOURCE case id (`OA2-Qnn`, `CP01-Qnn-a`, `CP02-Q04-a`), so its expected marks are that case's own key. Q37 (paper-01 Q10) is an answer-mismatch case by design; Q29 carries the paper-01 injection line by design. |

Planned as `V2.W.BOARD.38` (lib/planner.cjs). Generated by `make_board_composite.py` (HOTFIX-2 builder tools).
