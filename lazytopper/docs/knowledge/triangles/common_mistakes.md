# Common Mistakes (Triangles)

## Similarity mistakes
- Stating similarity without naming AA/SAS/SSS.
- Mismatched correspondence (wrong order of vertices).

## BPT mistakes
- Applying BPT without parallel line.
- Forgetting to state the theorem before writing ratios.

## Pythagoras mistakes
- Using Pythagoras in non-right triangles.
- Squaring the wrong side.

## Presentation mistakes
- Missing “Given / To Prove / Proof / Conclusion”.
- No justification for each step.
