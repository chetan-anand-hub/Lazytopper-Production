# Solved Examples (Short)

## Similarity via AA
Given: ∠A = ∠P, ∠B = ∠Q.
Then ΔABC ~ ΔPQR by AA. Therefore AB/PQ = BC/QR = AC/PR.

## BPT setup
In ΔABC, if DE ∥ BC, then AD/DB = AE/EC (BPT). Use this ratio to solve the unknown.

## Pythagoras
Right triangle ABC, right angle at B: AC^2 = AB^2 + BC^2.
