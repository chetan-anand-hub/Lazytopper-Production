## Known pitfalls / DO NOT repeat (high priority)
- **PITFALL:** Windows PowerShell binary downloads — **DO NOT** use plain `'>'` redirection for ZIP/binary; it can corrupt files and break `Expand-Archive`.  
  Use cmd.exe redirection or PowerShell byte-safe output.
- **PITFALL:** `gh` flag drift — `gh api` has **no** `--output`; `gh run download` has **no** `--log`.  
  Use the API logs endpoint and byte-safe redirection.
- **PITFALL:** Evidence artifacts should **NOT** be committed to git. Keep RUN folders under GPT Codes/Reports and ignore patterns in `.gitignore`.
- **PITFALL:** In PowerShell, typing `filename.txt` runs it as a command. Use `Get-Content filename.txt` or `notepad filename.txt`.
