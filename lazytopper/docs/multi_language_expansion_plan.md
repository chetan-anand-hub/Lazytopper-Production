# Multi‑language Expansion Plan (S22)

This document summarises the multi‑language expansion strategy proposed in Task S22.  It outlines how to organise translation files, manage pluralisation and interpolation, select fonts and handle layout for scripts like Devanagari and Bengali, prioritise surfaces for localisation, and roll out languages in phases.  It also includes technical considerations for locale detection, translation hooks and fallback behaviour.

Refer to `LazyTopper_S22_Multi_Language_Expansion_Plan.md` in the repository root for the detailed plan.  When implementing new locales, follow the file structure, naming conventions and guidelines described there.
