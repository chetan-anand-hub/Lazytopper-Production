📝 Worked Example Step by Step
CuO + H₂ → Cu + H₂O
(Copper oxide + Hydrogen → Copper + Water)

📋 Step 1: Write the Reaction

We have the reaction: CuO + H₂ → Cu + H₂O

We need to identify which substance is oxidised and which is reduced.

🔥 Step 2: Find Oxidation

Look at Hydrogen (H₂):
→ On left: H₂ (no oxygen)
→ On right: H₂O (has oxygen!)
→ H₂ GAINED oxygen ∴ H₂ is OXIDISED (ऑक्सीकृत)

H₂ → Oxidised ⬆ O gained

❄️ Step 3: Find Reduction

Look at CuO (Copper oxide):
→ On left: CuO (has oxygen)
→ On right: Cu (oxygen removed!)
→ CuO LOST oxygen ∴ CuO is REDUCED (अपचयित)

CuO → Reduced ⬇ O lost

⚡ Step 4: Identify Agents

→ Oxidising Agent (ऑक्सीकारक): CuO — it oxidises H₂ (gives O to H₂)
→ Reducing Agent (अपचायक): H₂ — it reduces CuO (removes O from CuO)

⚠️ The oxidising agent is itself reduced!

✅ Step 5: Conclusion (निष्कर्ष)

This is a REDOX reaction (रेडॉक्स अभिक्रिया).
Oxidation & Reduction occur simultaneously.
H₂ is the reducing agent → gets oxidised
CuO is the oxidising agent → gets reduced

🎉 Both happen together!
