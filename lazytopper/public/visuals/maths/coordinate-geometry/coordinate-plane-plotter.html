📚 Step-by-Step: How to Read Coordinates

चतुर्थांश · Quadrants — Click to highlight

Quadrant I (प्रथम) x > 0, y > 0  ↗
Example: (3, 4), (2, 5)
Quadrant II (द्वितीय) x < 0, y > 0  ↖
Example: (-3, 4), (-1, 2)
Quadrant III (तृतीय) x < 0, y < 0  ↙
Example: (-2, -3), (-4, -1)
Quadrant IV (चतुर्थ) x > 0, y < 0  ↘
Example: (3, -2), (1, -4)
