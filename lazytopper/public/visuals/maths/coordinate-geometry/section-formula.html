📌 The Section Formula (अनुभाग सूत्र)

P(x, y) = ( mx₂ + nx₁ / m + n , my₂ + ny₁ / m + n )
∵ AP : PB = m : n Internal Division
Midpoint Formula: M = ( (x₁+x₂)/2 , (y₁+y₂)/2 )
💡 याद रखें: Point P divides line segment joining A(x₁,y₁) and B(x₂,y₂) internally in ratio m:n

Question: Find the coordinates of point P which divides the join of A(2, 1) and B(7, 6) in ratio 3:2.
1 Identify values:
A(x₁, y₁) = (2, 1), B(x₂, y₂) = (7, 6)
Ratio m : n = 3 : 2  ∴ m = 3, n = 2
2 Apply Section Formula:
x = (m·x₂ + n·x₁) / (m + n)
x = (3×7 + 2×2) / (3+2)
x = (21 + 4) / 5 = 25/5 = 5

y = (m·y₂ + n·y₁) / (m + n)
y = (3×6 + 2×1) / 5
y = (18 + 2) / 5 = 20/5 = 4
3 ∴ Result:
P = (5, 4)
Point P(5,4) divides A(2,1) and B(7,6) in ratio 3:2 ✓
Verify: AP = √(9+9) = 3√2, PB = √(4+4) = 2√2 → ratio = 3:2 ✓
Question: Find the ratio in which point P(4, 5) divides the line segment joining A(1, 2) and B(7, 8).
1 Let ratio = k : 1
A(1,2), B(7,8), P(4,5)
Using section formula: x = (k·x₂ + 1·x₁)/(k+1)
2 Substitute x-coordinate:
4 = (k×7 + 1×1)/(k+1)
4(k+1) = 7k + 1
4k + 4 = 7k + 1
3 = 3k  ∴ k = 1
3 ∴ Ratio = k : 1 = 1 : 1
P is the midpoint of AB!
Verify y: (1×8 + 1×2)/(1+1) = 10/2 = 5 ✓
Midpoint Formula (मध्य बिंदु सूत्र):
When ratio m:n = 1:1, P becomes midpoint M

M = ( (x₁+x₂)/2 , (y₁+y₂)/2 )
Q Find midpoint of A(3, 4) and B(9, 2).
M = ((3+9)/2, (4+2)/2)
✓ M = (12/2, 6/2) = (6, 3)
Midpoint of A(3,4) and B(9,2) is M(6,3)

🔑 Key Points to Remember

✅ Internal Division — Point lies between the two points
✅ Section formula: P = ( (mx₂+nx₁)/(m+n) , (my₂+ny₁)/(m+n) )
✅ For midpoint: put m = n = 1 in section formula
✅ To find ratio: assume ratio = k:1, solve for k
✅ ∴ If k is positive → internal division; if negative → external
📝 CBSE Exam Tip: Always write the formula first in board exams. Show each calculation step clearly. Use x-coordinate or y-coordinate equation to find ratio k.
