📐 सूत्र (Formula) — याद रखें!
Area = ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|
∵ vertices: A(x₁,y₁), B(x₂,y₂), C(x₃,y₃)  |  | | = absolute value

📌 Worked Example — CBSE Style

Find area of △ABC with: A(2, 3), B(−1, 0), C(2, −4)
📖 Click each step to reveal (क्रमशः खोलें):
1
Write down the coordinates (निर्देशांक लिखें)
▼

Given vertices of △ABC:

x₁ = 2, y₁ = 3   → A(2, 3)
x₂ = −1, y₂ = 0   → B(−1, 0)
x₃ = 2, y₃ = −4   → C(2, −4)
2
Apply the formula (सूत्र लगाएं)
▼
Area = ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|

Substitute values:

= ½ |2(0 − (−4)) + (−1)((−4) − 3) + 2(3 − 0)|
3
Simplify brackets (सरल करें)
▼
= ½ |2(4) + (−1)(−7) + 2(3)|
= ½ |8 + 7 + 6|
= ½ |21|
4
∴ Final Answer (उत्तर)
▼
Area = ½ × 21 = 10.5 sq. units

∴ क्षेत्रफल = 21/2 square units

✅ Since Area ≠ 0, points are NOT collinear (एक रेखीय नहीं हैं)

💡 Key Concepts (मुख्य बातें)

Collinearity Test: If Area = 0, the three points are collinear (एक रेखीय)! This is a powerful use of this formula.
Sign Rule: We take absolute value | | because area is always positive (धनात्मक). The formula inside can give negative value depending on vertex order.
Unit: Area is in square units (वर्ग इकाई). If coordinates are in cm, area = cm².
