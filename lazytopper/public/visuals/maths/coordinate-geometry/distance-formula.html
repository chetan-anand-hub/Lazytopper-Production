Distance Formula — दूरी सूत्र

Class 10 • Coordinate Geometry
Distance Formula | दूरी सूत्र
d = √[ (x₂−x₁)² + (y₂−y₁)² ]
∵ Based on Pythagoras Theorem | पाइथागोरस प्रमेय पर आधारित

📖 Pythagoras Connection | प्रमेय से जोड़

∵ Why does this formula work?
The horizontal distance = |x₂ − x₁| (Base)
The vertical distance = |y₂ − y₁| (Perpendicular)
∴ By Pythagoras: d² = Base² + Perp² → d = √[(x₂−x₁)² + (y₂−y₁)²]

🔢 Worked Example — हल किया उदाहरण

❓ Find the distance between A(3, 4) and B(7, 1)
Step 1 — चरण १
Identify the coordinates:
x₁ = 3, y₁ = 4    x₂ = 7, y₂ = 1
Step 2 — चरण २
Apply the Distance Formula:
d = √[ (x₂−x₁)² + (y₂−y₁)² ]
Step 3 — चरण ३
Substitute the values:
d = √[ (7−3)² + (1−4)² ]
Step 4 — चरण ४
Calculate the differences:
d = √[ (4)² + (−3)² ] = √[ 16 + 9 ]
Step 5 — चरण ५ ✅
∴ Final Answer:
d = √25 = 5 units

💡 Special Cases — विशेष मामले

Same Y-axis
y₁ = y₂ (Horizontal Line)
d = |x₂ − x₁|
Only horizontal gap matters
Same X-axis
x₁ = x₂ (Vertical Line)
d = |y₂ − y₁|
Only vertical gap matters
Distance from Origin | मूल बिंदु से दूरी
d = √(x² + y²)
∵ Origin O = (0, 0), so x₁=0, y₁=0
