📖 What is Collinearity? Key Concept
Three points A(x₁,y₁), B(x₂,y₂) and C(x₃,y₃) are called collinear if they all lie on the same straight line — i.e., they do not form a triangle.

Condition: Area of triangle formed by A, B, C = 0
Area = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)| = 0
If Area = 0 → Points are Collinear | If Area ≠ 0 → Not Collinear

🧮 Two Methods to Check Collinearity
Area = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|
Set Area = 0 to find collinearity condition
If Area = 0, the three points are collinear. This is the most commonly used method for Class 10.
Slope AB = Slope BC → (y₂−y₁)/(x₂−x₁) = (y₃−y₂)/(x₃−x₂)
If slopes of any two pairs of segments are equal, points are collinear
If the slope from A to B equals the slope from B to C, all three points lie on the same line.
📋 Worked Example

Q: Check if A(1,1), B(2,3), C(3,5) are collinear.

1
Write down coordinates: A(1,1), B(2,3), C(3,5)
2
Apply area formula:
Area = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|
3
Substitute values:
= ½ |1(3−5) + 2(5−1) + 3(1−3)|
4
Simplify each bracket:
= ½ |1(−2) + 2(4) + 3(−2)| = ½|−2 + 8 − 6|
5
Final result:
= ½|0| = 0 → ∴ Points are COLLINEAR ✅
