📊 Complementary Events — संपूरक घटनाएँ

CBSE Class 10 Mathematics | Chapter: Probability (प्रायिकता)

🔑 Core Concept & Formula

For any event E and its complement not-E (E̅):
P(E) + P(not-E) = 1
∴ P(not-E) = 1 − P(E)
where  0 ≤ P(E) ≤ 1  &  0 ≤ P(not-E) ≤ 1
✅

Certain Event (निश्चित घटना)

P(E) = 1
P(not-E) = 0

❌

Impossible Event (असंभव घटना)

P(E) = 0
P(not-E) = 1

📝 Worked Example — Step by Step

Question: A bag contains 5 red, 3 blue, and 2 green balls. One ball is drawn at random.
If E = event of drawing a red ball, find P(not-E).
  • 1
    Find Total outcomes:
    Total balls = 5 + 3 + 2 = 10
    ∴ n(S) = 10
  • 2
    Find P(E) — Red ball:
    Favourable outcomes = 5 (red balls)
    P(E) = 5/10 = 1/2 = 0.5
  • 3
    Apply complement formula:
    P(not-E) = 1 − P(E)
    P(not-E) = 1 − 1/2 = 1/2 = 0.5
  • 4
    Verify ✓:
    P(E) + P(not-E) = 1/2 + 1/2 = 1 ✓
    (not-E = drawing blue or green ball)

📌 Key Points to Remember

✅ P(E) + P(not-E) = 1  Always
✅ P(not-E) = 1 − P(E)  Complement Rule
✅ Probability always lies between 0 and 1 inclusive
✅ P = 0 → Impossible event (असंभव घटना)
✅ P = 1 → Certain event (निश्चित घटना)
✅ E and E̅ together cover the entire sample space
✅ P(not-E) is also written as P(E̅) or P(Eᶜ)
∵ P(E) + P(E̅) = 1  ∴ P(E̅) = 1 − P(E)
