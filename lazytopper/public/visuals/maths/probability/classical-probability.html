🎲 Classical Probability

CBSE Class 10 Mathematics – Interactive Explainer

📐 Core Formula
P(E) = n(E) / n(S)
Favorable Outcomes ÷ Total Equally Likely Outcomes  |  0 ≤ P(E) ≤ 1

📚 Key Definitions

Experiment
An action with a well-defined set of results (e.g. tossing a coin)
Sample Space S
Set of ALL possible outcomes. |S| = n(S)
Event E
A subset of sample space. Favorable outcomes = n(E)
Equally Likely
Each outcome has the same chance of occurring
Certain Event
P(E) = 1 — always happens
Impossible Event
P(E) = 0 — can never happen
