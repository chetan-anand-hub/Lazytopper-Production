📐 Euclid's Division Lemma (प्रमेय)

🔑 मुख्य सूत्र | Key Formula

a = b × q + r
Given two positive integers a and b, there exist unique integers q and r such that the above holds, where 0 ≤ r < b
📦 a = Dividend (भाज्य)
➗ b = Divisor (भाजक)
🔢 q = Quotient (भागफल)
🔵 r = Remainder (शेषफल)

🎯 Goal: Find HCF of 135 and 12 using Euclid's Division Algorithm
∵ We keep applying a = b×q + r until r = 0
🎯 Goal: Find HCF of 56 and 98
∵ Since 98 > 56, we start with a=98, b=56
🎯 Goal: Find HCF of 867 and 255
∵ 867 > 255, so a=867, b=255

📋 Important Rules | याद रखो

✅ 0 ≤ r < b always
✅ a, b are positive integers
✅ q and r are unique
✅ If r=0, then b = HCF(a,b)
✅ HCF(a,b) = HCF(b,r)
🔄 Algorithm Steps | एल्गोरिथ्म के चरण:
Step 1: Apply lemma to a and b → find q and r
Step 2: If r = 0, then HCF = b (STOP ∴)
Step 3: If r ≠ 0, replace a←b and b←r, go to Step 1
💡 CBSE Tip: Always write the division equation a = b×q + r clearly for each step. The last non-zero remainder is the HCF!
