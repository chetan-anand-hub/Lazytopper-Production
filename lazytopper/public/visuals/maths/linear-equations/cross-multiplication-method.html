📋 The Cross Multiplication Formula

वज्र गुणन सूत्र (Cross Multiplication Formula)

For: a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0
x  =  b₁c₂ − b₂c₁  ÷  a₁b₂ − a₂b₁
y  =  c₁a₂ − c₂a₁  ÷  a₁b₂ − a₂b₁
COMPACT FORM (सघन रूप)
x/(b₁c₂−b₂c₁) = y/(c₁a₂−c₂a₁) = 1/(a₁b₂−a₂b₁)

⚠️ Important Condition (महत्वपूर्ण शर्त)
The solution is valid only when: a₁b₂ − a₂b₁ ≠ 0
If a₁b₂ − a₂b₁ = 0 → lines are parallel OR coincident (कोई अद्वितीय हल नहीं)
