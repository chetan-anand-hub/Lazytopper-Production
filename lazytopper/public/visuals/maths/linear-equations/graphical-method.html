📊 Types of Solutions (हल के प्रकार)

✂️ Intersecting Lines

Condition: a₁/a₂ ≠ b₁/b₂
Solution: Unique (एकमात्र हल)
Graph: Lines cross at one point
Consistent system (संगत)

↔️ Parallel Lines

Condition: a₁/a₂ = b₁/b₂ ≠ c₁/c₂
Solution: No solution (कोई हल नहीं)
Graph: Lines never meet
Inconsistent system (असंगत)

🔗 Coincident Lines

Condition: a₁/a₂ = b₁/b₂ = c₁/c₂
Solution: Infinite (अनंत हल)
Graph: Lines overlap completely
Dependent system (आश्रित)

📝 Worked Example (हल किया गया उदाहरण)

Problem: Solve graphically: x − 2y = 0 and 3x + 4y = 20

Equation 1: x − 2y = 0 → y = x/2

Make a table for Eq 1 (y = x/2):

x = 0 → y = 0  |  x = 2 → y = 1  |  x = 4 → y = 2
Equation 2: 3x + 4y = 20 → y = (20−3x)/4

Make a table for Eq 2:

x = 0 → y = 5  |  x = 4 → y = 2  |  x = 8 → y = −1

Plot both lines. They intersect at (4, 2).

∴ Solution: x = 4, y = 2 ✓

Verification: 4−2(2)=0 ✓ and 3(4)+4(2)=12+8=20 ✓
