✕ Elimination Method | विलोपन विधि

CBSE Class 10 · Pair of Linear Equations in Two Variables

Core Idea · मूल अवधारणा
Make coefficients equal → Add/Subtract → Cancel one variable!
गुणांक बराबर करो → जोड़ो/घटाओ → एक चर को विलुप्त करो!
💡 Key Idea: If two terms are equal and opposite (like +3y and −3y), they cancel out when added. We use this to eliminate one variable and find the other!
× Multiply equations + Add to eliminate ÷ Solve one variable
Worked Example · हल किया उदाहरण
E₁ 2x + 3y = 11
E₂ 3x − 2y = 1

👆 Click each step to reveal · प्रत्येक चरण पर क्लिक करें

1
Choose variable to eliminate
▶

We want to eliminate y. Find LCM of y's coefficients: LCM(3, 2) = 6

E₁ has 3y → multiply E₁ by 2
E₂ has 2y → multiply E₂ by 3

∴ Both equations will have 6y — then we can subtract to cancel!

2
Multiply equations to match coefficients
▶

Multiply E₁ by 2:

2×(2x + 3y = 11) → 4x + 6y = 22 ... (E₃)

Multiply E₂ by 3:

3×(3x − 2y = 1) → 9x − 6y = 3 ... (E₄)

✅ Now both have 6y (one +6y, one −6y)

3
Add equations — y gets eliminated! ✕
▶
4x + 6y = 22 (E₃)
+ 9x − 6y = 3 (E₄)
13x + 0y = 25

+6y and −6y cancel! ∴ 13x = 25

4
Solve for x
▶
13x = 25
x = 25 ÷ 13
∴ x = 25/13

Wait — let's use a nicer example! Trying x values in original: x = 2 ✓ (see step 5)

5
Substitute back to find y
▶

Put x = 25/13 in E₁: 2x + 3y = 11

2(25/13) + 3y = 11
50/13 + 3y = 11
3y = 11 − 50/13 = (143−50)/13 = 93/13
y = 93/39 = 31/13
✅ Answer: x = 25/13, y = 31/13

Verify in E₂: 3(25/13) − 2(31/13) = 75/13 − 62/13 = 13/13 = 1 ✓
