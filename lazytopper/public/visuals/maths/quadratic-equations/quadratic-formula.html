🔑 The Quadratic Formula – श्रीधराचार्य सूत्र

Named after Indian mathematician Shridharacharya (श्रीधराचार्य), ~9th century CE

x = −b ± √b²−4ac
──────────────────
2a
Roots of ax² + bx + c = 0  |  मूल
1
Start: ax² + bx + c = 0  (शुरुआत)
Divide every term by a
x² + (b/a)x + c/a = 0
2
Move constant: x² + (b/a)x = −c/a  (अचर पद स्थानांतरण)
3
Complete the Square (पूर्ण वर्ग बनाओ):
Add (b/2a)² to both sides:
x² + (b/a)x + (b/2a)² = (b/2a)² − c/a
⟹ (x + b/2a)² = (b²−4ac)/4a²
4
Take Square Root (वर्गमूल):
x + b/2a = ±√(b²−4ac) / 2a
5
Final Formula (अंतिम सूत्र):
x = (−b ± √(b²−4ac)) / 2a ✓

🔢 Discriminant – विविक्तकर

D = b² − 4ac
Also written as Δ (Delta) · विविक्तकर (Viviktkar)

Click each case to learn more · जानने के लिए क्लिक करें

✌️
D > 0
2 Real Roots
D > 0 means two distinct real roots (दो अलग वास्तविक मूल).
The parabola cuts x-axis at 2 points.
☝️
D = 0
1 Repeated Root
D = 0 means one equal real root (एक समान वास्तविक मूल).
The parabola just touches x-axis.
🚫
D < 0
No Real Roots
D < 0 means no real roots (कोई वास्तविक मूल नहीं).
The parabola doesn't cross x-axis.

💡 Key Tips – महत्वपूर्ण बातें

① Always write in standard form ax²+bx+c=0 first.
पहले व्यापक रूप में लिखें
② Calculate D (b²−4ac) before finding roots.
मूल निकालने से पहले D पता करें
③ Remember ± gives TWO roots (α and β).
± से दो मूल मिलते हैं (α और β)
④ Check: Sum of roots = −b/a, Product = c/a
मूलों का योग = −b/a, गुणनफल = c/a
