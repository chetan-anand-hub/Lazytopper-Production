मूल सूत्र (Key Formula)
For ax² + bx + c = 0
D = b² − 4ac
x = (−b ± √D) / 2a
D = विवेचक (Discriminant)
D > 0
✅ Real & Distinct
दो अलग वास्तविक मूल
D = 0
🟡 Real & Equal
दो बराबर वास्तविक मूल
D < 0
❌ No Real Roots
कोई वास्तविक मूल नहीं
