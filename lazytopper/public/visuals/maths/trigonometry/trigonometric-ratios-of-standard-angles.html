✏️ Worked Example (हल किया उदाहरण)

Find the value of: 2sin²30° + cos²45° − tan²60°

STEP 1 — Write known values
From the table, substitute standard values:
sin 30° = ½,  cos 45° = 1/√2,  tan 60° = √3
STEP 2 — Square each value
Calculate squares of each:
sin²30° = (½)² = ¼,  cos²45° = (1/√2)² = ½,  tan²60° = (√3)² = 3
STEP 3 — Substitute in expression
Put values in the expression:
= 2×(¼) + ½ − 3
STEP 4 — Simplify
Calculate step by step:
= ½ + ½ − 3 = 1 − 3 = −2 ✓
∴ ANSWER
The value of the expression is:
2sin²30° + cos²45° − tan²60° = −2
