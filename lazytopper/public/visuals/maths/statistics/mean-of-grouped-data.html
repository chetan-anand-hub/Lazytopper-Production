THREE METHODS TO FIND MEAN
Direct: x̄ = Σfᵢxᵢ / Σfᵢ
Assumed: x̄ = a + (Σfᵢdᵢ / Σfᵢ)
Step-Dev: x̄ = a + h·(Σfᵢuᵢ / Σfᵢ)
where dᵢ = xᵢ – a  |  uᵢ = dᵢ/h = (xᵢ – a)/h  |  a = assumed mean  |  h = class width
📌 Grouped Data — When data is large, it is organised into class intervals. We use the mid-point (xᵢ) of each class as a representative value. Frequency (fᵢ) tells how many observations fall in that class.
🔵 Direct Method Basic

Calculate mid-point xᵢ for each class. Multiply with fᵢ to get fᵢxᵢ. Sum all fᵢxᵢ and divide by Σfᵢ. Simple but tedious with large numbers.

🟢 Assumed Mean Shorter

Choose a convenient assumed mean 'a'. Find deviation dᵢ = xᵢ – a. Calculate Σfᵢdᵢ. Then x̄ = a + Σfᵢdᵢ/Σfᵢ. Numbers are smaller!

🟠 Step-Deviation Shortest

Divide dᵢ by class width h to get uᵢ = (xᵢ–a)/h. Numbers become even smaller. x̄ = a + h·Σfᵢuᵢ/Σfᵢ. Best for equal class widths.

💡 Key Insight: All three methods give the same answer! Step-Deviation is preferred when class widths are equal and numbers are large.
