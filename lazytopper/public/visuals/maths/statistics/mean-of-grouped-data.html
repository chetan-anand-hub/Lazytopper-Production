🎯 What is Mean? माध्य

Mean (माध्य) is the average of all data values. For grouped data, we cannot see individual values — only class intervals and frequencies. CBSE teaches 3 methods to find mean.

📌 Direct Method
🔧 Assumed Mean
⚡ Step Deviation
📐 Three Methods — Formula Comparison
x̄ = Σ(fᵢ × xᵢ) ÷ Σfᵢ
where xᵢ = midpoint of class, fᵢ = frequency

Steps: Find midpoint xᵢ for each class → Multiply fᵢ × xᵢ → Sum both columns → Divide

x̄ = a + (Σfᵢdᵢ ÷ Σfᵢ)
where a = Assumed Mean, dᵢ = xᵢ − a

Steps: Choose middle class → Set a = its midpoint → Find dᵢ = xᵢ − a → Compute fᵢdᵢ → Apply formula

x̄ = a + h × (Σfᵢuᵢ ÷ Σfᵢ)
where uᵢ = (xᵢ − a) ÷ h, h = class width

Steps: Choose a → Find dᵢ = xᵢ − a → Divide by h to get uᵢ → Compute fᵢuᵢ → Apply formula

Mean Marks by Direct Method ✅
1Choose Assumed Mean (a)
कल्पित माध्य चुनें — Pick middle class midpoint.
Middle class = 30–40, so a = 35
∵ This reduces deviation values
2Find dᵢ = xᵢ − a
xᵢfᵢdᵢ = xᵢ−35fᵢdᵢ

Mean by Assumed Mean Method ✅ Same Answer!
1Choose a = 35, h = 10 (class width)
पग विचलन: uᵢ = (xᵢ − a) ÷ h
h = 10 (each class is 10 wide)
2Calculate uᵢ and fᵢuᵢ
xᵢfᵢuᵢ=(xᵢ−35)÷10fᵢuᵢ
156(−20)÷10=−26×(−2)=−12
258(−10)÷10=−18×(−1)=−8
35150÷10=015×0=0
451210÷10=112×1=12
55920÷10=29×2=18
Σfᵢ=50—Σfᵢuᵢ=10
3Apply Formula
x̄ = a + h × (Σfᵢuᵢ ÷ Σfᵢ)
x̄ = 35 + 10 × (10 ÷ 50)
x̄ = 35 + 10 × 0.2
x̄ = 35 + 2 = 37
x̄ = 37

🔑 Key Points to Remember
📌 All 3 methods give SAME mean
∴ Direct = Assumed Mean = Step Deviation
📌 Midpoint Formula: xᵢ = (Lower limit + Upper limit) ÷ 2
📌 Assumed Mean (a): Choose midpoint of the class with highest frequency (modal class) for easiest calculation
📌 Step Deviation: h = class size (must be equal for all classes to use this method)
