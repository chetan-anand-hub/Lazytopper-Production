📊 Mode of Grouped Data | बहुलक

CBSE Class 10 • Statistics • Interactive Visual Explainer

✦ The Key Formula (CBSE Class 10) ✦
Mode = ℓ + [ (f₁ − f₀) / (2f₁ − f₀ − f₂) ] × h
ℓ = Lower boundary of modal class  |  h = Class width
f₁ = Frequency of modal class  |  f₀ = Frequency before modal class
f₂ = Frequency after modal class

💡 What is Mode? | बहुलक क्या है?

Mode (बहुलक) is the value that appears most frequently in a dataset. For grouped data, we first find the Modal Class — the class interval with the highest frequency.
