📊 Mode of Grouped Data

CBSE Class 10 Mathematics • Statistics • बहुलक

🎯 Concept Overview

Mode (बहुलक) is the value that appears most frequently in data. For grouped data, we cannot find the exact mode directly — we use a formula based on the Modal Class (the class with the highest frequency).

💡 Modal Class = The class interval with the maximum frequency
📐 The Formula
Mode = ℓ + ( f₁ − f₀ ) × h
             ─────────────────
             ( 2f₁ − f₀ − f₂ )
ℓ
Lower limit of modal class
h
Class size (width)
f₁
Frequency of modal class
f₀
Frequency of class before modal class
f₂
Frequency of class after modal class

🔢 Step-by-Step Solution

Click each step to reveal the solution:

1 Look for the class with the highest frequency.
From our table: 40–50 has frequency 28 — the highest!
∴ Modal Class = 40–50
2 From the modal class 40–50:
• ℓ = 40 (lower limit of modal class)
• h = 10 (class size = 50 − 40)
• f₁ = 28 (frequency of modal class)
• f₀ = 20 (frequency of class before: 30–40)
• f₂ = 14 (frequency of class after: 50–60)
3 Mode = ℓ + (f₁ − f₀) ÷ (2f₁ − f₀ − f₂) × h

= 40 + (28 − 20) ÷ (2×28 − 20 − 14) × 10
= 40 + 8 ÷ (56 − 20 − 14) × 10
= 40 + 8 ÷ 22 × 10
= 40 + 0.3636 × 10
= 40 + 3.636
4 ∴ Mode ≈ 43.64

This means the most common marks scored by students fall around 43.64.
∴ बहुलक ≈ 43.64

⚠️ f₁ must be greater than f₀ and f₂ for a valid modal class!
🧠 Exam Tips & Common Mistakes
✅ Always check that f₁ > f₀ and f₁ > f₂ — confirming it IS the modal class
⚠️ f₀ = frequency of class immediately before modal class (NOT the smallest)
❌ Common mistake: Using total frequency instead of f₁, f₀, f₂. Only 3 adjacent classes are used!
