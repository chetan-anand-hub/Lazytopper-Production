सूत्र Median Formula | मध्यिका सूत्र

Median = l + [ (n/2 − cf) / f ] × h
मध्यिका = l + [ (n/2 − cf) / f ] × h
l — Lower Limit
n — Total Frequency
cf — Cumulative Freq.
f — Class Frequency
h — Class Width

याद रखें Key Concepts to Remember

📌 Median Class (मध्यिका वर्ग)The class where cumulative frequency first exceeds n/2
📌 cf (पूर्व संचयी बारंबारता)Cumulative frequency of class BEFORE the median class
📌 l (निम्न सीमा)Lower class boundary of the median class
📌 h (वर्ग चौड़ाई)Class width = Upper limit − Lower limit
⚠️ Important: Median divides the distribution into exactly two equal halves. It is NOT affected by extreme values (outliers)!
