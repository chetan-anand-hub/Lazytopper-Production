📐 The Median Formula | माध्यिका सूत्र
Key Formula
Median = l + [ (n/2 − cf) ÷ f ] × h
∴ माध्यिका = l + [ (n/2 − cf) / f ] × h
lLower boundary of median class (माध्यिका वर्ग की निचली सीमा)
nTotal frequency (कुल बारंबारता)
cfCumulative frequency before median class (पूर्व संचयी बारंबारता)
fFrequency of median class (माध्यिका वर्ग की बारंबारता)
hClass width / size (वर्ग की चौड़ाई)
💡 Intuition: We know the median lies in a specific class. We use interpolation to pinpoint its exact value within that class using the cumulative frequency.

Grouped Data Cumulative Frequency Median Class Interpolation
📦 Grouped Data: When data is large, it's organized into class intervals (e.g., 0–10, 10–20…). We don't know individual values, so we use formulas to estimate median.
➕ Cumulative Frequency (संचयी बारंबारता): Running total of frequencies. For each class, add all previous frequencies to get cf. It tells us "how many values lie below this class's upper boundary."
🎯 Median Class: Find n/2. The class whose cumulative frequency first exceeds n/2 is the median class. The actual median lies somewhere inside this class.
📏 Interpolation: We assume values are uniformly distributed within each class. The formula calculates exactly how far into the median class the median lies, proportionally.

Problem: Find the median of the following frequency distribution of marks obtained by 50 students.

👆 Hover rows to explore. The Median Class is highlighted in amber.
Step 1
Find n and n/2
Add all frequencies to get the total count n. Then compute n/2 to find the median position.
n = 5+8+12+15+7+3 = 50
n/2 = 50/2 = 25
Step 2
Identify the Median Class
Find the class whose cumulative frequency first exceeds n/2 = 25.
CF up to 20–30 = 25 (not exceeded yet)
CF up to 30–40 = 40 ✓ (first to exceed 25)
∴ Median Class = 30 – 40 Median Class
Step 3
Identify the Values from Median Class
Extract all required values from the median class and its predecessor:
l = 30 (lower boundary of 30–40)
f = 15 (frequency of 30–40)
cf = 25 (CF of previous class 20–30)
h = 10 (class width = 40−30)
n/2 = 25
Step 4
Apply the Formula
Substitute all values into the median formula:
Median = l + [(n/2 − cf) ÷ f] × h
= 30 + [(25 − 25) ÷ 15] × 10
= 30 + [0 ÷ 15] × 10
= 30 + 0 × 10
= 30
Final Answer ✓
∴ Median = 30 marks
The median marks = 30. This means 50% of students scored less than 30 and 50% scored more than 30 marks.

✅ Key Points to Remember | याद रखें
  • Median divides the distribution into two equal halves
  • Always calculate cumulative frequency (संचयी बारंबारता) first
  • Median class = class where CF first ≥ n/2
  • l = lower class boundary (not lower class limit for exclusive classes)
  • The ogive (less than type) gives median at y = n/2
  • ∴ Median = l + [(n/2 − cf) / f] × h
