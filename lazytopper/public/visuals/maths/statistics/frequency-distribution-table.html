📖 What is a Frequency Distribution Table? Key Concept
A Frequency Distribution Table organises raw data into class intervals and shows how many data values (frequency) fall in each class.

Class Width (h) = Upper Boundary − Lower Boundary  |  Midpoint (xᵢ) = (Lower + Upper) / 2

🔢 Build a Table Step-by-Step
1Collect raw data — list all values (e.g., scores of students).
2Decide class width (h) — divide range by number of classes. Example: Range 0–60, 6 classes → h = 10.
3Tally each value — go through data and put a mark in the correct class row.
4Count tallies → Frequency (fᵢ) — total marks per row = frequency of that class.
5Cumulative Frequency — add each frequency to the running total. Last CF = Σfᵢ (total observations).
6Find Midpoint — xᵢ = (Lower + Upper) / 2. Used later to calculate Mean.
