💡 What is an Ogive? Concept

An Ogive (ओजाइव) is a smooth curve drawn by plotting cumulative frequencies against class limits. It helps us find median, quartiles, and percentiles graphically.

📌 Two types: Less-Than Ogive (≤) — uses upper class limits  |  More-Than Ogive (≥) — uses lower class limits

KEY FORMULAS — सूत्र
Cumulative Frequency (c.f.) = Sum of all previous frequencies
Median = value where Less-Than & More-Than Ogives intersect ✕
N/2 th observation → draw horizontal line → drop to x-axis → Median

📉 Less-Than Ogive

  • Plot (upper limit, c.f.)
  • Starts from lower left
  • Curves upward (∪ shape)
  • Total c.f. = N

📈 More-Than Ogive

  • Plot (lower limit, c.f.)
  • Starts from upper left
  • Curves downward (∩ shape)
  • Starts with c.f. = N

🪜 Step-by-Step: How to Draw Ogive Walkthrough

Click each step to reveal — एक-एक कदम समझें:

Step 1 — डेटा तैयार करें

Arrange data in a frequency distribution table with class intervals and frequencies. Find N = Σf = 50 (total students).

Step 2 — संचयी आवृत्ति (Less-Than)

Add frequencies cumulatively from top: 3, 3+5=8, 8+9=17, 17+12=29, 29+10=39, 39+7=46, 46+4=50

Plot points: (upper class limit, cumulative frequency) → (10,3), (20,8), (30,17)...

Step 3 — संचयी आवृत्ति (More-Than)

Subtract frequencies from N cumulatively from bottom: 50, 50-3=47, 47-5=42, 42-9=33...

Plot points: (lower class limit, cumulative frequency) → (0,50), (10,47), (20,42)...

Step 4 — ग्राफ बनाएं

On graph paper: X-axis = Class limits (marks), Y-axis = Cumulative Frequency (0 to N=50)

Plot all points and join them with a smooth curve (फ्रीहैंड) — not straight lines!

Step 5 — माध्य (Median) निकालें

Calculate N/2 = 50/2 = 25

Method 1: Draw horizontal line from y = 25 → meets Less-Than Ogive → drop vertical → read x-value → Median

Method 2: Intersection point of both curves → drop vertical → Median ≈ 37 marks

Step 6 — सत्यापन (Verify)

Cross-check using formula: Median = L + [(N/2 - cf) / f] × h

Median class (where c.f. ≥ 25) = 30–40, L=30, cf=17, f=12, h=10

Median = 30 + [(25-17)/12] × 10 = 30 + 6.67 = ≈ 36.67 ✓

⭐ Key Points to Remember CBSE Tips

✅ Ogive is always a smooth S-shaped curve — never join with straight lines

✅ Less-Than Ogive: plot (upper limit, c.f.) | More-Than: plot (lower limit, c.f.)

✅ Both ogives intersect at exactly one point → its x-coordinate = Median

✅ N/2 line method & intersection method give the same answer

✅ Total cumulative frequency always = N (sum of all frequencies)

✅ In CBSE exams: Always label axes, write scale, and mark the median clearly 📝
