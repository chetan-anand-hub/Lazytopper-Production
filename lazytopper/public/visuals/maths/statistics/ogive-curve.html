💡 What is an Ogive? (ओजाइव क्या है?)

An Ogive (pronounced oh-jive) is a graph of Cumulative Frequency (संचयी बारंबारता) plotted against class boundaries. It is a smooth S-shaped curve used to find Median, Quartiles and other values graphically.

🔢 Key Formulas (सूत्र)
Median using Ogive
N/2 → Draw horizontal line → Drop perpendicular → Read Median
Median Formula (for verification)
Median = ℓ + [(N/2 − cf) / f] × h
ℓ = lower limit of median class | cf = preceding cumulative frequency
f = frequency of median class | h = class width (वर्ग चौड़ाई)
∴ N/2 = 50/2 = 25
Median class: 30–40
(cf before = 25, cf after = 40)
ℓ=30, cf=25, f=15, h=10
Median = 30 + [(25−25)/15]×10
= 30 + 0 = 30
🪜 Step-by-Step Walkthrough (चरण-दर-चरण)

Click each step to reveal the solution process:

Step 1 — Find N/2 (N का आधा)
Total frequency N = 50
∴ N/2 = 50/2 = 25
We need to find the value where cumulative frequency = 25
Step 2 — Draw Less Than Ogive
Plot points: (10,5), (20,13), (30,25), (40,40), (50,46), (60,50)
Join with smooth curve → S-shaped upward curve ✓
Step 3 — Draw More Than Ogive
Plot points: (0,50), (10,45), (20,37), (30,25), (40,10), (50,4)
Join with smooth curve → Inverted S-curve ✓
Step 4 — Draw Horizontal Line at N/2 = 25
From Y-axis at 25, draw a horizontal line → It meets the Less Than Ogive
From that intersection, drop a perpendicular to X-axis
Step 5 — Read the Median (माध्यिका पढ़ें)
The perpendicular meets X-axis at x = 30
∴ Median (माध्यिका) = 30
Also: both curves INTERSECT at (30, 25) — this point directly gives Median! 🎯

🎯 Key Points to Remember (याद रखें)
📌 Less Than Ogive
Plotted using Upper class boundaries vs Cumulative Frequency. Starts from 0, rises to N. Shape: ∫
📌 More Than Ogive
Plotted using Lower class boundaries vs Cumulative Frequency. Starts from N, falls to 0. Shape: ∫ inverted
📌 Median from Ogive
The X-coordinate of the intersection point of both ogives gives the Median directly! ∴ Median = x at intersection
📌 Quartiles (चतुर्थक)
Q₁ at N/4, Q₃ at 3N/4 on Y-axis → drop perpendicular to X-axis from Less Than Ogive
