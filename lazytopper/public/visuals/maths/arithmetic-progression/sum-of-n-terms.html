CBSE Class 10 Mathematics | समांतर श्रेढ़ी का योग | Interactive Visual Explainer

📌 मुख्य सूत्र (Key Formula)
Sum of first n terms of an AP (समांतर श्रेढ़ी का योग)
Sₙ = n⁄₂ × (2a + (n−1)d)
— also written as —
Sₙ = n⁄₂ × (a + l)
where l = last term (aₙ)
n = number of terms (पदों की संख्या)
a = first term (प्रथम पद)
d = common difference (सार्व अंतर)
l = last term (अंतिम पद)

💡 गॉस की युक्ति (Gauss's Trick) — Why the Formula Works

Write the sum forwards AND backwards, then add pairs! Each pair sums to (a + l), and there are n such pairs → Total = n×(a+l), divide by 2 ∴ Sₙ = n/2 × (a+l)

∴ 2Sₙ = n × (a+l)  →  Sₙ = n/2 × (a+l)

❓ Find the sum of first 10 terms of AP: 5, 8, 11, 14, ...
Step 1 — Identify Values
From the AP: 5, 8, 11, 14, ...
a = 5,   d = 8−5 = 3,   n = 10
Step 2 — Find Last Term (l)
l = aₙ = a + (n−1)d
l = 5 + (10−1)×3 = 5 + 27 = 32
Step 3 — Apply Formula
Sₙ = n/2 × (a + l)
S₁₀ = 10/2 × (5 + 32) = 5 × 37 = 185
✅ Verification (Using 2a+(n-1)d formula)
S₁₀ = 10/2 × (2×5 + 9×3) = 5 × (10+27) = 5 × 37 = 185 ✓
❓ The first term of AP is 3, last term is 83, and Sₙ = 903. Find n and d.
Step 1 — Given Values
We know:
a = 3,   l = 83,   Sₙ = 903
Step 2 — Find n using Sₙ = n/2 × (a+l)
903 = n/2 × (3 + 83) = n/2 × 86 = 43n
∴ n = 903 ÷ 43 = 21
Step 3 — Find d using l = a+(n-1)d
83 = 3 + (21−1)×d = 3 + 20d
20d = 80  →  d = 4
✅ Answer
The AP has n = 21 terms with common difference d = 4.

📌 याद रखें (Remember)
🔵 Formula 1: Sₙ = n/2 × [2a + (n−1)d]  ← Use when a, d, n are given
🟢 Formula 2: Sₙ = n/2 × (a + l)  ← Use when first & last terms are given
🟡 Important: aₙ = Sₙ − Sₙ₋₁  ← nth term from sum formula (for n ≥ 2)
🔴 Special: Sum of first n natural numbers = n(n+1)/2  ← AP with a=1, d=1
