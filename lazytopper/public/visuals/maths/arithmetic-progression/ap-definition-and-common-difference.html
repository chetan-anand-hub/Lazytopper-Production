🔢 What is an Arithmetic Progression? DEFINITION

An Arithmetic Progression (AP) is a sequence where the difference between any two consecutive terms is always the same. This fixed difference is called the Common Difference (d).

a = first term (प्रथम पद) d = common difference (सार्व अंतर) n = number of terms

d = a₂ − a₁ = a₃ − a₂ = aₙ − aₙ₋₁
सार्व अंतर (Common Difference) = consecutive term − previous term
💡 याद रखें (Remember): d can be positive (increasing AP), negative (decreasing AP), or zero (constant AP — all terms equal)!

📖 Worked Example — Step by Step समझो

Question: Is the sequence 4, 7, 10, 13, 16, ... an AP? If yes, find the common difference.

1
Write down consecutive term differences:
a₂ − a₁ = 7 − 4 = 3
a₃ − a₂ = 10 − 7 = 3
a₄ − a₃ = 13 − 10 = 3
a₅ − a₄ = 16 − 13 = 3
2
Check if all differences are equal:
All differences = 3 ✔
Since the difference is constant, this IS an AP!
3
State the answer:
∴ The sequence is an AP with:
First term a = 4
Common difference d = 3
4
General form of this AP:
4, 4+3, 4+6, 4+9, 4+12, ...
= a, a+d, a+2d, a+3d, a+4d, ...
This is the standard form of any AP!

⭐ Key Points Summary REVISION
▸An AP has the form: a, a+d, a+2d, a+3d, ...
▸d > 0 → Increasing AP (बढ़ती हुई श्रेढ़ी)
▸d < 0 → Decreasing AP (घटती हुई श्रेढ़ी)
▸d = 0 → Constant AP (all terms equal)
▸To check AP: aₙ − aₙ₋₁ = constant for ALL consecutive pairs
General Term Formula (आगे पढ़ेंगे):
aₙ = a + (n−1)d
nth term = first term + (n−1) × common difference
