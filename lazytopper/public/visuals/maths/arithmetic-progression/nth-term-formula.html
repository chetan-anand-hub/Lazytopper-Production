🔑 The Key Formula — सूत्र
aₙ = a + (n − 1) × d
जहाँ: a = पहला पद | d = सार्व अंतर | n = पद संख्या | aₙ = nवाँ पद
1 What is an Arithmetic Progression? (AP क्या है?)

A sequence where each term differs from the previous by a constant amount called the Common Difference (d).

💡 Key Insight: In an AP, d = a₂ − a₁ = a₃ − a₂ = ... (always constant!)

3 📖 Worked Example — Step by Step
Problem: Find the 15th term of AP: 7, 11, 15, 19, ...
Step 0 — Given
Identify the AP
The sequence is: 7, 11, 15, 19, ...
Step 1 — Find 'a'
First Term (पहला पद)
The first term is:
a = 7
Step 2 — Find 'd'
Common Difference (सार्व अंतर)
d = a₂ − a₁ = 11 − 7 = 4 ✓ (verify: 15−11=4, 19−15=4)
d = 4
Step 3 — Apply Formula
Use aₙ = a + (n−1)d
We need n = 15:
a₁₅ = 7 + (15 − 1) × 4
Step 4 — Calculate
Simplify Step by Step
= 7 + 14 × 4 = 7 + 56
∴ a₁₅ = 63 ✅
4 🧠 Why aₙ = a + (n−1)d? (Formula की समझ)

Click each term below to see how it's built from the first term!

Pattern:
a₁ = a = a + 0×d = a + (1−1)d
a₂ = a + d = a + 1×d = a + (2−1)d
a₃ = a + d + d = a + 2d = a + (3−1)d
⋮
aₙ = a + (n−1)d ← General Formula! 🎉
