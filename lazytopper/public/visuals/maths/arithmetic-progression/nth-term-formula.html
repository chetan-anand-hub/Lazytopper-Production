📐 The Formula / सूत्र
n वाँ पद (nth Term of AP)
an  =  a  +  (n − 1) × d
where / जहाँ :
a = प्रथम पद (First term)
n = पद संख्या (Term number)
d = सार्व अंतर (Common difference)
aₙ = n वाँ पद (nth term)

📚 Key Concepts / मुख्य अवधारणाएँ
ARITHMETIC PROGRESSION / समांतर श्रेढ़ी
A sequence where the difference between consecutive terms is constant (= d).
COMMON DIFFERENCE / सार्व अंतर
d = a₂ − a₁ = a₃ − a₂ = ... (any term minus previous term)
GENERAL TERM / व्यापक पद
aₙ = a + (n−1)d gives any term directly without listing all terms.
REMEMBER / याद रखें
For n=1: a₁ = a + 0×d = a ✓
For n=2: a₂ = a + d ✓
