📐 Key Formula — मुख्य सूत्र
aₙ = a + (n−1)d
aₙ = nth term  |  a = first term (प्रथम पद)  |  d = common difference (सार्व अंतर)  |  n = term number
∴ Sum of n terms
Sₙ = n/2 × [2a+(n−1)d]
∵ Common Difference
d = aₙ₊₁ − aₙ
