⭐ Key Properties of AP

• ∵ Consecutive terms differ by constant d (सार्व अंतर)

• ∴ aₙ = a + (n−1)d — nth term formula

• If d > 0 → Increasing AP (वर्धमान)

• If d < 0 → Decreasing AP (ह्रासमान)

• If d = 0 → Constant AP (स्थिर)

• Sum of n terms: Sₙ = n/2 × (2a + (n−1)d)
