Relationship Between Zeroes and Coefficients — CBSE Class 10

📐 मुख्य सूत्र (Key Formulas)
For a Quadratic Polynomial: p(x) = ax² + bx + c  |  Zeroes: α (alpha) & β (beta)
Sum of Zeroes (α + β)
α + β = −b/a
= −(coefficient of x) / (coefficient of x²)
Product of Zeroes (α × β)
α × β = c/a
= (constant term) / (coefficient of x²)
💡 याद करने की ट्रिक (Memory Trick)

Think of it as: Sum = −b/a (negative of 'b' over 'a') and Product = c/a ('c' over 'a'). The sum has a NEGATIVE sign, the product does NOT! ∴ Never confuse the signs!

📖 Worked Example (Step-by-Step)
p(x) = 2x² − 7x + 3  |  Find α + β and α × β
1
Identify the Coefficients
Compare 2x² − 7x + 3 with standard form ax² + bx + c

a = 2  b = −7  c = 3

∴ coefficient of x² = 2, coefficient of x = −7, constant = 3
2
Apply Sum Formula
Using: α + β = −b/a

α + β = −(−7) / 2
α + β = 7/2

∵ b = −7, so −b = +7
∴ Sum of zeroes = 7/2 = 3.5
3
Apply Product Formula
Using: α × β = c/a

α × β = 3 / 2
∴ Product of zeroes = 3/2 = 1.5

✓ Verification: The actual zeroes are x = 3 and x = 1/2
Sum: 3 + 1/2 = 7/2 ✓   Product: 3 × 1/2 = 3/2 ✓

p(x) = x² + 7x + 10  |  Find α + β and α × β
1
Identify Coefficients
Compare x² + 7x + 10 with ax² + bx + c

a = 1  b = 7  c = 10

Note: when you see just x², the coefficient a = 1 (invisible 1!)
2
Sum of Zeroes
α + β = −b/a = −7/1 = −7

⚠️ Watch the sign! b = +7, so −b = −7
∴ Sum of zeroes = −7

This means if one zero is −2, the other is −5
because (−2) + (−5) = −7 ✓
3
Product of Zeroes
α × β = c/a = 10/1 = 10

∴ Product of zeroes = 10

✓ Verify: Zeroes are −2 and −5
Sum: (−2)+(−5) = −7 ✓
Product: (−2)×(−5) = +10 ✓

Given: α = 3, β = −4  |  Form the polynomial!
1
The Reverse Formula
If we KNOW the zeroes, we can BUILD the polynomial!

p(x) = x² − (α+β)x + (α×β)

This is derived from:
p(x) = (x − α)(x − β) = x² − (α+β)x + αβ

∵ α = 3 and β = −4
2
Calculate Sum and Product
α + β = 3 + (−4) = −1

α × β = 3 × (−4) = −12

Now we have everything needed to write our polynomial! 🎉
3
Write the Polynomial
p(x) = x² − (α+β)x + (α×β)

p(x) = x² − (−1)x + (−12)

∴ p(x) = x² + x − 12

✓ Check: p(3) = 9+3−12 = 0 ✓   p(−4) = 16−4−12 = 0 ✓

🎯 CBSE Exam Tip

In exams, always identify a, b, c first, then apply formulas. Many students lose marks by using wrong signs! Remember: Sum = −b/a (has minus), Product = c/a (no minus). Also remember: p(α) = 0 and p(β) = 0 by definition of zeroes (शून्यक).
