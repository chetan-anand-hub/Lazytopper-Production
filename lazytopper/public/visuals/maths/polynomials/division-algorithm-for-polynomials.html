🔑 The Division Algorithm | विभाजन प्रमेय (Theorem)
p(x) = g(x) × q(x) + r(x)
Dividend = Divisor × Quotient + Remainder
∵ deg r(x) < deg g(x) OR r(x) = 0  |  g(x) ≠ 0

g(x) × q(x) + r(x)
= (x + 2)(2x² - x + 9) + (-13)
= 2x³ - x² + 9x + 4x² - 2x + 18 - 13
= 2x³ + 3x² + 7x + 5
= p(x) ✓
📝 Practice Problems CBSE Style
Q1. Divide x³ - 3x² + 5x - 3 by x² - x + 1. Find q(x) and r(x).
Solution:
Dividing x³ - 3x² + 5x - 3 by x² - x + 1

Step 1: x³ ÷ x² = x
  x(x² - x + 1) = x³ - x² + x
  Subtract: (-3x² + 5x - 3) - (-x² + x) = -2x² + 4x - 3

Step 2: -2x² ÷ x² = -2
  -2(x² - x + 1) = -2x² + 2x - 2
  Subtract: (-2x² + 4x - 3) - (-2x² + 2x - 2) = 2x - 1

∴ q(x) = x - 2, r(x) = 2x - 1
deg r(x) = 1 < deg g(x) = 2 ✓
Q2. If p(x) = x⁴ - 3x² + 4x + 5 and g(x) = x² - x + 1, verify the division algorithm after dividing.
Solution:
Dividing x⁴ - 3x² + 4x + 5 by x² - x + 1:

x⁴ ÷ x² = x² → x²(x²-x+1) = x⁴-x³+x²
Remainder: x³-4x²+4x+5

x³ ÷ x² = x → x(x²-x+1) = x³-x²+x
Remainder: -3x²+3x+5

-3x² ÷ x² = -3 → -3(x²-x+1) = -3x²+3x-3
Remainder: 8

∴ q(x) = x²+x-3, r(x) = 8

Verification:
(x²-x+1)(x²+x-3)+8
= x⁴+x³-3x²-x³-x²+3x+x²+x-3+8
= x⁴-3x²+4x+5 = p(x) ✓
💡 Key Points to Remember Exam Tips
📌
Condition: deg r(x) < deg g(x) OR r(x) = 0. Always check this!
⚠️
Missing Terms: Write 0 as coefficient for missing powers (e.g., x³ + 0x² + 5x)
✅
Always Verify: Multiply back: g(x)×q(x)+r(x) must equal p(x)
🎯
Finding Zeros: If r(x)=0, then g(x) is a factor of p(x) and the zeros of g(x) are zeros of p(x)
