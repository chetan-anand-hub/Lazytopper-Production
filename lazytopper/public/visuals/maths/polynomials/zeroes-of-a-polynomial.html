🎯 Core Concept | मुख्य अवधारणा

A value x = α is called a zero (शून्यक) of polynomial p(x) if:

p(α) = 0

∴ Zeroes are the x-coordinates where the graph touches/crosses the x-axis

📌 Number of Zeroes | शून्यकों की संख्या

Linear (degree 1) 1 zero
Quadratic (degree 2) ≤ 2 zeroes
Cubic (degree 3) ≤ 3 zeroes

∴ Degree = Maximum possible zeroes

🔗 Relationship | संबंध (Quadratic)

For p(x) = ax² + bx + c with zeroes α and β:

α + β = -b/a (Sum)
α × β = c/a (Product)

These are called Vieta's Formulas (विएटा सूत्र)
