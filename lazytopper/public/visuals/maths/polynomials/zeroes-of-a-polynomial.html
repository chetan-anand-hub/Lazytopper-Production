📖 परिभाषा Definition
शून्यक (Zero/Root) वह मान है जो polynomial में x की जगह रखने पर polynomial का मान शून्य (0) हो जाता है।

The value of x for which p(x) = 0 is called a zero of the polynomial.
p(α) = 0  ⟹  α is a zero of p(x)

💡 Key Concepts महत्वपूर्ण
Linear Polynomial p(x) = ax + b
Zero: x = −b/a  →  हमेशा 1 zero
Quadratic Polynomial p(x) = ax² + bx + c
अधिकतम 2 zeroes (हो सकते हैं 0, 1, या 2)
x = −b ± √(b²−4ac)

अधिकतम 3 zeroes
✏️ Worked Example Step-by-Step
Find zeroes of: p(x) = x² − 5x + 6
Step 0 / 4
1Identify the polynomial
p(x) = x² − 5x + 6   Quadratic
a = 1, b = −5, c = 6
2Factorise करें (Split the middle term)
x² − 5x + 6
= x² − 3x − 2x + 6
= x(x−3) − 2(x−3)
= (x−2)(x−3)
3p(x) = 0 रखें
(x−2)(x−3) = 0
⟹ x−2 = 0  या  x−3 = 0
⟹ x = 2  या  x = 3
4Verify ✓
p(2) = 4−10+6 = 0 ✅
p(3) = 9−15+6 = 0 ✅
∴ Zeroes = 2 और 3 (Graph x-axis cuts at x=2, x=3)
🔗 Zeroes का सम्बन्ध (Vieta's Formulas)
For p(x) = ax² + bx + c with zeroes α, β:
α + β = −b/a
α × β = c/a
Example में: α=2, β=3
α+β = 5 = −(−5)/1 ✅  |  α×β = 6 = 6/1 ✅
📌 Graph Rules याद करें
🔵 x-axis को काटे → Zero exist करता है
🟢 x-axis को छुए (touch) → Repeated Zero (दोनों equal)
🔴 x-axis से न मिले → No real zeroes
