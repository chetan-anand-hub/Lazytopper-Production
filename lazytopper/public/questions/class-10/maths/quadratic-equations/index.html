Quadratic Equations — Class 10 Mathematics, NCERT Chapter 4

Board weightage: high · 12 step-marked questions · 33 marks in total

One question, a few tools. A quadratic equation is any equation you can write as ax^2 + bx + c = 0, where a ≠ 0. The whole chapter answers one question: <b>what values of x make this true?</b> Those values are the <b>roots</b>. You'll learn to find them (factorisation, the quadratic formula), decide whether they exist (the discriminant), relate them to the coefficients, and turn real situations into equations you can solve.

Formula sheet

  • Standard form ax^2 + bx + c = 0, a ≠ 0
  • Quadratic formula x = dfrac-b ± root(b^2 - 4ac)2a
  • Discriminant D = b^2 - 4ac
  • Nature of roots D>0: distinct · D=0: equal · D<0: none real
  • Roots & coefficients alpha+beta = -b / a · alphabeta = c / a · x^2-(alpha+beta)x+alphabeta=0

Key definitions

Quadratic equation
any equation that simplifies to degree 2. If the x^2 term survives simplification, it is quadratic — always simplify FIRST before deciding (NCERT's Example 2 warning). NCERT 2026-27 Ch4 p.39
Root of a quadratic equation
a value of x that makes the equation true — plug it in and the LHS becomes 0. Same thing as a zero of the polynomial ax^2+bx+c. NCERT 2026-27 Ch4 p.42
Discriminant
D = b^2 - 4ac. When a question asks about the NATURE of roots (or “find k”), compute D first — its sign answers the question without solving for x. NCERT 2026-27 Ch4 p.45
Nature of roots
D>0: cuts the x-axis twice · D=0: just touches it · D<0: never meets it. In answers, always say “no <b>real</b> roots”, not “no roots”. NCERT 2026-27 Ch4 p.45
Quadratic formula
x = dfrac-b ± root(b^2 - 4ac)2a — the fallback that always works when b^2 - 4ac ge 0, e.g. when the middle term won't split. NCERT 2026-27 Ch4 p.47 (Summary 4)
Standard form
That is, ax² + bx + c = 0, a ≠ 0 is called the standard form of a quadratic equation. NCERT 2026-27 Ch4 p.39
Zeroes = roots
Note that the zeroes of the quadratic polynomial ax² + bx + c and the roots of the quadratic equation ax² + bx + c = 0 are the same. NCERT 2026-27 Ch4 p.42
At most two roots
You have observed, in Chapter 2, that a quadratic polynomial can have at most two zeroes. So, any quadratic equation can have atmost two roots. NCERT 2026-27 Ch4 p.42
Roots by factorisation
If we can factorise ax² + bx + c, a ≠ 0, into a product of two linear factors, then the roots of the quadratic equation ax² + bx + c = 0 can be found by equating each factor to zero. NCERT 2026-27 Ch4 p.47 (Summary 3)

What the board actually asks

solving by factorisation & the quadratic formula, the discriminant (nature of roots), and word problems — these carry almost every mark here.

Q1. 1 mark Discriminant and Nature of Roots

If 2 is a root of the equation x² + ax + 12 = 0 and the equation x² + ax + q = 0 has two equal roots, then the value of q is:

  1. 16
  2. 12
  3. 20
  4. 8

Step-marked solution

  1. [0.5 mark] Since 2 is a root of x² + ax + 12 = 0: (2)² + 2a + 12 = 0 ⇒ 4 + 2a + 12 = 0 ⇒ a = −8.
  2. [0.5 mark] For x² + ax + q = 0 to have equal roots, D = a² − 4q = 0 ⇒ (−8)² − 4q = 0 ⇒ 64 = 4q ⇒ q = 16.

Answer. q = 16.

Q2. 2 marks Discriminant and Nature of Roots

Using the discriminant, state whether the roots of 4x² − 4x + 1 = 0 are real and equal, and find them if they are.

Step-marked solution

  1. [1 mark] a = 4, b = −4, c = 1. D = (−4)² − 4(4)(1) = 16 − 16 = 0.
  2. [1 mark] Since D = 0, the roots are real and equal; the repeated root is x = −b/2a = 4/8 = 1/2.

Answer. Real and equal roots; x = 1/2 (repeated).

Q3. 3 marks Word Problems on Quadratic Equations

A dealer sells a toy for ₹24 and gains as much percent as the cost price (in rupees) of the toy. Find the cost price of the toy.

Step-marked solution

  1. [1 mark] Let the cost price be ₹x. Gain% = x, so gain = x × (x/100) = x²/100, and selling price = x + x²/100.
  2. [1 mark] Given SP = 24: x + x²/100 = 24 ⇒ x² + 100x − 2400 = 0 ⇒ (x + 120)(x − 20) = 0.
  3. [1 mark] x = 20 (cost price cannot be negative). The cost price of the toy is ₹20.

Answer. Cost price = ₹20.

Q4. 4 marks Word Problems

From the 2025 CBSE board paper

A garden designer is planning a rectangular lawn that is to be surrounded by a uniform walkway. The total area of the lawn and the walkway is 360 square metres. The width of the walkway is same on all sides. The dimensions of the lawn itself are 12 metres by 10 metres. Based on the information given above, answer the following questions : (i) Formulate the quadratic equation representing the total area of the lawn and the walkway, taking width of walkway = x m. 1 (ii) (a) Solve the quadratic equation to find the width of the 2 OR (b) If the cost of paving the walkway at the rate of 50 per square metre is 12,000, calculate the area of the walkway. 2 (iii) Find the perimeter of the lawn. 1

Step-marked solution

  1. [1 mark] (i) With walkway width x m, the outer rectangle is (12 + 2x) by (10 + 2x): (12 + 2x)(10 + 2x) = 360 ⟹ 4x² + 44x − 240 = 0 ⟹ x² + 11x − 60 = 0.
  2. [1 mark] (ii)(a) Factorise: (x + 15)(x − 4) = 0 ⟹ x = 4 (reject x = −15 as width cannot be negative).
  3. [1 mark] (ii)(a) Width of the walkway = 4 m. [OR (b) Area of walkway = 12000 ÷ 50 = 240 m².]
  4. [1 mark] (iii) Perimeter of the lawn = 2(12 + 10) = 44 m.

Answer. (i) x² + 11x − 60 = 0; (ii) width = 4 m OR area of walkway = 240 m²; (iii) perimeter of lawn = 44 m.

Q5. 5 marks Nature of Roots

From the 2024 CBSE board paper

Find the value of 'c' for which the quadratic equation (c + 1) x2 – 6 (c + 1) x + 3 (c + 9) = 0; c ¹ –1 has real and equal roots.

Step-marked solution

  1. [1 mark] For real and equal roots, discriminant D = b² – 4ac = 0.
  2. [1 mark] Here a = (c + 1), b = –6(c + 1), c-term = 3(c + 9). So {–6(c + 1)}² – 4(c + 1) × 3(c + 9) = 0.
  3. [1 mark] 36(c + 1)² – 12(c + 1)(c + 9) = 0 → 12(c + 1)[3(c + 1) – (c + 9)] = 0 → 12(c + 1)(2c – 6) = 0.
  4. [1 mark] So c = –1 or c = 3; since c ≠ –1 (given), c = 3.
  5. [1 mark] Verification: for c = 3 the equation becomes 4x² – 24x + 36 = 0, i.e. x² – 6x + 9 = (x – 3)² = 0, giving equal roots x = 3, 3. Hence c = 3.

Answer. c = 3 (rejecting c = –1); the equal roots are x = 3, 3.

Q6. 1 mark Discriminant and Nature of Roots

If the equation x² + 2(k + 2)x + 9k = 0 has two equal roots, then the value(s) of k is/are:

  1. 1 or 4
  2. 2 or 3
  3. 1 or 8
  4. 4 or 6

Step-marked solution

  1. [0.5 mark] Equal roots ⇒ D = b² − 4ac = 0 with b = 2(k + 2), a = 1, c = 9k: [2(k + 2)]² − 4(9k) = 0 ⇒ 4(k² + 4k + 4) − 36k = 0.
  2. [0.5 mark] 4k² − 20k + 16 = 0 ⇒ k² − 5k + 4 = 0 ⇒ (k − 1)(k − 4) = 0 ⇒ k = 1 or k = 4.

Answer. k = 1 or k = 4.

Q7. 2 marks Discriminant and Nature of Roots

Find k if the equation 9x² + 6kx + 4 = 0 possesses two equal roots.

Step-marked solution

  1. [1 mark] Equal roots ⇒ D = (6k)² − 4(9)(4) = 36k² − 144 = 0.
  2. [1 mark] 36k² = 144 ⇒ k² = 4 ⇒ k = ±2.

Answer. k = ±2.

Q8. 3 marks Solution by Factorisation

Solve for x: 1/(a + b + x) = 1/a + 1/b + 1/x, where a + b + x ≠ 0 and a, b, x ≠ 0.

Step-marked solution

  1. [1 mark] Transpose 1/x: 1/(a + b + x) − 1/x = 1/a + 1/b ⇒ [x − (a + b + x)] / [x(a + b + x)] = (a + b)/(ab) ⇒ −(a + b)/[x(a + b + x)] = (a + b)/(ab).
  2. [1 mark] Since a + b ≠ 0, cancel (a + b): −1/[x(a + b + x)] = 1/(ab) ⇒ x(a + b + x) + ab = 0 ⇒ x² + ax + bx + ab = 0.
  3. [1 mark] x(x + a) + b(x + a) = 0 ⇒ (x + a)(x + b) = 0 ⇒ x = −a or x = −b.

Answer. x = −a or x = −b.

Q9. 4 marks Applications of Quadratic Equations

A farmer lays out a rectangular vegetable garden. He designs it so that the length is 4 m more than three times the breadth, and the garden covers an area of 175 m². (i) If the breadth is x m, write an expression for the length. (ii) Form a quadratic equation from the given area. (iii) Solve it to find the breadth. (iv) Find the length of the garden.

Step-marked solution

  1. [1 mark] Breadth = x m, so length = (3x + 4) m.
  2. [1 mark] Area = x(3x + 4) = 175 ⇒ 3x² + 4x − 175 = 0.
  3. [1 mark] D = 16 + 4(3)(175) = 2116 = 46²; x = (−4 + 46)/6 = 7 (reject x = −50/6 < 0 as breadth cannot be negative).
  4. [1 mark] Breadth = 7 m, so length = 3(7) + 4 = 25 m.

Answer. Breadth = 7 m, length = 25 m.

Q10. 5 marks Nature of Roots

From the 2024 CBSE board paper

Find the value of 'k' for which the quadratic equation (k + 1) x2 – 2 (3k + 1) x + (8k + 1) = 0 has real and equal roots.

Step-marked solution

  1. [1 mark] For real and equal roots, discriminant D = b² – 4ac = 0.
  2. [1 mark] Here a = (k + 1), b = –2(3k + 1), c = (8k + 1). So [–2(3k + 1)]² – 4(k + 1)(8k + 1) = 0.
  3. [1 mark] 4(9k² + 6k + 1) – 4(8k² + 9k + 1) = 0 → 4(k² – 3k) = 0 → k² – 3k = 0.
  4. [1 mark] k(k – 3) = 0, so k = 0 or k = 3 (both valid, since k + 1 ≠ 0 in each case).
  5. [1 mark] Verification: k = 0 gives x² – 2x + 1 = (x – 1)² = 0 (equal roots x = 1); k = 3 gives 4x² – 20x + 25 = (2x – 5)² = 0 (equal roots x = 5/2). Hence k = 0 or k = 3.

Answer. k = 0 or k = 3.

Q11. 1 mark Discriminant and Nature of Roots

If the roots of the equation 5x² − kx + 1 = 0 are real and distinct, then:

  1. k > 2√5 or k < −2√5
  2. −2√5 < k < 2√5
  3. k = ±2√5
  4. only k < 2√5

Step-marked solution

  1. [0.5 mark] Real and distinct ⇒ D = b² − 4ac > 0. Here D = (−k)² − 4(5)(1) = k² − 20 > 0.
  2. [0.5 mark] k² > 20 ⇒ |k| > 2√5 ⇒ k > 2√5 or k < −2√5.

Answer. k > 2√5 or k < −2√5.

Q12. 2 marks Discriminant and Nature of Roots

Find the range of values of k for which the equation x² + 5kx + 16 = 0 has no real roots.

Step-marked solution

  1. [1 mark] No real roots ⇒ D = (5k)² − 4(1)(16) = 25k² − 64 < 0.
  2. [1 mark] k² < 64/25 ⇒ |k| < 8/5 ⇒ −8/5 < k < 8/5.

Answer. −8/5 < k < 8/5.

Common mistakes — where marks are lost

  • <b>Forgetting to reject the invalid root</b> — negative length / age / count, or an excluded value like k ≠ -1.
  • <b>Sign slips in D</b> — when b is negative, (-4)^2 = +16, not -16.
  • <b>Sign error in form-the-equation</b> — the middle term is -(alpha+beta), not +.
  • <b>Writing “no roots” when D < 0</b> — say “no <i>real</i> roots”.
