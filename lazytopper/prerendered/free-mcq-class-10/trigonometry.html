  1. Q1

    If 2x=secA and x2​=tanA then 2(x2−x21​)=?
    • (a)21​
    • (b)41​
    • (c)81​
    • (d)161​
    Show answer

    Answer: (a) 21​

    Using sec2A−tan2A=1: 4x2−x24​=1, so x2−x21​=41​ and 2(x2−x21​)=21​.

  2. Q3

    If cosA+cos2A=1 then sin2A+sin4A=?
    • (a)1
    • (b)2
    • (c)4
    • (d)3.
    Show answer

    Answer: (a) 1

    cosA=1−cos2A=sin2A. So sin2A+sin4A=cosA+cos2A=1.

  4. Q5

    If tanθ=7​1​ then (cosec2θ+sec2θ)(cosec2θ−sec2θ)​=?
    • (a)3−2​

  5. Q6

    sin2A=2sinA is true when A =
    • (a)0∘
    • (b)30∘
    • (c)45∘
    • (d)60∘

    Answer: (a) 0∘
