Exercise 8.2

Exemplar Ch8 Ex 8.2 Q42 marks
State whether the statement is true or false, with justification: (1 − cos²θ) · sec²θ = tan θ.
Step 1 LHS = (1 − cos²θ) · sec²θ = sin²θ · (1/cos²θ) = sin²θ/cos²θ = tan²θ.

Step-by-step solution

  1. LHS = (1 − cos²θ) · sec²θ = sin²θ · (1/cos²θ) = sin²θ/cos²θ = tan²θ.
  2. So LHS = tan²θ, not tan θ in general.
  3. Hence the statement is FALSE (it should be tan²θ).

Answer: False — LHS simplifies to tan²θ, not tan θ.

Exercise 8.3

Exemplar Ch8 Ex 8.3 Q13 marks
Prove that sin θ/(1 + cos θ) + (1 + cos θ)/sin θ = 2 cosec θ.
Step 1 LHS = sin θ/(1 + cos θ) + (1 + cos θ)/sin θ.

Step-by-step solution

  1. LHS = sin θ/(1 + cos θ) + (1 + cos θ)/sin θ.
  2. Combine over common denominator sin θ · (1 + cos θ): LHS = [sin²θ + (1 + cos θ)²] / [sin θ (1 + cos θ)].
  3. Expand numerator: sin²θ + 1 + 2 cos θ + cos²θ = (sin²θ + cos²θ) + 1 + 2 cos θ = 1 + 1 + 2 cos θ = 2 + 2 cos θ = 2(1 + cos θ).
  4. LHS = 2(1 + cos θ) / [sin θ (1 + cos θ)] = 2/sin θ = 2 cosec θ = RHS.
  5. Hence proved.

Answer: LHS = 2 cosec θ = RHS.

Exemplar Ch8 Ex 8.3 Q33 marks
If tan A = 3/4, show that sin A · cos A = 12/25.
Step 1 tan A = 3/4 ⇒ opposite = 3k, adjacent = 4k. Hypotenuse = √((3k)² + (4k)²) = √(25k²) = 5k.

Step-by-step solution

  1. tan A = 3/4 ⇒ opposite = 3k, adjacent = 4k. Hypotenuse = √((3k)² + (4k)²) = √(25k²) = 5k.
  2. sin A = 3/5, cos A = 4/5.
  3. sin A · cos A = (3/5)(4/5) = 12/25.
  4. Hence proved.

Answer: sin A · cos A = 12/25.

Exemplar Ch8 Ex 8.3 Q92 marks
If √3 tan θ = 1, find the value of sin²θ − cos²θ.
Step 1 tan θ = 1/√3 ⇒ θ = 30°.

Step-by-step solution

  1. tan θ = 1/√3 ⇒ θ = 30°.
  2. sin 30° = 1/2, cos 30° = √3/2.
  3. sin²θ − cos²θ = (1/2)² − (√3/2)² = 1/4 − 3/4 = −1/2.

Answer: −1/2.

Exemplar Ch8 Ex 8.3 Q113 marks
Simplify (1 + tan²θ)(1 − sin θ)(1 + sin θ).
Step 1 (1 − sin θ)(1 + sin θ) = 1 − sin²θ = cos²θ.

Step-by-step solution

  1. (1 − sin θ)(1 + sin θ) = 1 − sin²θ = cos²θ.
  2. 1 + tan²θ = sec²θ = 1/cos²θ.
  3. Product = sec²θ · cos²θ = (1/cos²θ) · cos²θ = 1.

Answer: 1.

Exemplar Ch8 Ex 8.3 Q122 marks
If 2 sin²θ − cos²θ = 2, then find the value of θ (0° ≤ θ ≤ 90°).
Step 1 Replace cos²θ with 1 − sin²θ: 2 sin²θ − (1 − sin²θ) = 2.

Step-by-step solution

  1. Replace cos²θ with 1 − sin²θ: 2 sin²θ − (1 − sin²θ) = 2.
  2. 2 sin²θ − 1 + sin²θ = 2 ⇒ 3 sin²θ = 3 ⇒ sin²θ = 1.
  3. sin θ = 1 (taking positive root, since θ acute) ⇒ θ = 90°.

Answer: θ = 90°.

Exercise 8.4

Exemplar Ch8 Ex 8.4 Q15 marks
If cosec θ + cot θ = p, prove that cos θ = (p² − 1)/(p² + 1).
Step 1 Given: cosec θ + cot θ = p. …(1)

Step-by-step solution

  1. Given: cosec θ + cot θ = p. …(1)
  2. Use the identity cosec²θ − cot²θ = 1, i.e., (cosec θ + cot θ)(cosec θ − cot θ) = 1.
  3. So cosec θ − cot θ = 1/p. …(2)
  4. Add (1) and (2): 2 cosec θ = p + 1/p = (p² + 1)/p ⇒ cosec θ = (p² + 1)/(2p) ⇒ sin θ = 2p/(p² + 1).
  5. Subtract (2) from (1): 2 cot θ = p − 1/p = (p² − 1)/p ⇒ cot θ = (p² − 1)/(2p).
  6. cos θ = cot θ · sin θ = [(p² − 1)/(2p)] · [2p/(p² + 1)] = (p² − 1)/(p² + 1). Proved.

Answer: cos θ = (p² − 1)/(p² + 1).

Exemplar Ch8 Ex 8.4 Q95 marks
If tan θ + sec θ = l, prove that sec θ = (l² + 1)/(2l).
Step 1 [1 mark] Given: tan θ + sec θ = l. …(1)

Step-by-step solution

  1. [1 mark] Given: tan θ + sec θ = l. …(1)
  2. [1 mark] Use the identity sec²θ − tan²θ = 1, i.e., (sec θ + tan θ)(sec θ − tan θ) = 1.
  3. [1 mark] Dividing by (1): sec θ − tan θ = 1/l. …(2)
  4. [1 mark] Add (1) and (2): 2 sec θ = l + 1/l = (l² + 1)/l.
  5. [1 mark] Therefore sec θ = (l² + 1)/(2l). Proved.

Answer: sec θ = (l² + 1)/(2l).

Exemplar Ch8 MCQ Q131 mark
If sin θ − cos θ = 0, then the value of (sin⁴θ + cos⁴θ) is:
Step 1 sin θ = cos θ ⇒ tan θ = 1 ⇒ θ = 45°.

Step-by-step solution

  1. sin θ = cos θ ⇒ tan θ = 1 ⇒ θ = 45°.
  2. sin 45° = cos 45° = 1/√2.
  3. sin⁴θ + cos⁴θ = (1/√2)⁴ + (1/√2)⁴ = 1/4 + 1/4 = 1/2.

Answer: 1/2 — option (c).
