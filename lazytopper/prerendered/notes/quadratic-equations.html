The Big Idea AUTHORED

One question, a few tools.

A quadratic equation is any equation you can write as ax2+bx+c=0, where a=0. The whole chapter answers one question: what values of x make this true? Those values are the roots. You'll learn to find them (factorisation, the quadratic formula), decide whether they exist (the discriminant), relate them to the coefficients, and turn real situations into equations you can solve.

Definitions the board rewards NCERT VERBATIM

State these in NCERT’s exact words

Quadratic equation
📖NCERT verbatim — memorise this exact wording· Ch 4,
“A quadratic equation in the variable x is an equation of the form ax² + bx + c = 0, where a, b, c are real numbers, a ≠ 0.”
What it means: any equation that simplifies to degree 2. If the x2 term survives simplification, it is quadratic — always simplify FIRST before deciding (NCERT's Example 2 warning).
Root of a quadratic equation
📖NCERT verbatim — memorise this exact wording· Ch 4,
“In general, a real number α is called a root of the quadratic equation ax² + bx + c = 0, a ≠ 0 if aα² + bα + c = 0. We also say that x = α is a solution of the quadratic equation, or that α satisfies the quadratic equation.”
What it means: a value of x that makes the equation true — plug it in and the LHS becomes 0. Same thing as a zero of the polynomial ax2+bx+c.
Discriminant
📖NCERT verbatim — memorise this exact wording· Ch 4,
“Since b² – 4ac determines whether the quadratic equation ax² + bx + c = 0 has real roots or not, b² – 4ac is called the discriminant of this quadratic equation.”
What it means: D=b2−4ac. When a question asks about the NATURE of roots (or “find k”), compute D first — its sign answers the question without solving for x.
Nature of roots
📖NCERT verbatim — memorise this exact wording· Ch 4,
“So, a quadratic equation ax² + bx + c = 0 has (i) two distinct real roots, if b² – 4ac > 0, (ii) two equal real roots, if b² – 4ac = 0, (iii) no real roots, if b² – 4ac < 0.”
What it means: D>0: cuts the x-axis twice · D=0: just touches it · D<0: never meets it. In answers, always say “no real roots”, not “no roots”.
Quadratic formula
📖NCERT verbatim — memorise this exact wording· Ch 4,
“Quadratic formula: The roots of a quadratic equation ax² + bx + c = 0 are given by (−b ± √(b² − 4ac)) / 2a, provided b² – 4ac ≥ 0.”
What it means: x=2a−b±b2−4ac​​ — the fallback that always works when b2−4ac≥0, e.g. when the middle term won't split.
📖Key terms — NCERT verbatim (state word-for-word)
Standard form
That is, ax² + bx + c = 0, a ≠ 0 is called the standard form of a quadratic equation. (Ch 4, )
Zeroes = roots
Note that the zeroes of the quadratic polynomial ax² + bx + c and the roots of the quadratic equation ax² + bx + c = 0 are the same. (Ch 4, )
At most two roots
You have observed, in Chapter 2, that a quadratic polynomial can have at most two zeroes. So, any quadratic equation can have atmost two roots. (Ch 4, )
Roots by factorisation
If we can factorise ax² + bx + c, a ≠ 0, into a product of two linear factors, then the roots of the quadratic equation ax² + bx + c = 0 can be found by equating each factor to zero. (Ch 4, )
Must-know concepts AUTHORED FRAMING

…and where they’re tested

1
Solving by factorisation
Split the middle term so the product of the two parts equals a⋅c, factor by grouping into two linear factors, then equate each factor to zero — the roots fall out.
2–3 mark “find the roots”
2
The quadratic formula
x=2a−b±b2−4ac​​, valid when b2−4ac≥0. The fallback when factorisation is hard — write a, b, c with their signs before substituting.
2–3 marks
3
Nature of roots via the discriminant
D=b2−4ac. D>0 → two distinct real roots · D=0 → two equal real roots · D<0 → no real roots. The graph shows it best:
“find k” for equal roots — up to 5 marks (CBSE 2024, 30/5/1 Q32a)
4
Roots & coefficients (sum & product)
For roots α,β: α+β=−ab​ and αβ=ac​. Build an equation from given roots: x2−(α+β)x+αβ=0. ⚑ Syllabus note: catalogued under Polynomials (quadratic zeroes–coefficient relationship) — applied here.

5
Word problems → equation
Translate the situation (area, ages, speed, consecutive numbers) into ax2+bx+c=0, solve, and REJECT the root the situation forbids — a negative length or age, or an excluded value like k=−1.

The quadratic formula — where it comes from

NCERT's history box (p.39) credits Sridharacharya (C.E. 1025) with the quadratic formula, derived “by the method of completing the square”. In the 2026-27 syllabus, completing the square is NOT an assessed solution method — you solve by factorisation or the formula. Use this derivation to understand where the formula and the b2−4ac≥0 condition come from, not as an exam technique.

1
Start from the standard form.
ax2+bx+c=0,a=0
2
Divide through by a — allowed precisely because a=0.
x2+ab​x+ac​=0
3
Move the constant across.
x2+ab​x=−ac​
4
Complete the square: add (2ab​)2 to both sides.
x2+ab​x+(2ab​)2=(2ab​)2−ac​
5
The left side is now a perfect square.
(x+2ab​)2=4a2b2−4ac​
6
Take square roots.
x+2ab​=±2ab2−4ac​​
Real only when b2−4ac≥0 — this is exactly where the discriminant condition comes from.
7
Isolate x.
x=2a−b±b2−4ac​​

3 competency questions from the CBSE board pattern, with the full step-marked solution for each — the marks are shown per step, as the official scheme awards them.

5 marksSection D

The product of two consecutive positive odd integers is 483. Find the two integers.

Step-marked solution
  1. [1 mark] Let the smaller odd integer be x; the next consecutive odd integer is x + 2. Given product: x(x + 2) = 483.
  2. [1 mark] Write in standard form: x² + 2x − 483 = 0.
  3. [1 mark] Split the middle term: x² + 23x − 21x − 483 = 0 ⇒ (x + 23)(x − 21) = 0.
  4. [1 mark] Roots x = 21 or x = −23. Reject x = −23 because the integers must be positive.
  5. [1 mark] So x = 21 and the integers are 21 and 23 (21 × 23 = 483 ✓).
5 marksSection D

One positive number is 3 more than twice another positive number. If their product is 90, find the two numbers.

Step-marked solution
  1. [1 mark] Let the smaller number be x; the larger number is (2x + 3). Given product: x(2x + 3) = 90.
  2. [1 mark] Standard form: 2x² + 3x − 90 = 0.
  3. [1 mark] Apply the quadratic formula: x = (−3 ± √(9 + 720)) / 4 = (−3 ± 27) / 4.
  4. [1 mark] Roots x = 6 or x = −7.5. Reject x = −7.5 because the numbers are stated to be positive.
  5. [1 mark] So x = 6 and the larger number is 2(6) + 3 = 15.
5 marksSection D

The difference of two natural numbers is 3 and the difference of their reciprocals is 3/28. Find the two numbers.

Step-marked solution
  1. [1 mark] Let the larger number be x; the smaller is (x − 3). Given 1/(x − 3) − 1/x = 3/28.
  2. [1 mark] Combine the left side: [x − (x − 3)] / [x(x − 3)] = 3/28 ⇒ 3/(x² − 3x) = 3/28, so x² − 3x = 28. Standard form: x² − 3x − 28 = 0.
  3. [1 mark] Factorise: (x − 7)(x + 4) = 0.
  4. [1 mark] Roots x = 7 or x = −4. Reject x = −4 because the numbers are natural (positive).
  5. [1 mark] So x = 7 and the smaller number is 7 − 3 = 4.
