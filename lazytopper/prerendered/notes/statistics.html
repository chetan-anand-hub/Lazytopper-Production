Statistics

★

What the board actually asks: the mean of grouped data (direct, assumed-mean, step-deviation), the mode of grouped data, and the median of grouped data via a cumulative-frequency table & class marks — plus the reverse question “the median is given, find the missing frequency”. Almost every mark here is a plug-into-the-formula computation, so identifying the right class (modal / median) and reading off l,f,cf,h correctly is where the marks live.

The Big Idea AUTHORED

One dataset, three ‘typical’ values.

In Class IX you found the mean, median and mode of ungrouped data. This chapter extends all three measures of central tendency to grouped data — data bundled into class intervals like 40−55. Because you no longer see individual observations, each method works on a representative of the class: the class mark (mid-point) for the mean, the modal class for the mode, and the median class (located with cumulative frequencies) for the median. Learn to spot the right class and substitute into the right formula, and every question in this chapter falls out.

Definitions the board rewards NCERT VERBATIM

State these in NCERT’s exact words

Mean (average) of observations
📖NCERT verbatim — memorise this exact wording· Ch 13,
“The mean (or average) of observations, as we know, is the sum of the values of all the observations divided by the total number of observations.”
What it means: for grouped data you cannot see each value, so you use the class mark xi​ of each class as its stand-in: xˉ=Σfi​Σfi​xi​​.
Class mark (mid-point)
📖NCERT verbatim — memorise this exact wording· Ch 13,
“It is assumed that the frequency of each class-interval is centred around its mid-point. So the mid-point (or class mark) of each class can be chosen to represent the observations falling in the class.”
What it means: class mark=2upper limit+lower limit​. This single number represents the whole class in the mean calculation — it is your xi​.
Mode
📖NCERT verbatim — memorise this exact wording· Ch 13,
“Recall from Class IX, a mode is that value among the observations which occurs most often, that is, the value of the observation having the maximum frequency.”
What it means: the most-frequent value. For grouped data you cannot read it off directly — you locate the modal class (the class with the greatest frequency) and use the mode formula.
Median
📖NCERT verbatim — memorise this exact wording· Ch 13,
“the median is a measure of central tendency which gives the value of the middle-most observation in the data.”
What it means: the middle value once the data is ordered. For grouped data the middle observation sits inside a class, so you find the median class using cumulative frequencies and the median formula.
Modal class
📖NCERT verbatim — memorise this exact wording· Ch 13,
“In a grouped frequency distribution, it is not possible to determine the mode by looking at the frequencies. Here, we can only locate a class with the maximum frequency, called the modal class.”
What it means: the class interval with the highest frequency. Its lower limit l and the frequencies f1​ (modal), f0​ (preceding), f2​ (succeeding) feed the mode formula.
📖Key terms — NCERT verbatim (state word-for-word)
Direct Method
This new method of finding the mean is known as the Direct Method. (Ch 13, )
Assumed Mean Method
The method discussed above is called the Assumed Mean Method. (Ch 13, )
Step-deviation Method
the step-deviation method will be convenient to apply if all the di's have a common factor. (Ch 13, )
Median class
We now locate the class whose cumulative frequency is greater than (and nearest to) [n/2] This is called the median class. (Ch 13, )
Cumulative frequency
The cumulative frequency of a class is the frequency obtained by adding the frequencies of all the classes preceding the given class. (Ch 13, )
Empirical relationship
There is a empirical relationship between the three measures of central tendency : [3 Median = Mode + 2 Mean] (Ch 13, )
Must-know concepts AUTHORED FRAMING

…and where they’re tested

1
Mean of grouped data — three methods, same answer
Replace each class by its class mark xi​, then use whichever method keeps the arithmetic small: Direct xˉ=Σfi​Σfi​xi​​ · Assumed-mean xˉ=a+Σfi​Σfi​di​​ (with di​=xi​−a) · Step-deviation xˉ=a+h(Σfi​Σfi​ui​​) (with ui​=hxi​−a​). All three give the identical mean — step-deviation is fastest when the di​ share a common factor h.
3-mark “find the mean of the following distribution” — a fixture of every board paper
2
Mode of grouped data — find the modal class first
Spot the modal class (highest frequency), read off l (its lower limit), h (class size), f1​ (modal frequency), f0​ (preceding), f2​ (succeeding), then Mode=l+(2f1​−f0​−f2​f1​−f0​​)h. The commonest slip is a sign error in the denominator 2f1​−f0​−f2​.
3-mark “find the mode”, often paired with “compare and interpret the mode and the mean”
3
Median of grouped data — locate the median class via cumulative frequency
Build the cumulative frequency column, compute 2n​, and pick the median class — the first class whose cumulative frequency is ≥2n​. Then Median=l+(f2n​−cf​)h, where cf is the cumulative frequency of the class preceding the median class. Watch: cf is from the class before, not the median class itself.
3-mark “find the median”, and the reverse 5-mark “median given, find the missing frequency”
4
Which measure, and the empirical bridge
Mean uses every observation but is dragged by extreme values; median resists extremes (best for ‘typical’ wage/productivity); mode answers ‘most popular / most frequent’. When two are known, the empirical relation 3Median=Mode+2Mean estimates the third. ⚑ Syllabus note (2026-27): the graphical method of finding the median is OUT of the rationalised syllabus — here the median is computed by formula only, from a cumulative-frequency table.
“compare and interpret the two measures” parts; estimate-the-third using 3Median=Mode+2Mean

Ch 13, Example 2,
“The table below gives the percentage distribution of female teachers in the primary schools of rural areas of various states and union territories (U.T.) of India. Find the mean percentage of female teachers by all the three methods discussed in this section.”
1
Set up class marks and totals.Class marks xi​=20,30,40,50,60,70,80 with frequencies fi​=6,11,7,4,4,2,1. Taking a=50, h=10: Σfi​=35, Σfi​xi​=1390, Σfi​di​=−360, Σfi​ui​=−36.Concept: class marks + column sums
1 mark
2
Direct method.xˉ=Σfi​Σfi​xi​​=351390​=39.71.Concept: direct method
1 mark
3
Assumed-mean method.xˉ=a+Σfi​Σfi​di​​=50+35−360​=39.71 — same answer.Concept: assumed-mean method
½ mark
4
Step-deviation method.xˉ=a+h(Σfi​Σfi​ui​​)=50+10×35−36​=39.71. So the mean percentage of female teachers is 39.71.Concept: step-deviation method
½ mark
Mark-scheme logic (authored): 3-mark shape: 1 for the class-mark table and column sums, 1 for computing the mean by one method, 1 shared for confirming the other two methods give the identical 39.71. NCERT's point is that the choice of method is a convenience, not a different answer.

Problem-solving strategies AUTHORED
→
“Find the mean”?Write class marks xi​, then pick the lightest arithmetic: direct if xi​,fi​ small; assumed-mean / step-deviation if they are large or the di​ share a common factor h.
→
“Find the mode”?Circle the modal class (max frequency), read off l,h,f1​,f0​,f2​, then Mode=l+(2f1​−f0​−f2​f1​−f0​​)h.
→
“Find the median”?Build the cumulative frequency column, compute 2n​, locate the median class (first cf≥2n​), then plug l,cf,f,h into the median formula.
→
Classes look discontinuous (e.g. 118-126, 127-135)?Convert to continuous classes (117.5-126.5, 126.5-135.5, ...) BEFORE applying the mode or median formula.
→
“Median given, find the missing frequency”?Set up the cumulative frequency column with the unknowns, use n for one equation and the median formula for another, then solve the pair.
Common mistakes that cost marks

Where students lose easy marks

✕
cf is the cumulative frequency of the class PRECEDING the median class — not of the median class itself. Reading the wrong row is the commonest median error.
✕
Not converting to continuous classes before the mode/median formula (e.g. 118-126 must become 117.5-126.5) — the formulae assume continuous intervals.
✕
Sign slip in the mode denominator 2f1​−f0​−f2​ — subtract BOTH f0​ and f2​.
✕
Picking the wrong class — the modal class is the one with the maximum frequency; the median class is the first whose cumulative frequency reaches 2n​. Confusing the two wrecks the answer.

Why the assumed-mean & step-deviation formulas work

NCERT derives the assumed-mean and step-deviation formulas from the direct method (pp.174-177) — they are just simplified forms that shrink the arithmetic, not different definitions of the mean. Following the derivation shows WHY the mean comes out identical whichever method you choose, and why any convenient a and h work.

1
Pick an assumed mean a (a convenient class mark) and take the deviation of each class mark from it.
di​=xi​−a
2
Define the mean of the deviations.
dˉ=Σfi​Σfi​di​​
3
Substitute di​=xi​−a and split the sum — a is constant, so it factors out.
dˉ=Σfi​Σfi​(xi​−a)​=Σfi​Σfi​xi​​−a=xˉ−a
Σfi​Σfi​xi​​ is exactly the direct-method mean xˉ, and Σfi​aΣfi​​=a.
4
Rearrange to get the Assumed Mean Method.
xˉ=a+dˉ=a+Σfi​Σfi​di​​
5
To shrink the numbers further, scale the deviations by the class size h.
ui​=hxi​−a​,uˉ=Σfi​Σfi​ui​​=h1​(xˉ−a)
6
Rearrange to get the Step-deviation Method — and note a,h may be any convenient numbers.
xˉ=a+huˉ=a+h(Σfi​Σfi​ui​​)
The formula still holds for any non-zero h, so you choose a and h to make the columns small — that is the whole point of the method.

3 competency questions from the CBSE board pattern, with the full step-marked solution for each — the marks are shown per step, as the official scheme awards them.

5 marksSection D

A car assembly unit assembles a limited number of cars daily, depending on the prevailing demand. The table presents an analysis: cars assembled per day (0-4: 33 days, 4-8: 18 days, 8-12: 21 days, 12-16: 11 days, 16-20: 7 days). (i) If the demand of the cars is doubled, estimate how many cars on an average should be assembled per day to meet the increased demand? (ii) At least on how many days, less than average number of cars were assembled?

Step-marked solution
  1. [1 mark] Class marks xᵢ: 2, 6, 10, 14, 18; frequencies fᵢ: 33, 18, 21, 11, 7; Σfᵢ = 90.
  2. [1 mark] Σfᵢ·xᵢ = 33·2 + 18·6 + 21·10 + 11·14 + 7·18 = 66 + 108 + 210 + 154 + 126 = 664.
  3. [1 mark] Mean = Σfᵢxᵢ/Σfᵢ = 664/90 ≈ 7.38 cars per day.
  4. [1 mark] (i) For doubled demand, average required = 2 × 7.38 ≈ 14.76 ≈ 15 cars per day.
  5. [1 mark] (ii) The mean 7.38 lies in class 4-8; all 33 days in class 0-4 had fewer than 7.38 cars assembled, so on at least 33 days production was below average.
5 marksSection D

The pyramid graph shows the ages of 548 Members of Parliament (MPs) in the 17th Lok Sabha. On an average, how much younger is a female MP than a male MP? Round your answer to the nearest whole number.

Step-marked solution
  1. [1 mark] From the pyramid graph, construct grouped frequency distribution tables (class marks × frequencies) of ages for male and female MPs separately.
  2. [1 mark] Female MPs: Σfᵢ = 80, Σfᵢxᵢ = 4280 ⇒ mean age = 4280/80 = 53.5 years.
  3. [1 mark] Male MPs: Σfᵢ = 468, Σfᵢxᵢ = 27980 ⇒ mean age = 27980/468 ≈ 59.8 years.
  4. [1 mark] Difference of mean ages = 59.8 − 53.5 = 6.3 years.
  5. [1 mark] Rounded to the nearest whole number, a female MP is on average ≈ 6 years younger than a male MP.
1 markSection A

The Indian Council of Medical Research wants to analyse the age group of people affected by a certain disease. The table below shows the age distribution of patients with a certain disease admitted to a hospital. Age (in years) : Number of cases 5–14 : 6 15–24 : 11 25–34 : 21 35–44 : 23 45–54 : 14 55–64 : 5 The most highly affected age group is:

Step-marked solution
  1. [1 mark] The most highly affected age group is the class with the highest frequency. The class 35–44 has the highest frequency (23), so the answer is (iii) 35–44.
