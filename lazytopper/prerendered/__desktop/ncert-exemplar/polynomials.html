Exercise 2.1

Exemplar Ex 2.1 Q11 mark
If one of the zeroes of the quadratic polynomial (k – 1)x² + kx + 1 is −3, then the value of k is
Step 1 Substitute x = −3 into (k − 1)x² + kx + 1: (k − 1)(9) + k(−3) + 1 = 0.

Step-by-step solution

  1. Substitute x = −3 into (k − 1)x² + kx + 1: (k − 1)(9) + k(−3) + 1 = 0.
  2. 9k − 9 − 3k + 1 = 0 ⇒ 6k − 8 = 0 ⇒ k = 8/6 = 4/3.

Answer: 4/3 — option (a).

Exemplar Ex 2.1 Q31 mark
If the zeroes of the quadratic polynomial x² + (a + 1)x + b are 2 and −3, then
Step 1 Sum of zeroes: 2 + (−3) = −1 = −(a + 1) ⇒ a + 1 = 1 ⇒ a = 0.

Step-by-step solution

  1. Sum of zeroes: 2 + (−3) = −1 = −(a + 1) ⇒ a + 1 = 1 ⇒ a = 0.
  2. Product of zeroes: 2 × (−3) = −6 = b ⇒ b = −6.

Answer: a = 0, b = −6 — option (d).

Exemplar Ex 2.1 Q101 mark
If one of the zeroes of a quadratic polynomial of the form x² + ax + b is the negative of the other, then it
Step 1 If zeroes are α and −α, sum = 0 ⇒ −a/1 = 0 ⇒ a = 0 (no linear term).

Step-by-step solution

  1. If zeroes are α and −α, sum = 0 ⇒ −a/1 = 0 ⇒ a = 0 (no linear term).
  2. Product = α × (−α) = −α² ≤ 0, and < 0 if α ≠ 0. So constant term b = −α² < 0.

Answer: Option (a).

Exercise 2.3

Exemplar Ex 2.3 Q13 marks
Find the zeroes of 4x² – 3x – 1 by factorisation and verify the relationship between zeroes and coefficients.
Step 1 Split the middle term: 4x² − 4x + x − 1 = 4x(x − 1) + 1(x − 1) = (4x + 1)(x − 1).

Step-by-step solution

  1. Split the middle term: 4x² − 4x + x − 1 = 4x(x − 1) + 1(x − 1) = (4x + 1)(x − 1).
  2. Zeroes: x = −1/4 and x = 1.
  3. Sum: −1/4 + 1 = 3/4 = −(−3)/4 = −b/a. ✓
  4. Product: (−1/4)(1) = −1/4 = c/a. ✓

Answer: Zeroes: −1/4 and 1; relationships verified.

Exemplar Ex 2.3 Q23 marks
Find the zeroes of 3x² + 4x – 4 by factorisation and verify the relationship between zeroes and coefficients.
Step 1 Split the middle term: 3x² + 6x − 2x − 4 = 3x(x + 2) − 2(x + 2) = (3x − 2)(x + 2).

Step-by-step solution

  1. Split the middle term: 3x² + 6x − 2x − 4 = 3x(x + 2) − 2(x + 2) = (3x − 2)(x + 2).
  2. Zeroes: x = 2/3 and x = −2.
  3. Sum: 2/3 − 2 = −4/3 = −(4)/3 = −b/a. ✓
  4. Product: (2/3)(−2) = −4/3 = c/a. ✓

Answer: Zeroes: 2/3 and −2; relationships verified.

Exemplar Ex 2.3 Q83 marks
Find the zeroes of v² + 4√3·v – 15 and verify the relationship between zeroes and coefficients.
Step 1 Split the middle term: v² + 5√3·v − √3·v − 15 = v(v + 5√3) − √3(v + 5√3) = (v − √3)(v + 5√3).

Step-by-step solution

  1. Split the middle term: v² + 5√3·v − √3·v − 15 = v(v + 5√3) − √3(v + 5√3) = (v − √3)(v + 5√3).
  2. Zeroes: v = √3 and v = −5√3.
  3. Sum: √3 + (−5√3) = −4√3 = −(4√3)/1 = −b/a. ✓
  4. Product: (√3)(−5√3) = −15 = c/a. ✓

Answer: Zeroes: √3 and −5√3; relationships verified.

CBSE board pattern: Assertion-Reason and case-based questions

These are not NCERT Exemplar questions. Neither NCERT book has Assertion-Reason questions: they, and case-based questions, are a CBSE board-paper format. These follow that format on this chapter's 2026-27 syllabus, with solutions by LazyTopper.

CBSE board pattern · Assertion-Reason1 mark
Assertion (A): If both zeroes of a quadratic polynomial ax² + bx + c are negative, then a, b and c all have the same sign. Reason (R): For ax² + bx + c with zeroes α, β: α + β = −b/a and αβ = c/a.
Step 1 α, β < 0 ⇒ α + β < 0 and αβ > 0. So −b/a < 0 (i.e., b/a > 0) and c/a > 0.

Step-by-step solution

  1. α, β < 0 ⇒ α + β < 0 and αβ > 0. So −b/a < 0 (i.e., b/a > 0) and c/a > 0.
  2. b/a > 0 ⇒ b and a have the same sign; c/a > 0 ⇒ c and a have the same sign. Hence all three same sign. A true.
  3. R is the standard identity — true.
  4. R is the route used to derive A.

Answer: Option (A).

CBSE board pattern · Assertion-Reason1 mark
Assertion (A): If the zeroes of ax² + bx + c (with c ≠ 0) are equal, then c and a have the same sign. Reason (R): For real, equal zeroes the discriminant b² − 4ac = 0 and the common root is −b/(2a), whose square equals c/a.
Step 1 Equal zeroes α = β ⇒ αβ = α² ≥ 0, and > 0 if α ≠ 0. αβ = c/a > 0 ⇒ c and a have same sign. A true.

Step-by-step solution

  1. Equal zeroes α = β ⇒ αβ = α² ≥ 0, and > 0 if α ≠ 0. αβ = c/a > 0 ⇒ c and a have same sign. A true.
  2. R is the standard discriminant relation — true.
  3. R justifies why c/a is positive (= α²), which directly gives A.

Answer: Option (A).

CBSE board pattern · Case-based4 marks
A bridge’s arch is modelled by p(x) = x² + (k + 1)x + b. Surveyors find that the arch lands on the x-axis at x = 2 and x = −3. (i) Find b using the product of zeroes. (ii) Find k using the sum of zeroes. (iii) Write the polynomial explicitly. (iv) Verify that x = 2 is indeed a zero of your polynomial.
Step 1 (i) Product of zeroes 2 × (−3) = −6 = b ⇒ b = −6.

Step-by-step solution

  1. (i) Product of zeroes 2 × (−3) = −6 = b ⇒ b = −6.
  2. (ii) Sum of zeroes 2 + (−3) = −1 = −(k + 1) ⇒ k + 1 = 1 ⇒ k = 0.
  3. (iii) p(x) = x² + (0 + 1)x − 6 = x² + x − 6.
  4. (iv) p(2) = 4 + 2 − 6 = 0 ✓.

Answer: (i) b = −6; (ii) k = 0; (iii) p(x) = x² + x − 6; (iv) verified.
