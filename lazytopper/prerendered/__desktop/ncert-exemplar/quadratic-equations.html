Exemplar Ex 4.1 Q31 mark
Which of the following equations has 2 as a root?
Step 1 Test x = 2 in each option.

Step-by-step solution

  1. Test x = 2 in each option.
  2. (a) 4 − 8 + 5 = 1 ≠ 0.
  3. (b) 4 + 6 − 12 = −2 ≠ 0.
  4. (c) 2(4) − 7(2) + 6 = 8 − 14 + 6 = 0 ✓.
  5. (d) 12 − 12 − 2 = −2 ≠ 0.
  6. Therefore option (c) has 2 as a root.

Answer: 2x² − 7x + 6 = 0 — option (c).

Exemplar Ex 4.1 Q41 mark
If 1/2 is a root of the equation x² + kx − 5/4 = 0, then the value of k is:
Step 1 Substitute x = 1/2 in the equation: (1/2)² + k(1/2) − 5/4 = 0.

Step-by-step solution

  1. Substitute x = 1/2 in the equation: (1/2)² + k(1/2) − 5/4 = 0.
  2. 1/4 + k/2 − 5/4 = 0 ⇒ k/2 − 4/4 = 0 ⇒ k/2 = 1 ⇒ k = 2.

Answer: k = 2 — option (a).

Exemplar Ex 4.1 Q61 mark
The values of k for which the quadratic equation 2x² − kx + k = 0 has equal roots are:
Step 1 Equal roots ⇔ D = b² − 4ac = 0.

Step-by-step solution

  1. Equal roots ⇔ D = b² − 4ac = 0.
  2. Here a = 2, b = −k, c = k ⇒ D = k² − 4(2)(k) = k² − 8k.
  3. Set D = 0: k² − 8k = 0 ⇒ k(k − 8) = 0 ⇒ k = 0 or k = 8.
  4. Both values give a quadratic (a = 2 ≠ 0), so both are valid.

Answer: k = 0 or k = 8 — option (d).

Exemplar Ex 4.1 Q81 mark
The quadratic equation 2x² − √5 x + 1 = 0 has:
Step 1 Here a = 2, b = −√5, c = 1.

Step-by-step solution

  1. Here a = 2, b = −√5, c = 1.
  2. D = b² − 4ac = (√5)² − 4(2)(1) = 5 − 8 = −3 < 0.
  3. Since D < 0, the equation has no real roots.

Answer: No real roots — option (c).

Exemplar Ex 4.1 Q91 mark
Which of the following equations has two distinct real roots?
Step 1 (a) D = (3√2)² − 4(2)(9/4) = 18 − 18 = 0 → equal roots.

Step-by-step solution

  1. (a) D = (3√2)² − 4(2)(9/4) = 18 − 18 = 0 → equal roots.
  2. (b) D = 1 − 4(1)(−5) = 1 + 20 = 21 > 0 → two distinct real roots. ✓
  3. (c) D = 9 − 4(1)(2√2) = 9 − 8√2 ≈ 9 − 11.31 < 0 → no real roots.
  4. (d) D = 9 − 20 = −11 < 0 → no real roots.
  5. Only option (b) has D > 0 → two distinct real roots.

Answer: x² + x − 5 = 0 — option (b).

Which of the following equations has no real roots?
Step 1 (a) D = 16 − 4·3√2 = 16 − 12√2 ≈ 16 − 16.97 < 0 → no real roots. ✓

  2. (b) D = 16 + 12√2 > 0 → real roots.

Exemplar Ex 4.2 Q2(iv)2 marks
Is the statement 'Every quadratic equation has at most two roots' true or false? Justify.
Step 1 A quadratic equation is ax² + bx + c = 0 with a ≠ 0.

Step-by-step solution

  1. A quadratic equation is ax² + bx + c = 0 with a ≠ 0.
  2. The associated polynomial has degree 2.
  3. By the standard result, a degree-n polynomial has at most n roots over the reals (or complexes).
  4. Hence a quadratic has at most 2 roots — statement is TRUE.

Answer: TRUE — a quadratic (degree 2) has at most 2 roots.

Exemplar Ex 4.2 Q62 marks
Is 0.2 a root of the equation x² − 0.4 = 0? Justify.
Step 1 Substitute x = 0.2 into x² − 0.4: (0.2)² − 0.4 = 0.04 − 0.4 = −0.36 ≠ 0.

Step-by-step solution

  1. Substitute x = 0.2 into x² − 0.4: (0.2)² − 0.4 = 0.04 − 0.4 = −0.36 ≠ 0.
  2. Hence 0.2 is NOT a root.
  3. Solving x² = 0.4 gives x = ±√0.4 = ±(√10)/5 ≈ ±0.632, which are the actual roots.

Answer: No — 0.2 does not satisfy x² − 0.4 = 0.

Exemplar Ex 4.2 Q72 marks
If b = 0 and c < 0, are the roots of x² + bx + c = 0 numerically equal and opposite in sign? Justify.
Step 1 Set b = 0: x² + c = 0 ⇒ x² = −c.

Step-by-step solution

  1. Set b = 0: x² + c = 0 ⇒ x² = −c.
  2. Given c < 0, so −c > 0 and √(−c) is real and positive.
  3. Roots: x = +√(−c) and x = −√(−c).
  4. These are equal in magnitude (|x| = √(−c)) and opposite in sign (one +, one −).
  5. Hence the claim is TRUE.

Answer: Yes — roots are ±√(−c), equal in magnitude and opposite in sign.

Exemplar Ex 4.2 Q42 marks
Does there exist a quadratic equation whose coefficients are rational but both of its roots are irrational? Justify.
Step 1 Pick example: x² − 4x + 1 = 0 with rational coefficients.

Step-by-step solution

  1. Pick example: x² − 4x + 1 = 0 with rational coefficients.
  2. D = 16 − 4 = 12; √12 = 2√3, an irrational number.
  3. Roots: x = (4 ± 2√3)/2 = 2 ± √3 — both irrational.
  4. Hence such a quadratic exists. Note that irrational roots of a rational-coefficient quadratic must occur in conjugate pairs.

Answer: Yes — e.g., x² − 4x + 1 = 0 has roots 2 ± √3 (both irrational).

Exercise 4.3

Exemplar Ex 4.3 Q1(i)3 marks
Find the roots of 2x² − 3x − 5 = 0 by using the quadratic formula.
Step 1 Identify a = 2, b = −3, c = −5.

Step-by-step solution

  1. Identify a = 2, b = −3, c = −5.
  2. D = b² − 4ac = 9 − 4(2)(−5) = 9 + 40 = 49 > 0 (two distinct real roots).
  3. Apply quadratic formula: x = (−b ± √D)/(2a) = (3 ± 7)/4.
  4. x = 10/4 = 5/2 or x = −4/4 = −1.
  5. Verify x = −1: 2(1) − 3(−1) − 5 = 2 + 3 − 5 = 0 ✓

Answer: x = 5/2 or x = −1.

Exemplar Ex 4.3 Q1(ii)3 marks
Find the roots of 5x² + 13x + 8 = 0 by using the quadratic formula.
Step 1 a = 5, b = 13, c = 8.

Step-by-step solution

  1. a = 5, b = 13, c = 8.
  2. D = 13² − 4(5)(8) = 169 − 160 = 9 > 0.
  3. x = (−13 ± 3)/10 ⇒ x = −10/10 = −1 or x = −16/10 = −8/5.
  4. Verify x = −1: 5(1) + 13(−1) + 8 = 5 − 13 + 8 = 0 ✓

Answer: x = −1 or x = −8/5.

Exemplar Ex 4.3 Q1(v)3 marks
Find the roots of x² + 2√2 x − 6 = 0 using the quadratic formula.
Step 1 a = 1, b = 2√2, c = −6.

Step-by-step solution

  1. a = 1, b = 2√2, c = −6.
  2. D = (2√2)² − 4(1)(−6) = 8 + 24 = 32 > 0.
  3. √D = √32 = 4√2.
  4. x = (−2√2 ± 4√2)/2 = (−2√2 + 4√2)/2 or (−2√2 − 4√2)/2 = (2√2)/2 or (−6√2)/2 = √2 or −3√2.
  5. Verify x = √2: (√2)² + 2√2·√2 − 6 = 2 + 4 − 6 = 0 ✓

Answer: x = √2 or x = −3√2.

Exemplar Ex 4.3 Q2(i)3 marks
Find the roots of 2x² + (5/3)x − 2 = 0 by the factorisation method.
Step 1 Multiply through by 3 to clear fractions: 6x² + 5x − 6 = 0.

Step-by-step solution

  1. Multiply through by 3 to clear fractions: 6x² + 5x − 6 = 0.
  2. Product ac = 6·(−6) = −36; need two numbers with product −36 and sum +5: +9 and −4.
  3. Split: 6x² + 9x − 4x − 6 = 0 ⇒ 3x(2x + 3) − 2(2x + 3) = 0 ⇒ (2x + 3)(3x − 2) = 0.
  4. x = −3/2 or x = 2/3.
  5. Verify x = 2/3: 2(4/9) + (5/3)(2/3) − 2 = 8/9 + 10/9 − 18/9 = 0 ✓

Answer: x = 2/3 or x = −3/2.

Exemplar Ex 4.4 Q1(i)3 marks
Find whether 8x² + 2x − 3 = 0 has real roots. If real roots exist, find them.
Step 1 a = 8, b = 2, c = −3.

Step-by-step solution

  1. a = 8, b = 2, c = −3.
  2. D = 4 − 4(8)(−3) = 4 + 96 = 100 > 0 → two distinct real roots.
  3. x = (−2 ± 10)/16 ⇒ x = 8/16 = 1/2 or x = −12/16 = −3/4.
  4. Verify x = 1/2: 8(1/4) + 2(1/2) − 3 = 2 + 1 − 3 = 0 ✓

Answer: Real roots: x = 1/2 or x = −3/4.

Exemplar Ex 4.4 Q23 marks
Find a natural number whose square diminished by 84 is equal to thrice of 8 more than the given number.
Step 1 Let the natural number be x. Form equation: x² − 84 = 3(x + 8).

Step-by-step solution

  1. Let the natural number be x. Form equation: x² − 84 = 3(x + 8).
  2. Simplify: x² − 84 = 3x + 24 ⇒ x² − 3x − 108 = 0.
  3. Factorise: x² − 12x + 9x − 108 = 0 ⇒ x(x − 12) + 9(x − 12) = 0 ⇒ (x − 12)(x + 9) = 0.
  4. x = 12 or x = −9. Reject x = −9 (must be natural). Hence x = 12.
  5. Verify: 12² − 84 = 144 − 84 = 60 and 3(12 + 8) = 60 ✓

Answer: The natural number is 12.

Exemplar Ex 4.4 Q33 marks
A natural number, when increased by 12, equals 160 times its reciprocal. Find the number.
Step 1 Let the natural number be x. Equation: x + 12 = 160/x.

Step-by-step solution

  1. Let the natural number be x. Equation: x + 12 = 160/x.
  2. Multiply by x (valid since x > 0): x² + 12x = 160 ⇒ x² + 12x − 160 = 0.
  3. Factorise: x² + 20x − 8x − 160 = 0 ⇒ x(x + 20) − 8(x + 20) = 0 ⇒ (x − 8)(x + 20) = 0.
  4. x = 8 or x = −20. Reject negative (must be natural). x = 8.
  5. Verify: 8 + 12 = 20 and 160/8 = 20 ✓

Answer: The natural number is 8.

Exemplar Ex 4.4 Q55 marks
If Zeba were younger by 5 years than what she really is, then the square of her age (in years) would have been 11 more than five times her actual age. What is her age now?
Step 1 Let Zeba's actual age be x years. Her 'younger by 5 years' age = (x − 5) years.

Step-by-step solution

  1. Let Zeba's actual age be x years. Her 'younger by 5 years' age = (x − 5) years.
  2. Equation: (x − 5)² = 5x + 11.
  3. Expand: x² − 10x + 25 = 5x + 11 ⇒ x² − 15x + 14 = 0.
  4. Factorise: x² − 14x − x + 14 = 0 ⇒ x(x − 14) − 1(x − 14) = 0 ⇒ (x − 14)(x − 1) = 0.
  5. x = 14 or x = 1. Reject x = 1 (then x − 5 = −4, age cannot be negative). So x = 14.
  6. Verify: (14 − 5)² = 81 and 5(14) + 11 = 81 ✓

Answer: Zeba's present age is 14 years.

Exemplar Ex 4.4 Q65 marks
At present Asha's age (in years) is 2 more than the square of her daughter Nisha's age. When Nisha grows to her mother's present age, Asha's age would be one year less than 10 times the present age of Nisha. Find the present ages of both Asha and Nisha.
Step 1 Let Nisha's present age = x years. Then Asha's present age = x² + 2 years.

Step-by-step solution

  1. Let Nisha's present age = x years. Then Asha's present age = x² + 2 years.
  2. After (Asha's_present − x) = (x² + 2 − x) years, Nisha will be x² + 2 (Asha's present age). At that time, Asha's age = (x² + 2) + (x² + 2 − x) = 2x² − x + 4.
  3. Given: 2x² − x + 4 = 10x − 1 ⇒ 2x² − 11x + 5 = 0.
  4. Factorise: 2x² − 10x − x + 5 = 0 ⇒ 2x(x − 5) − 1(x − 5) = 0 ⇒ (x − 5)(2x − 1) = 0.
  5. x = 5 or x = 1/2. Age must be a whole number → x = 5. Nisha = 5 years. Asha = 5² + 2 = 27 years.
  6. Verify: When Nisha grows to 27, that is in 22 years; Asha will be 27 + 22 = 49 = 10(5) − 1 ✓

Answer: Nisha = 5 years, Asha = 27 years.

Exemplar Sample LA Q25 marks
Had Ajita scored 10 more marks in her Mathematics test out of 30 marks, 9 times these new marks would have been the square of her actual marks. How many marks did she get in the test?
Step 1 Let Ajita's actual marks be x. 'If she had scored 10 more' = x + 10. The condition gives 9(x + 10) = x².

Step-by-step solution

  1. Let Ajita's actual marks be x. 'If she had scored 10 more' = x + 10. The condition gives 9(x + 10) = x².
  2. Expand: 9x + 90 = x² ⇒ x² − 9x − 90 = 0.
  3. Factorise: x² − 15x + 6x − 90 = 0 ⇒ x(x − 15) + 6(x − 15) = 0 ⇒ (x − 15)(x + 6) = 0.
  4. x = 15 or x = −6. Reject negative (marks ≥ 0). So x = 15.
  5. Verify: 9(15 + 10) = 9 × 25 = 225 = 15² ✓ Also 15 ≤ 30 (test out of 30) — valid.

Answer: Ajita scored 15 marks.
