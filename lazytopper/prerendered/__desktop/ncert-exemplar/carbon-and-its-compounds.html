Exemplar Q121 mark
Identify the unsaturated compounds from the following (i) Propane (ii) Propene (iii) Propyne (iv) Chloropropane

Step-by-step solution

  1. Unsaturated = has C=C or C≡C.
  2. Propene has C=C; propyne has C≡C. Propane (single bonds) and chloropropane (single bonds + Cl) are saturated.
  3. So unsaturated = (ii) and (iii). Answer: (D)

Answer: (ii) and (iii) — option (d)

Exemplar Q353 marks
Name the functional groups present in the following compounds: (a) CH₃-CO-CH₂-CH₂-CH₂-CH₃ (b) CH₃-CH₂-CH₂-COOH (c) CH₃-CH₂-CH₂-CH₂-CHO (d) CH₃-CH₂-OH

Step-by-step solution

  1. (a) CO between two C → ketone.
  2. (b) COOH at end → carboxylic acid.
  3. (c) CHO at end → aldehyde.
  4. (d) OH on terminal C → alcohol.

Answer: (a) ketone; (b) carboxylic acid; (c) aldehyde; (d) alcohol.

Exemplar Q363 marks
How is ethene prepared from ethanol? Give the reaction involved in it.

Step-by-step solution

  1. Ethanol + conc. H₂SO₄ at 443 K → dehydration.
  2. C₂H₅OH → C₂H₄ + H₂O.
  3. Conc. H₂SO₄ removes H from one C and OH from adjacent C, forming H₂O and ethene.

Answer: C₂H₅OH --(conc.H₂SO₄, 443K)--> C₂H₄ + H₂O.

Exemplar Q393 marks
Ethene is formed when ethanol at 443 K is heated with excess of concentrated sulphuric acid. What is the role of sulphuric acid in this reaction? Write the balanced chemical equation of this reaction.

Step-by-step solution

  1. Conc. H₂SO₄ is a strong dehydrating agent.
  2. Removes H from one C and OH from adjacent C of ethanol, forming H₂O.
  3. The C-C left behind becomes C=C → ethene formed.
  4. Reaction: C₂H₅OH → C₂H₄ + H₂O (catalysed by conc. H₂SO₄ at 443K).

Answer: H₂SO₄ acts as a dehydrating agent. C₂H₅OH → C₂H₄ + H₂O (at 443K).

Exemplar Q443 marks
Match the reactions given in Column (A) with the names given in Column (B): (a) CH₃OH + CH₃COOH → CH₃COOCH₃ + H₂O — (i) Addition reaction (b) CH₂=CH₂ + H₂ → CH₃-CH₃ — (ii) Substitution reaction (c) CH₄ + Cl₂ → CH₃Cl + HCl — (iii) Neutralisation reaction (d) CH₃COOH + NaOH → CH₃COONa + H₂O — (iv) Esterification reaction

Step-by-step solution

  1. (a) Acid + alcohol → ester + water = esterification → (iv).
  2. (b) H₂ adds across C=C → addition → (i).
  3. (c) H replaced by Cl → substitution → (ii).
  4. (d) Acid + base → salt + water → neutralisation → (iii).

Answer: (a)-(iv), (b)-(i), (c)-(ii), (d)-(iii).

Long answer questions

Exemplar Q525 marks
A compound C (molecular formula, C₂H₄O₂) reacts with Na-metal to form a compound R and evolves a gas which burns with a pop sound. Compound C on treatment with an alcohol A in presence of an acid forms a sweet smelling compound S (molecular formula, C₃H₆O₂). On addition of NaOH to C, it also gives R and water. S on treatment with NaOH solution gives back R and A. Identify C, R, A, S and write down the reactions involved.

Step-by-step solution

  1. C₂H₄O₂ = ethanoic acid CH₃COOH (acidic, reacts with Na evolving H₂).
  2. Na + acid: 2CH₃COOH + 2Na → 2CH₃COONa + H₂. R = CH₃COONa.
  3. S has formula C₃H₆O₂ (one more C and 2 more H than C). Esterification of CH₃COOH with alcohol A → ester S.
  4. If alcohol A = CH₃OH (methanol), the ester is CH₃COOCH₃ (methyl ethanoate, C₃H₆O₂). ✓
  5. (iii) acid + base: CH₃COOH + NaOH → CH₃COONa (R) + H₂O ✓.
  6. (iv) saponification: CH₃COOCH₃ + NaOH → CH₃COONa + CH₃OH (R + A) ✓.

Answer: C = CH₃COOH; R = CH₃COONa; A = CH₃OH; S = CH₃COOCH₃.
