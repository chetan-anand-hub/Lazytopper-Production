Exemplar Ex 3.1 Q21 mark
The pair of equations x + 2y + 5 = 0 and −3x − 6y + 1 = 0 has:
Step 1 a₁/a₂ = 1/−3 = −1/3; b₁/b₂ = 2/−6 = −1/3; c₁/c₂ = 5/1 = 5.

Step-by-step solution

  1. a₁/a₂ = 1/−3 = −1/3; b₁/b₂ = 2/−6 = −1/3; c₁/c₂ = 5/1 = 5.
  2. a₁/a₂ = b₁/b₂ ≠ c₁/c₂ → parallel lines → no solution.

Answer: No solution — option (d).

Exemplar Ex 3.1 Q31 mark
If a pair of linear equations is consistent, then the lines will be:
Step 1 A consistent pair has at least one solution.

Step-by-step solution

  1. A consistent pair has at least one solution.
  2. Intersecting lines → unique solution (consistent).
  3. Coincident lines → infinitely many solutions (consistent and dependent).
  4. Parallel lines have no solution → inconsistent. Hence consistent pairs are 'intersecting or coincident'.

Answer: Intersecting or coincident — option (c).

Exemplar Ex 3.1 Q41 mark
The pair of equations y = 0 and y = −7 has:
Step 1 y = 0 is the x-axis; y = −7 is a horizontal line 7 units below the x-axis.

Step-by-step solution

  1. y = 0 is the x-axis; y = −7 is a horizontal line 7 units below the x-axis.
  2. Both lines are horizontal and distinct → they are parallel and never meet.
  3. Therefore the pair has no solution.

Answer: No solution — option (d).

Exemplar Ex 3.1 Q61 mark
For what value of k do the equations 3x − y + 8 = 0 and 6x − ky = −16 represent coincident lines?
Step 1 Rewrite as 3x − y + 8 = 0 and 6x − ky + 16 = 0.

Step-by-step solution

  1. Rewrite as 3x − y + 8 = 0 and 6x − ky + 16 = 0.
  2. For coincident lines: a₁/a₂ = b₁/b₂ = c₁/c₂.
  3. 3/6 = −1/−k = 8/16 → 1/2 = 1/k = 1/2.
  4. From 1/k = 1/2: k = 2.

Answer: k = 2 — option (c).

Exemplar Ex 3.1 Q71 mark
If the lines given by 3x + 2ky = 2 and 2x + 5y + 1 = 0 are parallel, then the value of k is:
Step 1 For parallel lines: a₁/a₂ = b₁/b₂ but ≠ c₁/c₂.

Step-by-step solution

  1. For parallel lines: a₁/a₂ = b₁/b₂ but ≠ c₁/c₂.
  2. 3/2 = 2k/5 → 4k = 15 → k = 15/4.
  3. Check c₁/c₂ = −2/1 = −2 ≠ 3/2 ✓ (still parallel, not coincident).

Answer: k = 15/4 — option (c).

Exemplar Ex 3.1 Q81 mark
The value of c for which the pair of equations cx − y = 2 and 6x − 2y = 3 will have infinitely many solutions is:
Step 1 For infinitely many solutions: c/6 = −1/−2 = −2/−3.

Step-by-step solution

  1. For infinitely many solutions: c/6 = −1/−2 = −2/−3.
  2. c/6 = 1/2 → c = 3.
  3. But c/6 = 2/3 → c = 4. These do not agree.
  4. Hence no value of c makes all three ratios equal → 'no value'.

Answer: No value — option (d).

Exemplar Ex 3.1 Q91 mark
One equation of a pair of dependent linear equations is −5x + 7y = 2. The second equation can be:
Step 1 Dependent pair ⇒ second equation is a non-zero scalar multiple of the first.

Step-by-step solution

  1. Dependent pair ⇒ second equation is a non-zero scalar multiple of the first.
  2. First equation: −5x + 7y − 2 = 0. Multiply by −2: 10x − 14y + 4 = 0 ⇒ 10x − 14y = −4.
  3. Option (d) matches; the others are not scalar multiples.

Answer: 10x − 14y = −4 — option (d).

Exemplar Ex 3.1 Q111 mark

Exemplar Ex 3.1 Q121 mark
Aruna has only ₹1 and ₹2 coins. The total number of coins is 50 and the total amount with her is ₹75. The number of ₹1 and ₹2 coins are respectively:
Step 1 Let x = number of ₹1 coins and y = number of ₹2 coins.

Step-by-step solution

  1. Let x = number of ₹1 coins and y = number of ₹2 coins.
  2. Count: x + y = 50; Value: x + 2y = 75.
  3. Subtract: y = 25; then x = 25.
  4. Hence 25 coins of each denomination.

Exemplar Ex 3.1 Q131 mark
The father's age is six times his son's age. Four years hence, the age of the father will be four times his son's age. The present ages, in years, of the son and the father are, respectively:
Step 1 Let son's age = y and father's age = x. Then x = 6y …(1).

Step-by-step solution

  1. Let son's age = y and father's age = x. Then x = 6y …(1).
  2. Four years hence: x + 4 = 4(y + 4) → x = 4y + 12 …(2).
  3. From (1) and (2): 6y = 4y + 12 → 2y = 12 → y = 6.
  4. Then x = 36. Son = 6 yr, Father = 36 yr.

Answer: Son = 6, Father = 36 — option (c).

Exemplar Ex 3.2 Q1(i)2 marks
Does the pair 2x + 4y = 3 and 12y + 6x = 6 have no solution? Justify.
Step 1 Rewrite in standard form: 2x + 4y − 3 = 0 and 6x + 12y − 6 = 0.

Step-by-step solution

  1. Rewrite in standard form: 2x + 4y − 3 = 0 and 6x + 12y − 6 = 0.
  2. a₁/a₂ = 1/3, b₁/b₂ = 1/3, c₁/c₂ = 1/2.
  3. Two ratios equal but third differs ⇒ parallel lines.
  4. Conclusion: no solution — the statement 'no solution' is true.

Answer: Yes — the pair has no solution (parallel lines).

Exemplar Ex 3.2 Q3(iv)2 marks
Do the equations x + 3y − 11 = 0 and 2(2x + 6y) = 22 have infinitely many solutions? Justify.
Step 1 Simplify second equation: 2(2x + 6y) = 22 → 4x + 12y = 22 → 2x + 6y = 11.

Step-by-step solution

  1. Simplify second equation: 2(2x + 6y) = 22 → 4x + 12y = 22 → 2x + 6y = 11.
  2. Now compare with x + 3y = 11: a₁/a₂ = 1/2, b₁/b₂ = 3/6 = 1/2, c₁/c₂ = 11/11 = 1.
  3. Since a₁/a₂ = b₁/b₂ ≠ c₁/c₂, the lines are parallel — NO solution.
  4. Hence the pair is inconsistent, not dependent.

Answer: No — the pair is inconsistent (parallel lines), not infinitely many.

Exemplar Ex 3.2 Q62 marks
The line represented by x = 7 is parallel to the x-axis. Justify whether the statement is true or not.
Step 1 The equation x = 7 fixes x while allowing y to be any value → set of points (7, y).

Step-by-step solution

  1. The equation x = 7 fixes x while allowing y to be any value → set of points (7, y).
  2. All these points lie on a vertical line at x = 7.
  3. A vertical line is parallel to the y-axis (and perpendicular to the x-axis).
  4. Hence the statement is false.

Answer: False — x = 7 is parallel to the y-axis, not the x-axis.

Exemplar Ex 3.2 Q52 marks
For all real values of c, the pair x − 2y = 8 and 5x − 10y = c has a unique solution. True or false? Justify.
Step 1 Compute a₁/a₂ = 1/5 and b₁/b₂ = (−2)/(−10) = 1/5.

Step-by-step solution

  1. Compute a₁/a₂ = 1/5 and b₁/b₂ = (−2)/(−10) = 1/5.
  2. Since a₁/a₂ = b₁/b₂, the lines cannot be intersecting (which requires a₁/a₂ ≠ b₁/b₂).
  3. Depending on c, they are coincident (c = 40, c₁/c₂ = 1/5 too) or parallel (any other c).
  4. In neither case do we get a UNIQUE solution. Statement is false.

Answer: False — a₁/a₂ = b₁/b₂ forces parallel or coincident, never unique.

Exercise 3.3

Exemplar Ex 3.3 Q13 marks
For which value(s) of λ does the pair λx + y = λ² and x + λy = 1 have (i) no solution, (ii) infinitely many solutions, (iii) a unique solution?
Step 1 Standard form: a₁ = λ, b₁ = 1, c₁ = −λ²; a₂ = 1, b₂ = λ, c₂ = −1.

Step-by-step solution

  1. Standard form: a₁ = λ, b₁ = 1, c₁ = −λ²; a₂ = 1, b₂ = λ, c₂ = −1.
  2. a₁/a₂ = λ, b₁/b₂ = 1/λ, c₁/c₂ = λ².
  3. (i) No solution: a₁/a₂ = b₁/b₂ but ≠ c₁/c₂ → λ = 1/λ ⇒ λ² = 1 ⇒ λ = ±1; check c₁/c₂. At λ = −1: λ = 1/λ = −1, c₁/c₂ = 1 ≠ −1 ✓ parallel.
  4. (ii) Infinitely many: all three equal → λ = 1/λ = λ². λ = ±1; for λ = 1, all ratios = 1 ✓.
  5. (iii) Unique: a₁/a₂ ≠ b₁/b₂ → λ ≠ 1/λ → λ² ≠ 1 → λ ≠ ±1.

Answer: (i) λ = −1, (ii) λ = 1, (iii) λ ≠ ±1.

Exemplar Ex 3.3 Q23 marks
For which value(s) of k will the pair of equations kx + 3y = k − 3 and 12x + ky = k have no solution?
Step 1 Standard form: a₁ = k, b₁ = 3, c₁ = −(k − 3); a₂ = 12, b₂ = k, c₂ = −k.

Step-by-step solution

  1. Standard form: a₁ = k, b₁ = 3, c₁ = −(k − 3); a₂ = 12, b₂ = k, c₂ = −k.
  2. Ratios: k/12, 3/k, (k − 3)/k.
  3. For no solution: k/12 = 3/k AND k/12 ≠ (k − 3)/k.
  4. From k/12 = 3/k: k² = 36 → k = ±6.
  5. Check k = 6: 6/12 = 1/2 and 3/6 = 1/2 and 3/6 = 1/2 → all equal → infinitely many → reject.
  6. Check k = −6: −6/12 = −1/2 and 3/−6 = −1/2 and −9/−6 = 3/2 ≠ −1/2 → 'no solution' ✓. Answer: k = −6.

Answer: k = −6.

Exemplar Ex 3.3 Q33 marks
For which values of a and b will the pair x + 2y = 1 and (a − b)x + (a + b)y = a + b − 2 have infinitely many solutions?
Step 1 Set up: 1/(a − b) = 2/(a + b) = 1/(a + b − 2).

Step-by-step solution

  1. Set up: 1/(a − b) = 2/(a + b) = 1/(a + b − 2).
  2. From the first two: (a + b) = 2(a − b) → a + b = 2a − 2b → 3b = a, i.e., a = 3b.
  3. From the last two: 2(a + b − 2) = (a + b) → a + b − 4 = 0 → a + b = 4.
  4. Combine: a = 3b and a + b = 4 → 4b = 4 → b = 1; then a = 3.
  5. Hence a = 3, b = 1.

Answer: a = 3 and b = 1.

Exemplar Ex 3.3 Q53 marks
Two straight paths are represented by the equations x − 3y = 2 and −2x + 6y = 5. Check whether the paths cross each other or not.
Step 1 Standard form: x − 3y − 2 = 0 and −2x + 6y − 5 = 0.

Step-by-step solution

  1. Standard form: x − 3y − 2 = 0 and −2x + 6y − 5 = 0.
  2. Ratios: a₁/a₂ = −1/2, b₁/b₂ = −1/2, c₁/c₂ = 2/5.
  3. a₁/a₂ = b₁/b₂ but ≠ c₁/c₂ → parallel.
  4. Since parallel lines never meet, the two paths do not cross.

Answer: The paths do not cross — the lines are parallel.

Exemplar Ex 3.3 Q73 marks
If 2x + y = 23 and 4x − y = 19, find the values of (5y − 2x) and (y/x − 2).
Step 1 Add (2x + y) + (4x − y) = 23 + 19 → 6x = 42 → x = 7.

Step-by-step solution

  1. Add (2x + y) + (4x − y) = 23 + 19 → 6x = 42 → x = 7.
  2. Substitute in 2x + y = 23: 14 + y = 23 → y = 9.
  3. 5y − 2x = 5(9) − 2(7) = 45 − 14 = 31.
  4. y/x − 2 = 9/7 − 2 = 9/7 − 14/7 = −5/7.

Answer: 5y − 2x = 31 and y/x − 2 = −5/7.

Exemplar Ex 3.3 Q9(v)3 marks
Solve: 43x + 67y = −24 and 67x + 43y = 24.
Step 1 Add the two equations: (43 + 67)x + (67 + 43)y = −24 + 24 → 110x + 110y = 0 → x + y = 0 …(A).

Step-by-step solution

  1. Add the two equations: (43 + 67)x + (67 + 43)y = −24 + 24 → 110x + 110y = 0 → x + y = 0 …(A).
  2. Subtract first from second: (67 − 43)x + (43 − 67)y = 24 − (−24) → 24x − 24y = 48 → x − y = 2 …(B).
  3. Add (A) and (B): 2x = 2 → x = 1.
  4. From (A): y = −x = −1. Hence (x, y) = (1, −1).

Answer: x = 1, y = −1.

Exemplar Ex 3.4 Q45 marks
The cost of 4 pens and 4 pencil boxes is ₹100. Three times the cost of a pen is ₹15 more than the cost of a pencil box. Form the pair of linear equations and find the cost of a pen and of a pencil box.
Step 1 Let cost of one pen = ₹x and cost of one pencil box = ₹y.

Step-by-step solution

  1. Let cost of one pen = ₹x and cost of one pencil box = ₹y.
  2. Total cost: 4x + 4y = 100 → x + y = 25 …(1).
  3. Relation: 3x = y + 15 → 3x − y = 15 …(2).
  4. Add (1) and (2): 4x = 40 → x = 10.
  5. From (1): y = 25 − 10 = 15. Pen costs ₹10, pencil box ₹15.

Answer: Pen = ₹10 and Pencil box = ₹15.

CBSE board pattern: Assertion-Reason and case-based questions

These are not NCERT Exemplar questions. Neither NCERT book has Assertion-Reason questions: they, and case-based questions, are a CBSE board-paper format. These follow that format on this chapter's 2026-27 syllabus, with solutions by LazyTopper.

CBSE board pattern · Case-based4 marks
Akhila went to a village fair with ₹20. She wanted to enjoy rides on the Giant Wheel and play Hoopla. The number of times she played Hoopla is half the number of rides she had on the Giant Wheel. Each Giant-Wheel ride costs ₹3 and a game of Hoopla costs ₹4, and she spent the entire ₹20. Let x = number of Giant-Wheel rides and y = number of times she played Hoopla. (i) Form a pair of linear equations representing the situation. (ii) Solve graphically (describe lines and intersection). (iii) How many rides and games did she have? (iv) Verify algebraically.
Step 1 Translate to equations: y = x/2 ⇒ x − 2y = 0 …(1); total spend 3x + 4y = 20 …(2).

Step-by-step solution

  1. Translate to equations: y = x/2 ⇒ x − 2y = 0 …(1); total spend 3x + 4y = 20 …(2).
  2. Graphical: Eq (1) passes through (0, 0), (2, 1), (4, 2); Eq (2) passes through (0, 5), (4, 2). Lines meet at (4, 2).
  3. Algebraic check: from (1), x = 2y. Substitute in (2): 3(2y) + 4y = 20 → 10y = 20 → y = 2; x = 4.
  4. Conclusion: 4 rides on the Giant Wheel and 2 games of Hoopla.
  5. Verification: 4 − 2(2) = 0 ✓; 3(4) + 4(2) = 20 ✓.

Answer: Akhila had 4 Giant-Wheel rides and 2 games of Hoopla.

CBSE board pattern · Case-based4 marks
The taxi fare in a city consists of a fixed charge together with a charge proportional to the distance covered. For a distance of 10 km, the charge paid is ₹105 and for a journey of 15 km, the charge paid is ₹155. Let the fixed charge be ₹x and the per-km charge be ₹y. (i) Form the pair of linear equations. (ii) Find the fixed charge and the per-km rate. (iii) How much does a person have to pay for travelling 25 km?
Step 1 Let fixed charge = ₹x and per-km charge = ₹y.

Step-by-step solution

  1. Let fixed charge = ₹x and per-km charge = ₹y.
  2. 10 km journey: x + 10y = 105 …(1). 15 km journey: x + 15y = 155 …(2).
  3. Subtract (1) from (2): 5y = 50 → y = 10. Then from (1): x = 105 − 100 = 5.
  4. So fixed charge = ₹5 and per-km charge = ₹10.
  5. Fare for 25 km = x + 25y = 5 + 250 = ₹255.

Answer: Fixed charge ₹5, per-km charge ₹10; fare for 25 km = ₹255.

CBSE board pattern · Case-based4 marks
A lending library has a fixed charge for the first three days and an additional charge for each day thereafter. Saritha paid ₹27 for a book kept for 7 days, while Susy paid ₹21 for a book kept for 5 days. Let the fixed charge be ₹x and the additional per-day charge (after day 3) be ₹y. (i) Form the pair of equations. (ii) Find x and y. (iii) How much would a person pay for a book kept for 10 days?
Step 1 Let fixed charge for the first 3 days = ₹x; additional per-day charge = ₹y.

Step-by-step solution

  1. Let fixed charge for the first 3 days = ₹x; additional per-day charge = ₹y.
  2. Saritha (7 days): x + (7 − 3)y = 27 → x + 4y = 27 …(1).
  3. Susy (5 days): x + (5 − 3)y = 21 → x + 2y = 21 …(2).
  4. Subtract (2) from (1): 2y = 6 → y = 3. From (2): x = 21 − 6 = 15.
  5. For 10 days → 7 extra days: charge = 15 + 7(3) = ₹36.

Answer: Fixed ₹15, per-extra-day ₹3; charge for 10 days = ₹36.
