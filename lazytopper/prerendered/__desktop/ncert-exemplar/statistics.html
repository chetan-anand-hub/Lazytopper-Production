Exemplar Ex 13.1 Q31 mark

Step-by-step solution

  1. Σ fᵢ(xᵢ − x̄) = Σ fᵢxᵢ − x̄ · Σ fᵢ.
  2. Since x̄ = Σ fᵢxᵢ / Σ fᵢ, the right side equals Σ fᵢxᵢ − Σ fᵢxᵢ = 0.

Answer: 0 — option (a).

Exemplar Ex 13.2 Q42 marks
Will the median class and modal class of a grouped data always be different? Justify your answer briefly.
Step 1 No — they can coincide.

Step-by-step solution

  1. No — they can coincide.
  2. Example: a distribution with one class having both the maximum frequency and containing the (n/2)ᵗʰ observation will have the same class as median class and modal class.

Answer: Not always different — they can coincide.

Exemplar Ex 13.2 Q12 marks
The median of an ungrouped data and the median calculated when the same data is grouped are always the same. Do you think that this is a correct statement? Give reason.
Step 1 [1 mark] No, it is not always correct.

Step-by-step solution

  1. [1 mark] No, it is not always correct.
  2. [1 mark] The grouped-median formula assumes the observations in each class are uniformly (equally) spaced within the class, which is generally only an approximation, so the two medians need not coincide.

Answer: Not always — the grouped-median formula assumes uniform distribution within classes, so the values can differ.

Calculate the mean of: Marks 10-20 → 2 students, 20-30 → 4, 30-40 → 7, 40-50 → 6, 50-60 → 1.

Exemplar Ex 13.3 Q163 marks
Find the median bowling speed (in km/h) from: 85-100 → 11 players, 100-115 → 9, 115-130 → 8, 130-145 → 5.
Step 1 n = 33; n/2 = 16.5. cf: 11, 20, 28, 33. Median class is 100-115 (cf 20 first ≥ 16.5). l = 100, cf = 11, f = 9, h = 15.

Step-by-step solution

  1. n = 33; n/2 = 16.5. cf: 11, 20, 28, 33. Median class is 100-115 (cf 20 first ≥ 16.5). l = 100, cf = 11, f = 9, h = 15.

Answer: Median speed ≈ 109.17 km/h.

Exemplar Ex 13.3 Q183 marks

Step 1 Modal class is 201-202 (max freq = 26). l = 201, h = 1, f₁ = 26, f₀ = 12, f₂ = 20.

Exemplar Sample Question 2 (page 163)5 marks
Daily wages (₹) of 110 workers are tabulated: 100-120 → 10, 120-140 → 15, 140-160 → 20, 160-180 → 22, 180-200 → 18, 200-220 → 12, 220-240 → 13. Compute the mean daily wage.
Step 1 [1 mark] Take the class mark (midpoint) of each class as xᵢ: 110, 130, 150, 170, 190, 210, 230; the frequencies fᵢ are 10, 15, 20, 22, 18, 12, 13 with Σfᵢ = 110.

Step-by-step solution

  1. [1 mark] Take the class mark (midpoint) of each class as xᵢ: 110, 130, 150, 170, 190, 210, 230; the frequencies fᵢ are 10, 15, 20, 22, 18, 12, 13 with Σfᵢ = 110.
  2. [1 mark] Direct-method formula: mean x̄ = Σfᵢxᵢ / Σfᵢ.
  3. [1 mark] Compute each fᵢxᵢ: 10×110 = 1100, 15×130 = 1950, 20×150 = 3000, 22×170 = 3740, 18×190 = 3420, 12×210 = 2520, 13×230 = 2990.
  4. [1 mark] Add them: Σfᵢxᵢ = 1100 + 1950 + 3000 + 3740 + 3420 + 2520 + 2990 = 18720.
  5. [1 mark] Mean = 18720/110 ≈ ₹170.18 (mean daily wage).

Answer: Mean daily wage ≈ ₹170.18.

Exemplar Sample Question 3 (page 164)5 marks
Determine the median percentage of marks from 100 students: 30-35 → 14, 35-40 → 16, 40-45 → 18, 45-50 → 23, 50-55 → 18, 55-60 → 8, 60-65 → 3.
Step 1 [1 mark] Here n = 100, so n/2 = 50.

Step-by-step solution

  1. [1 mark] Here n = 100, so n/2 = 50.
  2. [1 mark] Cumulative frequencies (cf): 14, 30, 48, 71, 89, 97, 100.
  3. [1 mark] Median class is the first class whose cf ≥ 50, i.e. 45-50 (cf 71); so l = 45, cf (of preceding class) = 48, f = 23, h = 5.
  4. [1 mark] Median formula: Median = l + ((n/2 − cf)/f) × h = 45 + ((50 − 48)/23) × 5.
  5. [1 mark] = 45 + (2 × 5)/23 = 45 + 10/23 ≈ 45 + 0.43 = 45.4% (median percentage of marks).

Answer: Median percentage ≈ 45.4%.

CBSE board pattern · Case-based4 marks
A school's environment club surveys SO₂ concentration (in ppm) for 30 localities. Concentration of SO₂: 0.00-0.04 → 4, 0.04-0.08 → 9, 0.08-0.12 → 9, 0.12-0.16 → 2, 0.16-0.20 → 4, 0.20-0.24 → 2. (i) Find the class mark of the class 0.04-0.08. (ii) Find Σfᵢ and Σfᵢxᵢ. (iii) Find the mean SO₂ concentration. (iv) Which method did you use and why?
Step 1 (i) Class mark = (0.04 + 0.08)/2 = 0.06.

Step-by-step solution

  1. (i) Class mark = (0.04 + 0.08)/2 = 0.06.
  2. (ii) Class marks: 0.02, 0.06, 0.10, 0.14, 0.18, 0.22. Σfᵢ = 30. Σfᵢxᵢ = 4×0.02 + 9×0.06 + 9×0.10 + 2×0.14 + 4×0.18 + 2×0.22 = 0.08 + 0.54 + 0.90 + 0.28 + 0.72 + 0.44 = 2.96.
  3. (iii) Mean = 2.96/30 ≈ 0.099 ppm.
  4. (iv) Direct method — class marks are small, multiplication is easy and exact.

Answer: (i) 0.06; (ii) Σf = 30, Σfx = 2.96; (iii) Mean ≈ 0.099 ppm; (iv) Direct method.
