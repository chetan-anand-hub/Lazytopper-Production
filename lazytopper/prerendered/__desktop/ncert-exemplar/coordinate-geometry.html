  1. Side AB = 8 (both endpoints have y = 3).
  2. Let C(x, y). For equilateral: AC = BC = 8.
  3. AC² = BC² gives (x+4)² = (x−4)² → 16x = 0 → x = 0 (C lies on perpendicular bisector of AB).
  4. Substitute x = 0 in AC² = 64: 16 + (y−3)² = 64 → (y−3)² = 48 → y = 3 ± 4√3.
  5. AB lies on the line y = 3. For origin to be interior, C must be BELOW AB → y < 3 → y = 3 − 4√3.
  6. Therefore C = (0, 3 − 4√3).

Answer: C = (0, 3 − 4√3).
