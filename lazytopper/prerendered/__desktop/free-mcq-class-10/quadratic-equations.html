Quadratic Equations MCQs

  1. Q1

    If 2 is a root of the equation x2+ax+12=0 and the quadratic equation x2+ax+q=0 has equal roots, then q=
    • (a)12
    • (b)8
    • (c)20
    • (d)16
    Show answer

    Answer: (d) 16

    Putting x=2: 4+2a+12=0, so a=−8. Equal roots need a2−4q=0, so 64=4q and q=16.

  2. Q2

    If y=1 is a common root of the equations ay2+ay+3=0 and y2+y+b=0, then ab equals:
    • (a)3
    • (b)−21​
    • (c)6
    • (d)-3
    Show answer

    Answer: (a) 3

    From the first, 2a+3=0, so a=−23​. From the second, 2+b=0, so b=−2. Hence ab=3.

  3. Q3

    Which of the following is a quadratic equation?
    • (a)x2−3x​+2=0
    • (b)x+x1​=x2
    • (c)x2+x21​=5
    • (d)2x2−5x=(x−1)2
    Show answer

    Answer: (d) 2x2−5x=(x−1)2

    Option 4 simplifies to x2−3x−1=0, a quadratic. The others contain x​, or simplify to a degree 3 or 4 equation.

  4. Q4

    The root of a quadratic equation are 5 and -2. Then, the equation is:
    • (a)x2−3x+10=0
    • (b)x2−3x−10=0
    • (c)x2+3x−10=0
    • (d)x2+3x+10=0
    Show answer

    Answer: (b) x2−3x−10=0

    Sum of roots =3, product =−10. The equation is x2−3x−10=0.

  5. Q5

    If the equation x2−bx+1=0 does not possess real roots, then:
    • (a)-3 < b < 3
    • (b)-2 < b < 2
    • (c)b > 2
    • (d)b < -2
    Show answer

    Answer: (b) -2 < b < 2

    No real roots means D<0: b2−4<0, so −2<b<2.

  6. Q6

    If x=1 is a common root of ax2+ax+2=0 and x2+x+b=0, then ab=
    • (a)1
    • (b)2
    • (c)4
    • (d)3
    Show answer

    Answer: (b) 2

    From x2+x+b=0: b=−2. From ax2+ax+2=0: 2a+2=0, so a=−1. Hence ab=2.

  7. Q7

    Choose the correct answer from the given four options in the following questions Which of the following equations has no real roots?
    • (a)x2−4x+32​=0
    • (b)x2+4x−32​=0
    • (c)x2−4x−32​=0
    • (d)3x2+43​x+4=0
    Show answer

    Answer: (a) x2−4x+32​=0

    For option 1, D=16−122​<0 since 122​≈16.97. So it has no real roots.
