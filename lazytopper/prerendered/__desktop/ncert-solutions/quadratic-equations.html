Exercise 4.1

NCERT Ex 4.1 Q1(iii)2 marks
Check whether (x − 2)(x + 1) = (x − 1)(x + 3) is a quadratic equation.
Step 1 LHS: (x − 2)(x + 1) = x² − x − 2.

Step-by-step solution

  1. LHS: (x − 2)(x + 1) = x² − x − 2.
  2. RHS: (x − 1)(x + 3) = x² + 2x − 3.
  3. Set LHS = RHS: x² − x − 2 = x² + 2x − 3 ⇒ −3x + 1 = 0 (the x² terms cancel).
  4. The equation is linear (degree 1), NOT of the form ax² + bx + c = 0 with a ≠ 0. Hence it is not a quadratic equation.

Answer: Not a quadratic equation (the x² terms cancel; result is linear).

NCERT Ex 4.1 Q2(ii)2 marks
Represent the following situation as a quadratic equation: The product of two consecutive positive integers is 306. (Do not solve.)
Step 1 Let the smaller of the two consecutive positive integers be x.

Step-by-step solution

  1. Let the smaller of the two consecutive positive integers be x.
  2. Then the next consecutive integer = x + 1.
  3. Their product = x(x + 1) = 306.
  4. Rearrange: x² + x − 306 = 0 — the required quadratic equation.

Answer: x² + x − 306 = 0 (where x is the smaller positive integer).

Exercise 4.2

NCERT Ex 4.2 Q1(i)1 mark
The roots of the quadratic equation x² − 3x − 10 = 0 are:
Step 1 Split middle term: −3x = −5x + 2x (since (−5)(2) = −10 and −5 + 2 = −3).

Step-by-step solution

  1. Split middle term: −3x = −5x + 2x (since (−5)(2) = −10 and −5 + 2 = −3).
  2. x² − 5x + 2x − 10 = 0 ⇒ x(x − 5) + 2(x − 5) = 0.
  3. (x − 5)(x + 2) = 0 ⇒ x = 5 or x = −2.
  4. Hence roots are 5 and −2.

Answer: x = 5, x = −2 — option (a).

NCERT Ex 4.2 Q1(ii)2 marks
Find the roots of 2x² + x − 6 = 0 by factorisation.
Step 1 For 2x² + x − 6, product = 2 × (−6) = −12; we need two numbers whose product is −12 and sum is +1: these are +4 and −3.

Step-by-step solution

  1. For 2x² + x − 6, product = 2 × (−6) = −12; we need two numbers whose product is −12 and sum is +1: these are +4 and −3.
  2. Split: 2x² + 4x − 3x − 6 = 0.
  3. Group: 2x(x + 2) − 3(x + 2) = 0 ⇒ (x + 2)(2x − 3) = 0.
  4. Set each factor to zero: x + 2 = 0 ⇒ x = −2; 2x − 3 = 0 ⇒ x = 3/2.

Answer: x = −2 or x = 3/2.

NCERT Ex 4.2 Q1(v)3 marks
Find the roots of 100x² − 20x + 1 = 0 by factorisation.
Step 1 Product ac = 100 × 1 = 100; need two numbers with product 100 and sum −20: both −10.

Step-by-step solution

  1. Product ac = 100 × 1 = 100; need two numbers with product 100 and sum −20: both −10.
  2. Split: 100x² − 10x − 10x + 1 = 0.
  3. Group: 10x(10x − 1) − 1(10x − 1) = 0 ⇒ (10x − 1)(10x − 1) = 0 ⇒ (10x − 1)² = 0.
  4. 10x − 1 = 0 ⇒ x = 1/10.
  5. The equation has a repeated root x = 1/10 (equivalent to D = 400 − 400 = 0).

Answer: x = 1/10 (repeated root).

NCERT Ex 4.2 Q33 marks
Find two numbers whose sum is 27 and product is 182.
Step 1 Let the first number be x; then the other number is 27 − x.

Step-by-step solution

  1. Let the first number be x; then the other number is 27 − x.
  2. Their product: x(27 − x) = 182 ⇒ 27x − x² = 182 ⇒ x² − 27x + 182 = 0.
  3. Factorise: split −27 as −13 − 14 (since 13 × 14 = 182). x² − 13x − 14x + 182 = 0 ⇒ x(x − 13) − 14(x − 13) = 0 ⇒ (x − 13)(x − 14) = 0.
  4. So x = 13 or x = 14; the other number is then 14 or 13.
  5. Verify: 13 + 14 = 27 and 13 × 14 = 182 ✓

Answer: The two numbers are 13 and 14.

NCERT Ex 4.2 Q43 marks
Find two consecutive positive integers, the sum of whose squares is 365.
Step 1 Let the smaller integer be x; the next is x + 1.

Step-by-step solution

  1. Let the smaller integer be x; the next is x + 1.
  2. Equation: x² + (x + 1)² = 365 ⇒ 2x² + 2x + 1 = 365 ⇒ 2x² + 2x − 364 = 0 ⇒ x² + x − 182 = 0.
  3. Factorise: x² + 14x − 13x − 182 = 0 ⇒ x(x + 14) − 13(x + 14) = 0 ⇒ (x − 13)(x + 14) = 0.
  4. x = 13 or x = −14. Since we need positive integers, take x = 13.
  5. Integers are 13 and 14. Verify: 13² + 14² = 169 + 196 = 365 ✓

Answer: 13 and 14.

NCERT Ex 4.2 Q53 marks
The altitude of a right triangle is 7 cm less than its base. If the hypotenuse is 13 cm, find the other two sides.
Step 1 Let the base be x cm; then altitude = (x − 7) cm.

Step-by-step solution

  1. Let the base be x cm; then altitude = (x − 7) cm.
  2. By Pythagoras: base² + altitude² = hypotenuse² ⇒ x² + (x − 7)² = 13² = 169.
  3. Expand: x² + x² − 14x + 49 = 169 ⇒ 2x² − 14x − 120 = 0 ⇒ x² − 7x − 60 = 0.
  4. Factorise: x² − 12x + 5x − 60 = 0 ⇒ x(x − 12) + 5(x − 12) = 0 ⇒ (x − 12)(x + 5) = 0.
  5. x = 12 or x = −5. Reject x = −5 (length must be positive). So base = 12 cm, altitude = 12 − 7 = 5 cm.
  6. Verify: 12² + 5² = 144 + 25 = 169 = 13² ✓

Answer: Base = 12 cm, altitude = 5 cm.

NCERT Example 43 marks
Find the roots of the quadratic equation 6x² − x − 2 = 0 by factorisation.
Step 1 Product ac = 6 × (−2) = −12; we need two numbers with product −12 and sum −1: these are +3 and −4.

Step-by-step solution

  1. Product ac = 6 × (−2) = −12; we need two numbers with product −12 and sum −1: these are +3 and −4.
  2. Split middle term: 6x² + 3x − 4x − 2 = 0.
  3. Group: 3x(2x + 1) − 2(2x + 1) = 0 ⇒ (3x − 2)(2x + 1) = 0.
  4. Either 3x − 2 = 0 ⇒ x = 2/3, or 2x + 1 = 0 ⇒ x = −1/2.
  5. Verify: 6(2/3)² − (2/3) − 2 = 6·(4/9) − 2/3 − 2 = 8/3 − 2/3 − 2 = 6/3 − 2 = 0 ✓

Answer: x = 2/3 or x = −1/2.
