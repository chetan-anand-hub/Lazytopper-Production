Exercise 8.1

NCERT Ex 8.1 Q12 marks
In ∆ABC, right-angled at B, AB = 24 cm and BC = 7 cm. Determine sin A and cos A.
Step 1 Right-angled at B, so AC is the hypotenuse. By Pythagoras: AC² = AB² + BC² = 24² + 7² = 576 + 49 = 625.

Step-by-step solution

  1. Right-angled at B, so AC is the hypotenuse. By Pythagoras: AC² = AB² + BC² = 24² + 7² = 576 + 49 = 625.
  2. AC = 25 cm.
  3. For angle A: side opposite = BC = 7; side adjacent = AB = 24; hypotenuse = AC = 25.
  4. sin A = opposite / hypotenuse = BC / AC = 7/25.
  5. cos A = adjacent / hypotenuse = AB / AC = 24/25.

Answer: sin A = 7/25, cos A = 24/25.

NCERT Ex 8.1 Q32 marks
If sin A = 3/4, calculate cos A and tan A.
Step 1 sin A = opposite/hypotenuse = 3/4, so let opposite = 3k and hypotenuse = 4k for some k > 0.

Step-by-step solution

  1. sin A = opposite/hypotenuse = 3/4, so let opposite = 3k and hypotenuse = 4k for some k > 0.
  2. By Pythagoras, adjacent² = hyp² − opp² = (4k)² − (3k)² = 16k² − 9k² = 7k².
  3. Adjacent = k√7.
  4. cos A = adjacent/hypotenuse = k√7 / 4k = √7 / 4.
  5. tan A = opposite/adjacent = 3k / (k√7) = 3/√7.

Answer: cos A = √7/4, tan A = 3/√7.

NCERT Ex 8.1 Q43 marks
Given 15 cot A = 8, find sin A and sec A.
Step 1 15 cot A = 8 ⇒ cot A = 8/15, so tan A = 15/8.

Step-by-step solution

  1. 15 cot A = 8 ⇒ cot A = 8/15, so tan A = 15/8.
  2. tan A = opposite/adjacent = 15/8: let opposite = 15k, adjacent = 8k.
  3. Hypotenuse² = (15k)² + (8k)² = 225k² + 64k² = 289k² ⇒ hypotenuse = 17k.
  4. sin A = opposite/hypotenuse = 15k/17k = 15/17.
  5. sec A = hypotenuse/adjacent = 17k/8k = 17/8.

Answer: sin A = 15/17, sec A = 17/8.

NCERT Ex 8.1 Q55 marks
Given sec θ = 13/12, calculate all other trigonometric ratios.
Step 1 sec θ = hypotenuse/adjacent = 13/12, so let hypotenuse = 13k and adjacent = 12k.

Step-by-step solution

  1. sec θ = hypotenuse/adjacent = 13/12, so let hypotenuse = 13k and adjacent = 12k.
  2. By Pythagoras, opposite² = 13²k² − 12²k² = (169 − 144)k² = 25k² ⇒ opposite = 5k.
  3. cos θ = 1/sec θ = 12/13.
  4. sin θ = opposite/hypotenuse = 5k/13k = 5/13.
  5. tan θ = opposite/adjacent = 5k/12k = 5/12; cot θ = 12/5.
  6. cosec θ = hypotenuse/opposite = 13k/5k = 13/5.

Answer: sin θ = 5/13, cos θ = 12/13, tan θ = 5/12, cot θ = 12/5, cosec θ = 13/5.

NCERT Ex 8.1 Q7(i)3 marks
If cot θ = 7/8, evaluate (1 + sin θ)(1 − sin θ) / [(1 + cos θ)(1 − cos θ)].
Step 1 (1 + sin θ)(1 − sin θ) = 1 − sin²θ = cos²θ.

Step-by-step solution

  1. (1 + sin θ)(1 − sin θ) = 1 − sin²θ = cos²θ.
  2. (1 + cos θ)(1 − cos θ) = 1 − cos²θ = sin²θ.
  3. So the expression equals cos²θ / sin²θ = cot²θ.
  4. Given cot θ = 7/8 ⇒ cot²θ = 49/64.

Answer: 49/64.

NCERT Ex 8.1 Q9(i)2 marks
In ∆ABC, right-angled at B, if tan A = 1/√3, find sin A cos C + cos A sin C.
Step 1 tan A = 1/√3 ⇒ ∠A = 30°, so ∠C = 60° (since the triangle is right-angled at B).

Step-by-step solution

  1. tan A = 1/√3 ⇒ ∠A = 30°, so ∠C = 60° (since the triangle is right-angled at B).
  2. sin A = sin 30° = 1/2; cos A = cos 30° = √3/2.
  3. sin C = sin 60° = √3/2; cos C = cos 60° = 1/2.
  4. sin A cos C + cos A sin C = (1/2)(1/2) + (√3/2)(√3/2) = 1/4 + 3/4 = 1.

Answer: 1.

NCERT Ex 8.1 Q111 mark
Which of the following statements is true?
Step 1 (a) False — e.g. tan 60° = √3 > 1.

Step-by-step solution

  1. (a) False — e.g. tan 60° = √3 > 1.
  2. (b) True — sec A = hyp/adj, and 12/5 > 1 is allowed since sec A ≥ 1.
  3. (c) False — 'cos' is cosine, not cosecant; cosec is the abbreviation for cosecant.
  4. (d) False — sin θ ≤ 1 always, so 4/3 is impossible.

Answer: Option (b): sec A = 12/5 is possible.

NCERT Ex 8.2 Q1(i)2 marks
Evaluate sin 60° cos 30° + sin 30° cos 60°.
Step 1 sin 60° = √3/2, cos 30° = √3/2 ⇒ sin 60° · cos 30° = (√3/2)(√3/2) = 3/4.

Step-by-step solution

  1. sin 60° = √3/2, cos 30° = √3/2 ⇒ sin 60° · cos 30° = (√3/2)(√3/2) = 3/4.
  2. sin 30° = 1/2, cos 60° = 1/2 ⇒ sin 30° · cos 60° = (1/2)(1/2) = 1/4.
  3. Sum = 3/4 + 1/4 = 4/4 = 1.

Answer: 1.

NCERT Ex 8.2 Q2(i)1 mark
The value of (2 tan 30°) / (1 + tan²30°) equals:
Step 1 tan 30° = 1/√3, so 2 tan 30° = 2/√3.

Step-by-step solution

  1. tan 30° = 1/√3, so 2 tan 30° = 2/√3.
  2. 1 + tan²30° = 1 + 1/3 = 4/3.
  3. Ratio = (2/√3) / (4/3) = (2/√3) × (3/4) = 6/(4√3) = 3/(2√3) = √3/2.
  4. √3/2 = sin 60°.

Answer: sin 60° — option (a).

NCERT Ex 8.2 Q33 marks
If tan(A + B) = √3 and tan(A − B) = 1/√3; 0° < A + B ≤ 90°, A > B, find A and B.
Step 1 tan(A + B) = √3 ⇒ A + B = 60°.

Step-by-step solution

  1. tan(A + B) = √3 ⇒ A + B = 60°.
  2. tan(A − B) = 1/√3 ⇒ A − B = 30°.
  3. Adding: 2A = 90° ⇒ A = 45°.
  4. Subtracting: 2B = 30° ⇒ B = 15°.

Answer: A = 45°, B = 15°.

NCERT Ex 8.3 Q4(ii)5 marks
Prove the identity: cos A/(1 + sin A) + (1 + sin A)/cos A = 2 sec A.
Step 1 Take LHS and combine over a common denominator cos A · (1 + sin A):

Step-by-step solution

  1. Take LHS and combine over a common denominator cos A · (1 + sin A):
  2. LHS = [cos²A + (1 + sin A)²] / [cos A (1 + sin A)].
  3. Expand numerator: cos²A + 1 + 2 sin A + sin²A = (cos²A + sin²A) + 1 + 2 sin A = 1 + 1 + 2 sin A = 2 + 2 sin A.
  4. = 2(1 + sin A).
  5. So LHS = 2(1 + sin A) / [cos A (1 + sin A)] = 2/cos A = 2 sec A = RHS.
  6. Hence proved.

Answer: LHS = 2 sec A = RHS.

NCERT Ex 8.3 Q4(vi)5 marks
Prove the identity: √[(1 + sin A)/(1 − sin A)] = sec A + tan A.
Step 1 Rationalise inside the square root by multiplying numerator and denominator by (1 + sin A):

Step-by-step solution

  1. Rationalise inside the square root by multiplying numerator and denominator by (1 + sin A):
  2. (1 + sin A)/(1 − sin A) = (1 + sin A)² / [(1 − sin A)(1 + sin A)] = (1 + sin A)² / (1 − sin²A) = (1 + sin A)² / cos²A.
  3. Take the (positive) square root: √[(1 + sin A)² / cos²A] = (1 + sin A) / cos A (taking +ve root since A acute).
  4. = 1/cos A + sin A/cos A = sec A + tan A.
  5. Hence LHS = sec A + tan A = RHS. Proved.

Answer: LHS = sec A + tan A = RHS.
