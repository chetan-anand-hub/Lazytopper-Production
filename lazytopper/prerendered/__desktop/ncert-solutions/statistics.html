Exercise 13.1

NCERT Ex 13.1 Q23 marks
Find the mean daily wage from: Daily wages (₹) 500-520 has 12 workers, 520-540 has 14, 540-560 has 8, 560-580 has 6, 580-600 has 10. (Use step-deviation, a = 550, h = 20.)
Step 1 Class marks: 510, 530, 550, 570, 590. uᵢ = (xᵢ − 550)/20 = −2, −1, 0, 1, 2.

Step-by-step solution

  1. Class marks: 510, 530, 550, 570, 590. uᵢ = (xᵢ − 550)/20 = −2, −1, 0, 1, 2.
  2. Σfᵢ = 50. Σfᵢuᵢ = 12×(−2) + 14×(−1) + 8×0 + 6×1 + 10×2 = −24 − 14 + 0 + 6 + 20 = −12.
  3. Mean = a + h × (Σfu/Σf) = 550 + 20 × (−12/50) = 550 − 4.8 = ₹545.20.

Answer: Mean daily wage = ₹545.20.

NCERT Ex 13.1 Q33 marks
The mean of the following distribution is ₹18. Find the missing frequency f. Daily pocket allowance (₹) 11-13 → 7, 13-15 → 6, 15-17 → 9, 17-19 → 13, 19-21 → f, 21-23 → 5, 23-25 → 4.
Step 1 Class marks: 12, 14, 16, 18, 20, 22, 24. Σfᵢxᵢ = 7×12 + 6×14 + 9×16 + 13×18 + 20f + 5×22 + 4×24 = 84 + 84 + 144 + 234 + 20f + 110 + 96 = 752 + 20f.

Step-by-step solution

  1. Class marks: 12, 14, 16, 18, 20, 22, 24. Σfᵢxᵢ = 7×12 + 6×14 + 9×16 + 13×18 + 20f + 5×22 + 4×24 = 84 + 84 + 144 + 234 + 20f + 110 + 96 = 752 + 20f.
  2. Σfᵢ = 7 + 6 + 9 + 13 + f + 5 + 4 = 44 + f.
  3. Mean = (752 + 20f)/(44 + f) = 18 ⇒ 752 + 20f = 18(44 + f) = 792 + 18f.
  4. 2f = 40 ⇒ f = 20.

Answer: Missing frequency f = 20.

Exercise 13.2

NCERT Ex 13.2 Q23 marks
Find the mode of: Lifetime (hours) 0-20 has 10, 20-40 has 35, 40-60 has 52, 60-80 has 61, 80-100 has 38, 100-120 has 29.
Step 1 Modal class is 60-80 (max freq = 61). l = 60, h = 20, f₁ = 61, f₀ = 52, f₂ = 38.

Step-by-step solution

  1. Modal class is 60-80 (max freq = 61). l = 60, h = 20, f₁ = 61, f₀ = 52, f₂ = 38.
  2. Mode = 60 + [(61 − 52)/(122 − 52 − 38)] × 20 = 60 + (9/32) × 20 = 60 + 180/32.
  3. = 60 + 5.625 ≈ 65.625 hours.

Answer: Modal lifetime ≈ 65.625 hours.

Exercise 13.3

NCERT Ex 13.3 Q15 marks
For monthly electricity consumption (in units): 65-85 → 4, 85-105 → 5, 105-125 → 13, 125-145 → 20, 145-165 → 14, 165-185 → 8, 185-205 → 4. Find the median, mean and mode of the data and compare them.
Step 1 [1 mark] Setup: n = 68, n/2 = 34. Cumulative frequencies: 4, 9, 22, 42, 56, 64, 68, so the median class is 125-145 (first cf ≥ 34); l = 125, cf = 22, f = 20, h = 20.

Step-by-step solution

  1. [1 mark] Setup: n = 68, n/2 = 34. Cumulative frequencies: 4, 9, 22, 42, 56, 64, 68, so the median class is 125-145 (first cf ≥ 34); l = 125, cf = 22, f = 20, h = 20.
  2. [1 mark] Median = l + ((n/2 − cf)/f) × h = 125 + ((34 − 22)/20) × 20 = 125 + 12 = 137 units.
  3. [1 mark] Mean by direct method: class marks 75, 95, 115, 135, 155, 175, 195; Σfx = 300 + 475 + 1495 + 2700 + 2170 + 1400 + 780 = 9320.
  4. [1 mark] Mean = Σfx/Σf = 9320/68 ≈ 137.06 units.
  5. [1 mark] Mode: modal class 125-145 (f₁ = 20, f₀ = 13, f₂ = 14, h = 20); Mode = 125 + ((20 − 13)/(40 − 13 − 14)) × 20 = 125 + (7/13) × 20 ≈ 135.77 units. Comparing: Mean (137.06) ≈ Median (137) > Mode (135.77), so the distribution is nearly symmetric.

Answer: Mean ≈ 137.06, Median = 137, Mode ≈ 135.77 — distribution near-symmetric.

NCERT Example 53 marks
Find the mode of: Family size 1-3 has 7 families, 3-5 has 8, 5-7 has 2, 7-9 has 2, 9-11 has 1.
Step 1 Max frequency is 8 ⇒ modal class is 3-5. l = 3, h = 2, f₁ = 8, f₀ = 7, f₂ = 2.

Step-by-step solution

  1. Max frequency is 8 ⇒ modal class is 3-5. l = 3, h = 2, f₁ = 8, f₀ = 7, f₂ = 2.
  2. Mode = l + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × h = 3 + [(8 − 7)/(16 − 7 − 2)] × 2 = 3 + (1/7) × 2 = 3 + 2/7.
  3. Mode ≈ 3 + 0.286 = 3.286.

Answer: Mode ≈ 3.286.

NCERT Example 73 marks
Find the median height of 51 girls from: <140 → 4, <145 → 11, <150 → 29, <155 → 40, <160 → 46, <165 → 51.
Step 1 Convert to frequencies: classes below 140 → 4, 140-145 → 7, 145-150 → 18, 150-155 → 11, 155-160 → 6, 160-165 → 5. n = 51, n/2 = 25.5.

Step-by-step solution

  1. Convert to frequencies: classes below 140 → 4, 140-145 → 7, 145-150 → 18, 150-155 → 11, 155-160 → 6, 160-165 → 5. n = 51, n/2 = 25.5.
  2. Median class is 145-150 (cf 29 first crosses 25.5). l = 145, cf = 11, f = 18, h = 5.
  3. Median = 145 + [(25.5 − 11)/18] × 5 = 145 + (14.5 × 5)/18 = 145 + 72.5/18 ≈ 145 + 4.03 = 149.03 cm.

Answer: Median height = 149.03 cm.

NCERT Example 85 marks
The median of the following data is 525 and the total frequency is 100. Find x and y. 0-100 → 2, 100-200 → 5, 200-300 → x, 300-400 → 12, 400-500 → 17, 500-600 → 20, 600-700 → y, 700-800 → 9, 800-900 → 7, 900-1000 → 4.
Step 1 [1 mark] The total frequency is 100 and the known frequencies sum to 76, so 76 + x + y = 100 ⇒ x + y = 24 …(i).

Step-by-step solution

  1. [1 mark] The total frequency is 100 and the known frequencies sum to 76, so 76 + x + y = 100 ⇒ x + y = 24 …(i).
  2. [1 mark] Median = 525 lies in the class 500-600, so l = 500, f = 20, h = 100 and n/2 = 50.
  3. [1 mark] Cumulative frequency preceding the median class: cf = 2 + 5 + x + 12 + 17 = 36 + x.
  4. [1 mark] Apply the median formula: 525 = 500 + [(50 − (36 + x))/20] × 100 ⇒ 25 = (14 − x) × 5 ⇒ 14 − x = 5 ⇒ x = 9.
  5. [1 mark] From (i): y = 24 − 9 = 15. Hence x = 9 and y = 15.

Answer: x = 9, y = 15.

CBSE board pattern · Case-based4 marks
A school's environment club surveys SO₂ concentration (in ppm) for 30 localities. Concentration of SO₂: 0.00-0.04 → 4, 0.04-0.08 → 9, 0.08-0.12 → 9, 0.12-0.16 → 2, 0.16-0.20 → 4, 0.20-0.24 → 2. (i) Find the class mark of the class 0.04-0.08. (ii) Find Σfᵢ and Σfᵢxᵢ. (iii) Find the mean SO₂ concentration. (iv) Which method did you use and why?
Step 1 (i) Class mark = (0.04 + 0.08)/2 = 0.06.

Step-by-step solution

  1. (i) Class mark = (0.04 + 0.08)/2 = 0.06.
  2. (ii) Class marks: 0.02, 0.06, 0.10, 0.14, 0.18, 0.22. Σfᵢ = 30. Σfᵢxᵢ = 4×0.02 + 9×0.06 + 9×0.10 + 2×0.14 + 4×0.18 + 2×0.22 = 0.08 + 0.54 + 0.90 + 0.28 + 0.72 + 0.44 = 2.96.
  3. (iii) Mean = 2.96/30 ≈ 0.099 ppm.
  4. (iv) Direct method — class marks are small, multiplication is easy and exact.

Answer: (i) 0.06; (ii) Σf = 30, Σfx = 2.96; (iii) Mean ≈ 0.099 ppm; (iv) Direct method.
