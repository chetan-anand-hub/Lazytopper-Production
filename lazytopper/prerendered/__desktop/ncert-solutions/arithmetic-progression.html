Exercise 5.1

NCERT Ex 5.1 Q41 mark
Which of the following is NOT an AP?
Step 1 Find consecutive differences for option (a): 4 − 2 = 2, 8 − 4 = 4, 16 − 8 = 8 — not constant.

Step-by-step solution

  1. Find consecutive differences for option (a): 4 − 2 = 2, 8 − 4 = 4, 16 − 8 = 8 — not constant.
  2. Hence 2, 4, 8, 16, … is a GP, not an AP.
  3. The remaining three options have constant common differences (−2, 4 and −4 respectively).

Answer: 2, 4, 8, 16, … — option (a).

NCERT Ex 5.1 Q3(i)2 marks
For the AP 3, 1, −1, −3, …, write the first term and the common difference.
Step 1 First term a = 3.

Step-by-step solution

  1. First term a = 3.
  2. Common difference d = a₂ − a₁ = 1 − 3 = −2.
  3. Therefore a = 3 and d = −2.

Answer: a = 3, d = −2.

NCERT Ex 5.1 Q2(i)2 marks
Write the first four terms of the AP with first term a = 10 and common difference d = 10.
Step 1 a₁ = a = 10.

Step-by-step solution

  1. a₁ = a = 10.
  2. a₂ = a + d = 20, a₃ = a + 2d = 30, a₄ = a + 3d = 40.
  3. So the first four terms are 10, 20, 30, 40.

Answer: 10, 20, 30, 40.

NCERT Ex 5.2 Q73 marks
Find the 31st term of an AP whose 11th term is 38 and the 16th term is 73.
Step 1 a + 10d = 38 …(1) and a + 15d = 73 …(2).

Step-by-step solution

  1. a + 10d = 38 …(1) and a + 15d = 73 …(2).
  2. Subtract (1) from (2): 5d = 35 ⇒ d = 7.
  3. From (1): a = 38 − 70 = −32.
  4. a₃₁ = a + 30d = −32 + 30 × 7 = −32 + 210 = 178.

Answer: 31st term = 178.

NCERT Ex 5.2 Q185 marks
The sum of the 4th and 8th terms of an AP is 24 and the sum of the 6th and 10th terms is 44. Find the first three terms of the AP.
Step 1 a₄ + a₈ = 24 ⇒ (a + 3d) + (a + 7d) = 24 ⇒ 2a + 10d = 24 ⇒ a + 5d = 12 …(1).

Step-by-step solution

  1. a₄ + a₈ = 24 ⇒ (a + 3d) + (a + 7d) = 24 ⇒ 2a + 10d = 24 ⇒ a + 5d = 12 …(1).
  2. a₆ + a₁₀ = 44 ⇒ (a + 5d) + (a + 9d) = 44 ⇒ 2a + 14d = 44 ⇒ a + 7d = 22 …(2).
  3. Subtract (1) from (2): 2d = 10 ⇒ d = 5.
  4. Substitute in (1): a + 25 = 12 ⇒ a = −13.
  5. First three terms: a, a + d, a + 2d = −13, −8, −3.

Answer: First three terms: −13, −8, −3.

NCERT Ex 5.3 Q73 marks
Find the sum of the first 22 terms of an AP in which d = 7 and the 22nd term is 149.
Step 1 a₂₂ = a + 21d = 149 ⇒ a + 21 × 7 = 149 ⇒ a = 149 − 147 = 2.

Step-by-step solution

  1. a₂₂ = a + 21d = 149 ⇒ a + 21 × 7 = 149 ⇒ a = 149 − 147 = 2.
  2. S₂₂ = n/2 (a + l) = 22/2 × (2 + 149).
  3. S₂₂ = 11 × 151 = 1661.

NCERT Ex 5.3 Q133 marks
Find the sum of the first 15 multiples of 8.
Step 1 The 15 multiples form the AP 8, 16, 24, …, with a = 8 and d = 8.

Step-by-step solution

  1. The 15 multiples form the AP 8, 16, 24, …, with a = 8 and d = 8.
  2. a₁₅ = 8 + 14 × 8 = 120.
  3. S₁₅ = 15/2 (8 + 120) = 15/2 × 128 = 15 × 64 = 960.

NCERT Ex 5.3 Q155 marks
A contract on a construction job specifies a penalty for delay of completion as ₹200 for the first day, ₹250 for the second day, ₹300 for the third day, etc., the penalty for each succeeding day being ₹50 more than for the preceding day. How much money must the contractor pay as penalty if the work is delayed by 30 days?
Step 1 Daily penalties form an AP: 200, 250, 300, …, with a = 200 and d = 50.

Step-by-step solution

  1. Daily penalties form an AP: 200, 250, 300, …, with a = 200 and d = 50.
  2. Number of days n = 30.
  3. S₃₀ = 30/2 [2 × 200 + 29 × 50] = 15 [400 + 1450] = 15 × 1850.
  4. S₃₀ = 27750.
  5. Contractor pays ₹27,750 as penalty.

Answer: Total penalty = ₹27,750.

NCERT Example 72 marks
How many two-digit numbers are divisible by 3?
Step 1 Two-digit multiples of 3 form the AP 12, 15, 18, …, 99 with a = 12, d = 3.

Step-by-step solution

  1. Two-digit multiples of 3 form the AP 12, 15, 18, …, 99 with a = 12, d = 3.

NCERT Example 53 marks
Determine the AP whose 3rd term is 5 and the 7th term is 9.
Step 1 a + 2d = 5 …(1) and a + 6d = 9 …(2).

Step-by-step solution

  1. a + 2d = 5 …(1) and a + 6d = 9 …(2).
  2. Subtract (1) from (2): 4d = 4 ⇒ d = 1.
  3. Substitute in (1): a = 5 − 2 = 3.
  4. So the AP is 3, 4, 5, 6, 7, ……

Answer: AP: 3, 4, 5, 6, 7, ….

NCERT Example 133 marks
How many terms of the AP 24, 21, 18, … must be taken so that their sum is 78?
Step 1 a = 24, d = −3, Sₙ = 78.

Step-by-step solution

  1. a = 24, d = −3, Sₙ = 78.
  2. Sₙ = n/2 [2a + (n − 1)d] = n/2 [48 + (n − 1)(−3)] = n/2 [51 − 3n].
  3. Equate: n(51 − 3n)/2 = 78 ⇒ 51n − 3n² = 156 ⇒ n² − 17n + 52 = 0.
  4. (n − 4)(n − 13) = 0 ⇒ n = 4 or n = 13. Both are valid because terms 5 to 13 sum to zero (terms cross from positive to negative).

Answer: n = 4 or n = 13.

NCERT Example 165 marks
A manufacturer of TV sets produced 600 sets in the third year and 700 sets in the seventh year. Assuming that the production increases uniformly by a fixed number every year, find (i) the production in the 1st year, (ii) the production in the 10th year, (iii) the total production in the first 7 years.
Step 1 Let aₙ denote production in the nth year. a₃ = 600 and a₇ = 700.

Step-by-step solution

  1. Let aₙ denote production in the nth year. a₃ = 600 and a₇ = 700.
  2. a + 2d = 600 and a + 6d = 700. Subtract: 4d = 100 ⇒ d = 25.
  3. (i) a = 600 − 2 × 25 = 550. Production in year 1 = 550 sets.
  4. (ii) a₁₀ = a + 9d = 550 + 225 = 775 sets.
  5. (iii) S₇ = 7/2 [2 × 550 + 6 × 25] = 7/2 × 1250 = 4375 sets.

Answer: (i) 550 sets, (ii) 775 sets, (iii) 4375 sets in first 7 years.

CBSE board pattern · Assertion-Reason1 mark
Assertion (A): The list of numbers −10, −6, −2, 2, … is an AP with common difference 4. Reason (R): A list of numbers is an AP if aₖ₊₁ − aₖ is the same constant for every k.
Step 1 Check differences: −6 − (−10) = 4, −2 − (−6) = 4, 2 − (−2) = 4. All equal, so A is true.

Step-by-step solution

  1. Check differences: −6 − (−10) = 4, −2 − (−6) = 4, 2 − (−2) = 4. All equal, so A is true.
  2. R is the standard definition of an AP — true.
  3. We used R to verify A, so R is the correct explanation.

Answer: Option (A).

CBSE board pattern · Case-based4 marks
200 logs are stacked so that 20 logs are in the bottom row, 19 in the next row, 18 in the next, and so on. (i) Write the AP formed by the number of logs in successive rows. (ii) How many rows are needed to stack 200 logs? (iii) How many logs are in the top row? (iv) What is the common difference?
Step 1 (i) AP: 20, 19, 18, … with a = 20, d = −1.

Step-by-step solution

  1. (i) AP: 20, 19, 18, … with a = 20, d = −1.
  2. (ii) Sₙ = n/2 [2a + (n − 1)d] = n/2 [40 − (n − 1)] = n(41 − n)/2 = 200.
  3. ⇒ n² − 41n + 400 = 0 ⇒ (n − 16)(n − 25) = 0. n = 16 (n = 25 makes the 25th term negative, so reject).
  4. (iii) a₁₆ = 20 + 15 × (−1) = 5 logs in the top row.
  5. (iv) d = −1.

Answer: (i) 20, 19, 18, …; (ii) 16 rows; (iii) 5 logs; (iv) d = −1.
