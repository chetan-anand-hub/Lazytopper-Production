NCERT Ex 7.1 Q1(i)2 marks
Find the distance between the pair of points (2, 3) and (4, 1).
Step 1 Apply distance formula d = √[(x₂−x₁)² + (y₂−y₁)²].

Step-by-step solution

  1. Apply distance formula d = √[(x₂−x₁)² + (y₂−y₁)²].
  2. d = √[(4−2)² + (1−3)²] = √(4+4) = √8 = 2√2.

Answer: 2√2 units.

NCERT Ex 7.1 Q1(iii)2 marks
Find the distance between the points (a, b) and (−a, −b).
Step 1 Apply d = √[(x₂−x₁)² + (y₂−y₁)²].

Step-by-step solution

  1. Apply d = √[(x₂−x₁)² + (y₂−y₁)²].
  2. d = √[(−a−a)² + (−b−b)²] = √[4a² + 4b²].
  3. = 2√(a² + b²).

Answer: 2√(a² + b²) units.

NCERT Ex 7.1 Q33 marks
Determine if the points (1, 5), (2, 3) and (−2, −11) are collinear.
Step 1 AB = √[(2−1)² + (3−5)²] = √(1+4) = √5 ≈ 2.236.

Step-by-step solution

  1. AB = √[(2−1)² + (3−5)²] = √(1+4) = √5 ≈ 2.236.
  2. BC = √[(−2−2)² + (−11−3)²] = √(16+196) = √212 ≈ 14.560.
  3. AC = √[(−2−1)² + (−11−5)²] = √(9+256) = √265 ≈ 16.279.
  4. Check AB + BC = √5 + √212 ≈ 16.796 ≠ AC ≈ 16.279.
  5. No sum of two sides equals the third → points are NOT collinear.

Answer: The points are NOT collinear.

NCERT Ex 7.1 Q43 marks
Check whether (5, −2), (6, 4) and (7, −2) are the vertices of an isosceles triangle.
Step 1 AB = √[(6−5)² + (4+2)²] = √(1+36) = √37.

Step-by-step solution

  1. AB = √[(6−5)² + (4+2)²] = √(1+36) = √37.
  2. BC = √[(7−6)² + (−2−4)²] = √(1+36) = √37.
  3. AC = √[(7−5)² + 0²] = √4 = 2.
  4. AB = BC → two sides equal → isosceles triangle.

Answer: Yes — the triangle is isosceles (AB = BC = √37, AC = 2).

NCERT Ex 7.1 Q73 marks
Find the point on the x-axis which is equidistant from (2, −5) and (−2, 9).
Step 1 Point on x-axis: P(x, 0).

Step-by-step solution

  1. Point on x-axis: P(x, 0).
  2. Set squared distances equal: (x−2)² + 25 = (x+2)² + 81.
  3. Expand: x² − 4x + 4 + 25 = x² + 4x + 4 + 81.
  4. Cancel x²: −4x + 29 = 4x + 85 → −8x = 56 → x = −7.
  5. Required point: (−7, 0).

Answer: (−7, 0).

NCERT Ex 7.1 Q83 marks
Find the values of y for which the distance between the points P(2, −3) and Q(10, y) is 10 units.
Step 1 PQ² = (10−2)² + (y+3)² = 64 + (y+3)².

Step-by-step solution

  1. PQ² = (10−2)² + (y+3)² = 64 + (y+3)².
  2. Given PQ = 10 → PQ² = 100.
  3. (y+3)² = 100 − 64 = 36 → y + 3 = ±6.
  4. y = 3 or y = −9.

Answer: y = 3 or y = −9.

NCERT Ex 7.1 Q103 marks
Find a relation between x and y such that the point (x, y) is equidistant from the points (3, 6) and (−3, 4).
Step 1 AP = BP ⇒ AP² = BP².

Step-by-step solution

  1. AP = BP ⇒ AP² = BP².
  2. (x−3)² + (y−6)² = (x+3)² + (y−4)².
  3. Expand: x² − 6x + 9 + y² − 12y + 36 = x² + 6x + 9 + y² − 8y + 16.
  4. Simplify: −6x − 12y + 45 = 6x − 8y + 25 → −12x − 4y + 20 = 0.
  5. Divide by −4: 3x + y − 5 = 0.

Answer: 3x + y = 5.

NCERT Ex 7.2 Q43 marks
Find the ratio in which the line segment joining the points (−3, 10) and (6, −8) is divided by (−1, 6).
Step 1 Let ratio be k : 1.

Step-by-step solution

  2. x = (6k − 3)/(k+1) = −1 → 6k − 3 = −k − 1 → 7k = 2 → k = 2/7.
  3. Ratio = 2 : 7.
  4. Verify y: (−8(2/7) + 10)/(2/7 + 1) = 54/9 = 6. ✓

NCERT Ex 7.2 Q53 marks
Find the ratio in which the line segment joining A(1, −5) and B(−4, 5) is divided by the x-axis. Also find the coordinates of the point of division.
Step 1 Let ratio be k : 1.

Step-by-step solution

  4. x = (−4(1) + 1(1))/2 = −3/2.
  5. Point of division: (−3/2, 0).

NCERT Ex 7.2 Q63 marks
If (1, 2), (4, y), (x, 6) and (3, 5) are the vertices of a parallelogram taken in order, find x and y.
Step 1 Use diagonals bisect: mid(AC) = mid(BD).

Step-by-step solution

  1. Use diagonals bisect: mid(AC) = mid(BD).
  2. Mid(AC) = ((1+x)/2, 4). Mid(BD) = (7/2, (y+5)/2).
  3. x-coords: (1+x)/2 = 7/2 → x = 6.
  4. y-coords: 4 = (y+5)/2 → y = 3.

Answer: x = 6, y = 3.

NCERT Ex 7.2 Q73 marks
Find the coordinates of a point A, where AB is the diameter of a circle whose centre is (2, −3) and B is (1, 4).
Step 1 Centre = midpoint of diameter ⇒ ((x+1)/2, (y+4)/2) = (2, −3).

Step-by-step solution

  1. Centre = midpoint of diameter ⇒ ((x+1)/2, (y+4)/2) = (2, −3).
  2. (x+1)/2 = 2 → x = 3.
  3. (y+4)/2 = −3 → y + 4 = −6 → y = −10.
  4. Therefore A = (3, −10).

Answer: A = (3, −10).

NCERT Example 13 marks
Do the points (3, 2), (−2, −3) and (2, 3) form a triangle? If so, name the type of triangle formed.
Step 1 Apply distance formula d = √[(x₂−x₁)² + (y₂−y₁)²] to each pair.

Step-by-step solution

  1. Apply distance formula d = √[(x₂−x₁)² + (y₂−y₁)²] to each pair.
  2. PQ = √[(3+2)² + (2+3)²] = √(25+25) = √50.
  3. QR = √[(−2−2)² + (−3−3)²] = √(16+36) = √52.
  4. PR = √[(3−2)² + (2−3)²] = √(1+1) = √2.
  5. Check triangle inequality: PQ + PR > QR (since √50 + √2 > √52). Hence a triangle is formed.
  6. Test right angle: PQ² + PR² = 50 + 2 = 52 = QR², i.e. QR² = PQ² + PR², so ∠P = 90°.
  7. Therefore △PQR is a right-angled triangle.

Answer: Yes — a right-angled triangle with the right angle at P.

NCERT Example 25 marks
Show that the points (1, 7), (4, 2), (−1, −1) and (−4, 4) are the vertices of a square.
Step 1 Label A(1, 7), B(4, 2), C(−1, −1), D(−4, 4).

Step-by-step solution

  1. Label A(1, 7), B(4, 2), C(−1, −1), D(−4, 4).
  2. AB = √[(1−4)² + (7−2)²] = √(9+25) = √34.
  3. BC = √[(4−(−1))² + (2−(−1))²] = √(25+9) = √34.
  4. CD = √[(−1−(−4))² + (−1−4)²] = √(9+25) = √34.
  5. DA = √[(−4−1)² + (4−7)²] = √(25+9) = √34. So AB = BC = CD = DA.
  6. Diagonals: AC = √[(1−(−1))² + (7−(−1))²] = √(4+64) = √68; BD = √[(4−(−4))² + (2−4)²] = √(64+4) = √68. AC = BD.
  7. All sides equal and diagonals equal → ABCD is a square.

Answer: Yes — ABCD is a square (all sides = √34 and both diagonals = √68).

NCERT Example 43 marks
Find a relation between x and y such that the point (x, y) is equidistant from the points (7, 1) and (3, 5).
Step 1 AP = BP ⇒ AP² = BP² (squaring removes the radical).

Step-by-step solution

  1. AP = BP ⇒ AP² = BP² (squaring removes the radical).
  2. (x−7)² + (y−1)² = (x−3)² + (y−5)².
  3. Expand: x² − 14x + 49 + y² − 2y + 1 = x² − 6x + 9 + y² − 10y + 25.
  4. Cancel x² and y² on both sides: −14x − 2y + 50 = −6x − 10y + 34.
  5. Rearrange: −8x + 8y = −16 → x − y = 2.
  6. Hence x − y = 2 is the perpendicular bisector of segment AB.

Answer: x − y = 2.

NCERT Example 53 marks
Find a point on the y-axis which is equidistant from the points A(6, 5) and B(−4, 3).
Step 1 Any point on the y-axis has the form (0, y).

Step-by-step solution

  1. Any point on the y-axis has the form (0, y).
  2. Set AP² = BP²: 6² + (5−y)² = (−4)² + (3−y)².
  3. Expand: 36 + 25 − 10y + y² = 16 + 9 − 6y + y².
  4. Cancel y²: 61 − 10y = 25 − 6y → −4y = −36 → y = 9.
  5. Required point: (0, 9). Check: AP = √(36 + 16) = √52 and BP = √(16 + 36) = √52. ✓

Answer: (0, 9).

Step 1 Use section formula P = ((m₁x₂ + m₂x₁)/(m₁+m₂), (m₁y₂ + m₂y₁)/(m₁+m₂)).

In what ratio does the point (−4, 6) divide the line segment joining the points A(−6, 10) and B(3, −8)?

NCERT Example 93 marks
Find the ratio in which the y-axis divides the line segment joining the points (5, −6) and (−1, −4). Also find the point of intersection.
Step 1 Let ratio be k : 1. By section formula, x = (−k + 5)/(k+1).

Step-by-step solution

  1. Let ratio be k : 1. By section formula, x = (−k + 5)/(k+1).
  2. y-axis ⇒ x = 0 → −k + 5 = 0 → k = 5. So ratio = 5 : 1.
  3. y = (−4·5 + (−6)·1)/(5+1) = (−20 − 6)/6 = −26/6 = −13/3.
  4. Point of intersection: (0, −13/3).

NCERT Example 103 marks
If the points A(6, 1), B(8, 2), C(9, 4) and D(p, 3) are the vertices of a parallelogram, taken in order, find the value of p.
Step 1 Diagonals of a parallelogram bisect each other ⇒ mid(AC) = mid(BD).

Step-by-step solution

  1. Diagonals of a parallelogram bisect each other ⇒ mid(AC) = mid(BD).
  2. Mid(AC) = ((6+9)/2, (1+4)/2) = (15/2, 5/2).
  3. Mid(BD) = ((8+p)/2, (2+3)/2) = ((8+p)/2, 5/2).
  4. Equate x: 15/2 = (8+p)/2 → p = 7. (y already matches.)

Answer: p = 7.

CBSE board pattern · Case-based4 marks
In a classroom, Ashima, Bharti and Camella are seated at A(3, 1), B(6, 4) and C(8, 6) respectively. (i) Find AB, BC and AC. (ii) Are A, B, C seated in a straight line? Justify using the distance formula.
Step 1 AB = √[(6−3)² + (4−1)²] = √(9+9) = √18 = 3√2.

Step-by-step solution

  1. AB = √[(6−3)² + (4−1)²] = √(9+9) = √18 = 3√2.
  2. BC = √[(8−6)² + (6−4)²] = √(4+4) = √8 = 2√2.
  3. AC = √[(8−3)² + (6−1)²] = √(25+25) = √50 = 5√2.
  4. Sum AB + BC = 3√2 + 2√2 = 5√2 = AC.
  5. When the sum of two distances equals the third, the three points are collinear → A, B, C are in a straight line.

Answer: AB = 3√2, BC = 2√2, AC = 5√2. AB + BC = AC ⇒ A, B, C are collinear (seated in a line).
